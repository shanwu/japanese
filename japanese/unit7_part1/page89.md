# 活用練習：動詞のた形 (Verb Past Informal / Ta-form Conjugation)

> 參考教學風格：`unit4_part1/page52.md`（文法功能 → 接續公式表格 → 例句 → 課堂練習 → 進階補充）  
> 本頁重點：**動詞「た形」三大類別變換規則**、**て形與た形音便完全對應原則**

---

## 學習目標 (Learning Objectives)

- 掌握日語動詞三大類的「**た形**」（過去簡體形）變換規則。
- 理解只要掌握「て形」，將「て $\to$ た」「で $\to$ だ」即可瞬間轉換為「た形」。

---

## 動詞のた形 活用規則全覽表

### 核心鐵律：て形與た形 100% 對應！
- **〜て $\to$ 〜た**
- **〜で $\to$ 〜だ**

| 類別 | 語尾 | 辭書形 | て形 | た形 | 中文意思 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **I 類 (促音便)** | う、つ、る | 言う / 立つ / 帰る | 言って / 立って / 帰って | **言った / 立った / 帰った** | 說了 / 站了 / 回去了 |
| **I 類 (撥音便)** | ぬ、ぶ、む | 死ぬ / 遊ぶ / 読む | 死んで / 遊んで / 読んで | **死んだ / 遊んだ / 読んだ** | 死了 / 玩了 / 讀了 |
| **I 類 (イ音便)** | く | 書く | 書いて | **書いた** | 寫了 |
| **I 類 (イ音便濁音)** | ぐ | 脱ぐ | 脱いで | **脱いだ** | 脫了 |
| **I 類 (促音便特例)** | 行く (いく) | 行く | 行って | **行った** ⚠️ | 去了 |
| **I 類 (無音便)** | す | 話す | 話して | **話した** | 說了 |
| **II 類 (一段)** | る | 食べる / 見る | 食べて / 見て | **食べた / 見た** | 吃了 / 看了 |
| **III 類 (不規則)** | くる / する | 来る / する | 来て (きて) / して | **来た (きた) / した** | 來了 / 做了 |
