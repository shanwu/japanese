
#### (14)

中川「山田さんのそのカメラはいいですね。どこでかいましたか。」

山田「いえ、これは兄に( )。」

1. あげました
2. もらいました
3. うりました
4. かいました

**題目解析：**
- **題目意思**：中川「山田先生的那台相機很好呢。在哪裡買的？」山田「不，這是從哥哥（ ）。」
- **文法重點**：這題考查授受動詞「もらう」（收到）的用法，以及「に」表示動作來源的用法
- **語境**：討論相機來源的對話

**單字解釋：**
- **中川** (Nakagawa)：中川（人名）
- **山田さん** (Yamada-san)：山田先生（人名 + 敬稱）
- **の** (no)：助詞，表示所有
- **その** (sono)：那個（連體詞・指距離對方較近的物品）
- **カメラ** (kamera)：相機（名詞・外來語）
- **は** (wa)：助詞，表示主題
- **いい** (ii)：好的（い形容詞）
- **です** (desu)：是（助動詞）
- **ね** (ne)：助詞，表示確認或感嘆
- **どこ** (doko)：哪裡（疑問詞）
- **で** (de)：助詞，表示地點
- **かいました** (kaimashita)：買了（動詞・「買う」的過去形）
- **か** (ka)：助詞，表示疑問
- **いえ** (ie)：不（感嘆詞・表示否定）
- **これ** (kore)：這個（指示代詞）
- **は** (wa)：助詞，表示主題
- **兄** (ani)：哥哥（名詞）
- **に** (ni)：助詞，表示動作的對象或來源

**文法解釋：**

**授受動詞「もらう」表示「收到、得到」：**
- **結構**：人 + に + もらう
- **意思**：從...收到、得到
- **用法**：用於表示從某人那裡收到物品或得到幫助
- **主語**：收到物品的人（通常是說話者）
- **に**：表示給予者（物品的來源）
- **例句**：
  - 兄にもらいました：從哥哥那裡收到的
  - 友達に本をもらいました：從朋友那裡收到書
  - 先生に教えてもらいました：請老師教（從老師那裡得到教導）

**授受動詞「あげる」表示「給」：**
- **結構**：人 + に + あげる
- **意思**：給...
- **用法**：用於表示給某人物品或幫助
- **主語**：給予物品的人（通常是說話者）
- **に**：表示接受者（物品的接收者）
- **例句**：
  - 兄にあげました：給哥哥了
  - 友達に本をあげました：給朋友書了
  - 先生にプレゼントをあげました：給老師禮物了

**動詞「うる」表示「賣」：**
- **結構**：人 + に + うる / 物 + を + うる
- **意思**：賣
- **用法**：用於表示賣出物品
- **例句**：
  - 友達にカメラをうりました：把相機賣給朋友了
  - 本をうりました：賣了書

**動詞「かう」表示「買」：**
- **結構**：どこ + で + かう / 物 + を + かう
- **意思**：買
- **用法**：用於表示購買物品
- **例句**：
  - どこでかいましたか：在哪裡買的？
  - 本をかいました：買了書

**各選項分析：**

1. **あげました** (agemashita)
   - ❌ **不正確**
   - **用法**：給...了（過去形）
   - **原因**：語意方向相反
   - 「あげました」是「あげる」的過去形，表示「給...了」
   - 「兄にあげました」意思是「給哥哥了」，表示說話者給哥哥物品
   - 但題目中，山田說「これは兄に（ ）」，表示相機是從哥哥那裡得到的，不是給哥哥的
   - **記憶要點**：「あげる」表示「給」，方向是從說話者到對方，與題意相反

2. **もらいました** (moraimashita)
   - ✅ **正確答案**
   - **用法**：從...收到了（過去形）
   - **原因**：完全符合語境
   - 「もらいました」是「もらう」的過去形，表示「從...收到了」
   - 「兄にもらいました」意思是「從哥哥那裡收到的」，符合題意
   - 山田說「いえ、これは兄にもらいました」，表示相機是從哥哥那裡得到的，不是買的
   - **記憶要點**：「もらう」表示「收到」，方向是從對方到說話者

3. **うりました** (urimashita)
   - ❌ **不正確**
   - **用法**：賣了（過去形）
   - **原因**：語意不符合
   - 「うりました」是「うる」的過去形，表示「賣了」
   - 「兄にうりました」意思是「賣給哥哥了」，表示說話者把物品賣給哥哥
   - 但題目中，山田是在說明相機的來源，不是說明賣出
   - 且「これは兄にうりました」語法上不自然（缺少賓語「を」）
   - **記憶要點**：「うる」表示「賣」，與題意不符

4. **かいました** (kaimashita)
   - ❌ **不正確**
   - **用法**：買了（過去形）
   - **原因**：語意不符合
   - 「かいました」是「かう」的過去形，表示「買了」
   - 「兄にかいました」語法不正確，因為「かう」通常用「どこでかう」或「物をかう」
   - 且中川問「どこでかいましたか」，山田回答「いえ」，表示不是買的
   - **記憶要點**：「かう」表示「買」，且語法結構不符合

**記憶要點總結：**
- **もらう** = 從...收到（本題答案）
- **あげる** = 給...
- **うる** = 賣
- **かう** = 買

**授受動詞的對比：**
- **もらう**（收到）：
  - 結構：人 + に + もらう
  - 方向：從對方到說話者
  - 例：兄にもらいました：從哥哥那裡收到的
- **あげる**（給）：
  - 結構：人 + に + あげる
  - 方向：從說話者到對方
  - 例：兄にあげました：給哥哥了
- **くれる**（給）：
  - 結構：人 + が + くれる
  - 方向：從對方到說話者（對方主動給）
  - 例：兄がくれました：哥哥給我了

**常用表達：**
- 兄にもらいました：從哥哥那裡收到的
- 友達に本をもらいました：從朋友那裡收到書
- 先生に教えてもらいました：請老師教（從老師那裡得到教導）
- 兄にあげました：給哥哥了
- 友達にプレゼントをあげました：給朋友禮物了
