
#### (13)

(川で)

A「見てください。小さな魚がたくさん( )よ。」

B「ほんとうですね。30ぴきくらいいますね。」

1. およぎます
2. およぎません
3. およぎました
4. およんでいます

**題目解析：**
- **題目意思**：（在河邊）A「請看。有很多小魚（ ）。」B「真的呢。大約有30條呢。」
- **文法重點**：這題考查「動詞て形 + います」表示正在進行或持續狀態的用法
- **語境**：在河邊觀察魚的對話場景

**單字解釋：**
- **川** (kawa)：河、河流（名詞）
- **で** (de)：助詞，表示地點
- **見て** (mite)：看（動詞・「見る」的て形）
- **ください** (kudasai)：請（助動詞）
- **小さな** (chiisana)：小的（連體詞・修飾名詞）
- **魚** (sakana)：魚（名詞）
- **が** (ga)：助詞，表示主語
- **たくさん** (takusan)：很多（副詞）
- **よ** (yo)：助詞，表示強調或提醒
- **ほんとう** (hontou)：真的（名詞・形容動詞）
- **です** (desu)：是（助動詞）
- **ね** (ne)：助詞，表示確認或感嘆
- **30ぴき** (sanjuppiki)：30條（數量詞・用於計算魚、蟲等小動物）
- **くらい** (kurai)：大約（副助詞）
- **います** (imasu)：有、存在（動詞・用於有生命物體）

**文法解釋：**

**「動詞て形 + います」表示正在進行或持續狀態：**
- **結構**：動詞て形 + います
- **意思**：正在...、...著
- **用法**：用於表示動作正在進行中，或表示持續的狀態
- **例句**：
  - 魚が泳いでいます：魚正在游泳
  - 本を読んでいます：正在讀書
  - テレビを見ています：正在看電視

**「動詞ます形」表示習慣或未來：**
- **結構**：動詞ます形
- **意思**：做...（習慣或未來）
- **用法**：用於表示習慣性動作或未來的動作
- **例句**：
  - 魚が泳ぎます：魚會游泳（一般情況）
  - 毎日泳ぎます：每天游泳

**「動詞ません」表示否定：**
- **結構**：動詞ません形
- **意思**：不做...
- **用法**：用於表示否定
- **例句**：
  - 魚が泳ぎません：魚不游泳

**「動詞ました」表示過去：**
- **結構**：動詞ました形
- **意思**：做了...（過去）
- **用法**：用於表示過去的動作
- **例句**：
  - 魚が泳ぎました：魚游了泳（過去）

**各選項分析：**

1. **およぎます** (oyogimasu)
   - ❌ **不正確**
   - **用法**：現在形，表示習慣或未來
   - **原因**：語意不符合
   - 「およぎます」是「泳ぐ」的現在形，表示「會游泳」或「將要游泳」
   - 但題目描述的是「現在正在看」的場景，應該用進行式
   - 「魚がたくさんおよぎます」意思是「很多魚會游泳」，不符合「正在看」的語境
   - **記憶要點**：現在形表示習慣或未來，不用於描述正在進行的動作

2. **およぎません** (oyogimasen)
   - ❌ **不正確**
   - **用法**：否定形，表示「不游泳」
   - **原因**：語意完全相反
   - 「およぎません」是「泳ぐ」的否定形，表示「不游泳」
   - 但題目描述的是「有很多魚在游泳」的場景
   - 「魚がたくさんおよぎません」意思是「很多魚不游泳」，與題意完全相反
   - **記憶要點**：否定形表示「不...」，與題意不符

3. **およぎました** (oyogimashita)
   - ❌ **不正確**
   - **用法**：過去形，表示「游了泳」
   - **原因**：時態不符合
   - 「およぎました」是「泳ぐ」的過去形，表示「游了泳」（過去的動作）
   - 但題目描述的是「現在正在看」的場景，應該用現在進行式
   - 「魚がたくさんおよぎました」意思是「很多魚游了泳」（過去），與「現在正在看」的語境不符
   - **記憶要點**：過去形表示過去的動作，不用於描述現在正在進行的動作

4. **およんでいます** (oyonde imasu)
   - ✅ **正確答案**
   - **用法**：進行式，表示「正在游泳」
   - **原因**：完全符合語境
   - 「およんでいます」是「泳ぐ」的て形 + います，表示「正在游泳」
   - 「魚がたくさんおよんでいます」意思是「很多魚正在游泳」，符合「現在正在看」的語境
   - 這是標準的進行式句型，用於描述正在進行的動作
   - **記憶要點**：動詞て形 + います = 正在...

**記憶要點總結：**
- **動詞て形 + います** = 正在...（本題答案）
- **動詞ます形** = 做...（習慣或未來）
- **動詞ません形** = 不做...
- **動詞ました形** = 做了...（過去）

**「～ています」的用法：**
- **表示正在進行**：描述現在正在進行的動作
  - 例：魚が泳いでいます：魚正在游泳
  - 例：本を読んでいます：正在讀書
  - 例：テレビを見ています：正在看電視
- **表示持續狀態**：描述持續的狀態
  - 例：結婚しています：已經結婚了（持續狀態）
  - 例：住んでいます：住著（持續狀態）

**時態對比：**
- **現在形**：およぎます（會游泳、將要游泳）
- **否定形**：およぎません（不游泳）
- **過去形**：およぎました（游了泳）
- **進行式**：およんでいます（正在游泳）

**常用表達：**
- 魚が泳いでいます：魚正在游泳
- たくさんの魚が泳いでいます：很多魚正在游泳
- 本を読んでいます：正在讀書
- テレビを見ています：正在看電視
