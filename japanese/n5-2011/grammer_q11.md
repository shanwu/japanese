
#### (11)

子ども「いただきます。」

母「あ、食べる( ) 手をあらいましょう。」

1. まえに
2. のまえに
3. あとに
4. のあとに

**題目解析：**
- **題目意思**：孩子「我開動了。」母親「啊，在吃（ ）洗手吧。」
- **文法重點**：這題考查「動詞辭書形 + まえに」表示「在...之前」的用法
- **語境**：母親提醒孩子在吃飯前要洗手的對話

**單字解釋：**
- **子ども** (kodomo)：孩子（名詞）
- **いただきます** (itadakimasu)：我開動了（動詞・用餐前的禮貌用語）
- **あ** (a)：啊（感嘆詞・表示提醒或驚訝）
- **食べる** (taberu)：吃（動詞・辭書形）
- **手** (te)：手（名詞）
- **を** (o)：助詞，表示動作的受詞
- **あらいましょう** (araimashou)：洗吧（動詞・「洗う」的ましょう形，表示提議）

**文法解釋：**

**「動詞辭書形 + まえに」表示「在...之前」：**
- **結構**：動詞辭書形 + まえに
- **意思**：在...之前
- **用法**：用於表示在某個動作之前做某事
- **例句**：
  - 食べるまえに手を洗う：在吃之前洗手
  - 寝るまえに歯を磨く：在睡覺之前刷牙
  - 出かけるまえに鍵をかける：在出門之前鎖門

**「名詞 + のまえに」表示「在...之前」：**
- **結構**：名詞 + のまえに
- **意思**：在...之前
- **用法**：用於表示在某個時間點或地點之前
- **例句**：
  - 食事のまえに：在用餐之前
  - 3時のまえに：在3點之前
  - 駅のまえに：在車站前面

**「動詞辭書形 + あとに」表示「在...之後」：**
- **結構**：動詞辭書形 + あとに
- **意思**：在...之後
- **用法**：用於表示在某個動作之後做某事
- **例句**：
  - 食べたあとに歯を磨く：在吃之後刷牙
  - 勉強したあとに遊ぶ：在學習之後玩

**各選項分析：**

1. **まえに** (mae ni)
   - ✅ **正確答案**
   - **用法**：動詞辭書形 + まえに，表示「在...之前」
   - **原因**：完全符合語境
   - 「食べるまえに」意思是「在吃之前」
   - 「食べるまえに手をあらいましょう」意思是「在吃之前洗手吧」，符合題意
   - 這是標準的「動詞辭書形 + まえに」句型
   - **記憶要點**：動詞辭書形 + まえに = 在...之前

2. **のまえに** (no mae ni)
   - ❌ **不正確**
   - **用法**：名詞 + のまえに，表示「在...之前」
   - **原因**：文法結構不正確
   - 「のまえに」用於名詞之後（食事のまえに），不用於動詞之後
   - 「食べるのまえに」語法不正確，動詞後應該直接用「まえに」，不需要「の」
   - **記憶要點**：「のまえに」只用於名詞，動詞用「まえに」

3. **あとに** (ato ni)
   - ❌ **不正確**
   - **用法**：動詞た形 + あとに，表示「在...之後」
   - **原因**：語意不符合
   - 「あとに」表示「在...之後」
   - 「食べるあとに」語法不正確（應該是「食べたあとに」）
   - 即使語法正確，語意也不對，因為應該在吃「之前」洗手，不是在吃「之後」
   - **記憶要點**：「あとに」表示「在...之後」，且動詞要用た形

4. **のあとに** (no ato ni)
   - ❌ **不正確**
   - **用法**：名詞 + のあとに，表示「在...之後」
   - **原因**：文法結構和語意都不正確
   - 「のあとに」用於名詞之後（食事のあとに），不用於動詞之後
   - 「食べるのあとに」語法不正確
   - 即使語法正確，語意也不對，因為應該在吃「之前」洗手
   - **記憶要點**：「のあとに」只用於名詞，動詞用「た形 + あとに」

**記憶要點總結：**
- **動詞辭書形 + まえに** = 在...之前（本題答案）
- **名詞 + のまえに** = 在...之前
- **動詞た形 + あとに** = 在...之後
- **名詞 + のあとに** = 在...之後

**「まえに」vs「あとに」的對比：**
- **まえに**（之前）：
  - 動詞辭書形 + まえに：食べるまえに（在吃之前）
  - 名詞 + のまえに：食事のまえに（在用餐之前）
- **あとに**（之後）：
  - 動詞た形 + あとに：食べたあとに（在吃之後）
  - 名詞 + のあとに：食事のあとに（在用餐之後）

**常用表達：**
- 食べるまえに手を洗う：在吃之前洗手
- 寝るまえに歯を磨く：在睡覺之前刷牙
- 出かけるまえに鍵をかける：在出門之前鎖門
- 勉強するまえに準備する：在學習之前準備
