### 問題 1

**先週** デパートにかいものにいきました。

1. せんしゅ
2. せんしゅう
3. ぜんしゅ
4. ぜんしゅう

**單字解說：**
- **先週** (senshū)
  - 詞性：名詞（時間名詞）
  - 意思：上週、上個星期
  - 構成：先（sen，先、前）+ 週（shū，週、星期）
  - 讀音：せんしゅう (senshū)
  - 用法：表示過去一週的時間
  - 例：先週の日曜日（上週日）、先週から（從上週開始）

- **デパート** (depāto)
  - 詞性：名詞（外來語）
  - 意思：百貨公司、百貨商店
  - 來源：來自英語 "department store"
  - 用法：指大型百貨商場

- **かいもの** (kaimono)
  - 詞性：名詞
  - 意思：購物、買東西
  - 構成：買い（買）+ 物（東西）
  - 用法：表示購物的行為

- **いきました** (ikimashita)
  - 原形：**行く** (iku) - 去、前往
  - 詞性：動詞（五段動詞）
  - 活用：行きます（現在形）→ 行きました（過去形）
  - 意思：去了（過去式）
  - 用法：表示過去的移動動作

**文法解說：**

**句型：時間名詞 + 場所 + に + 目的 + に + 動詞（過去形）**
- **結構**：先週 + デパート + に + かいもの + に + いきました
- **意思**：上週去百貨公司購物了
- **用法**：說明過去某個時間在特定地點做了什麼事

**本句分析：**
- **先週**（時間名詞）→ 上週（時間）
- **デパートに**（場所 + に）→ 到百貨公司（目的地）
- **かいものに**（目的 + に）→ 為了購物（目的）
- **いきました**（動詞過去形）→ 去了（過去的動作）
- **整體意思**：上週去百貨公司購物了

**重要文法點：**

1. **「に」的用法**：
   - **場所 + に**：表示移動的目的地
   - **目的 + に**：表示動作的目的
   - 例：デパートに（到百貨公司）、かいものに（為了購物）

2. **「～に行く」的句型**：
   - 結構：場所 + に + 目的 + に + 行く
   - 意思：去某地做某事
   - 例：学校に勉強に行く（去學校學習）

3. **過去形的用法**：
   - 動詞ます形 → 動詞ました（過去形）
   - 行きます → 行きました（去了）
   - 表示過去的動作或狀態

**題目相關解說：**

本題要求選擇「先週」的正確讀音。這是 JLPT N5 常見的漢字讀音題型，重點在於：
- 正確識別漢字的讀音
- 注意長音和短音的區別
- 注意清音和濁音的區別

**選項分析：**

1. **せんしゅ** (senshu)
   - ❌ **不正確**
   - **原因**：缺少長音「う」，讀音不完整
   - 「週」應該讀作「しゅう」(shū)，不是「しゅ」(shu)
   - 這是常見錯誤，容易漏掉長音
   - **記憶要點**：日語中的長音很重要，漏掉會改變意思

2. **せんしゅう** (senshū)
   - ✅ **正確答案**
   - **原因**：讀音完全正確
   - 「先」讀作「せん」(sen)
   - 「週」讀作「しゅう」(shū)，包含長音「う」
   - 符合標準日語讀音規則
   - **記憶要點**：這是「先週」的標準讀音

3. **ぜんしゅ** (zenshu)
   - ❌ **不正確**
   - **原因**：兩個錯誤
   - ①「先」讀作「せん」(sen)，不是「ぜん」(zen)（濁音錯誤）
   - ②「週」缺少長音「う」，應該讀作「しゅう」(shū)
   - 「ぜん」通常用於「全」（全部）等字
   - **記憶要點**：「先」是清音「せ」，不是濁音「ぜ」

4. **ぜんしゅう** (zenshū)
   - ❌ **不正確**
   - **原因**：「先」讀作「せん」(sen)，不是「ぜん」(zen)
   - 雖然「週」的讀音正確（しゅう），但「先」的濁音錯誤
   - 「ぜん」是「全」的讀音，不是「先」的讀音
   - **記憶要點**：不要混淆「先」（せん）和「全」（ぜん）

**記憶要點總結：**
- 「先週」的「先」讀作「せん」（清音），不是「ぜん」（濁音）
- 「週」必須讀作「しゅう」（長音），不是「しゅ」（短音）
- 長音在日語中很重要，漏掉會改變意思
- 「先」（せん）和「全」（ぜん）容易混淆，要注意區分

**相關詞彙：**
- 先週（せんしゅう）：上週
- 今週（こんしゅう）：本週
- 来週（らいしゅう）：下週
- 先月（せんげつ）：上個月
- 今月（こんげつ）：本月
- 来月（らいげつ）：下個月

### 問題 2

ごはんの**後**でさんぽします。

1. つぎ
2. うしろ
3. まえ
4. あと

**單字解說：**
- **ごはん** (gohan)
  - 詞性：名詞
  - 意思：飯、米飯、用餐
  - 構成：ご（敬語前綴）+ 飯（はん，飯）
  - 用法：指米飯或用餐
  - 例：ごはんを食べる（吃飯）、ごはんの時間（用餐時間）

- **後** (ato)
  - 詞性：名詞
  - 意思：之後、後面
  - 讀音：在時間順序上讀作「あと」(ato)
  - 用法：表示時間上的「之後」或空間上的「後面」
  - 注意：根據語境，讀音和意思會有所不同

- **で** (de)
  - 詞性：助詞
  - 意思：在、用、以（表示時間、場所、方法等）
  - 用法：接在名詞後面，表示時間、場所、方法等
  - 本句用法：表示時間「在...之後」

- **さんぽ** (sanpo)
  - 詞性：名詞（サ變動詞）
  - 意思：散步
  - 構成：散歩（さんぽ）
  - 用法：散步的行為

- **します** (shimasu)
  - 原形：**する** (suru) - 做、進行
  - 詞性：動詞（サ變動詞）
  - 活用：します（現在形）
  - 意思：做、進行
  - 用法：接在名詞後面，構成動詞
  - 例：さんぽします（散步）、勉強します（學習）

**文法解說：**

**句型：名詞 + の + 後 + で + 動詞**
- **結構**：ごはん + の + 後 + で + さんぽします
- **意思**：在用餐之後散步
- **用法**：表示在某個動作或時間之後做另一件事

**本句分析：**
- **ごはんの**（名詞 + の）→ 用餐的（修飾「後」）
- **後で**（名詞 + で）→ 在...之後（表示時間）
- **さんぽします**（動詞）→ 散步（動作）
- **整體意思**：在用餐之後散步

**重要文法點：**

1. **「～の後で」的用法**：
   - 結構：名詞 + の + 後 + で
   - 意思：在...之後
   - 用法：表示時間順序，某個動作之後做另一件事
   - 例：ごはんの後で（用餐之後）、勉強の後で（學習之後）

2. **「後」的讀音區別**：
   - **あと** (ato)：時間上的「之後」
   - **うしろ** (ushiro)：空間上的「後面」
   - 本句是時間順序，所以讀作「あと」

3. **「で」表示時間的用法**：
   - 接在時間名詞後面，表示「在...時候」
   - 例：後で（之後）、今で（現在）

4. **「～します」的用法**：
   - 名詞 + します = 動詞
   - 例：さんぽします（散步）、勉強します（學習）

**題目相關解說：**

本題要求選擇「後」的正確讀音。這是 JLPT N5 常見的漢字讀音題型，重點在於：
- 理解「後」在不同語境中的不同讀音
- 區分時間順序（あと）和空間位置（うしろ）
- 根據句子意思選擇正確的讀音

**選項分析：**

1. **つぎ** (tsugi)
   - ❌ **不正確**
   - **意思**：下一個、接下來
   - **原因**：雖然也表示順序，但「つぎ」是「次」的讀音，不是「後」的讀音
   - 「つぎ」強調「下一個」，而「後」強調「之後」
   - **記憶要點**：「次」（つぎ）和「後」（あと）意思相近但不同

2. **うしろ** (ushiro)
   - ❌ **不正確**
   - **意思**：後面（空間位置）
   - **原因**：「うしろ」是「後」在表示空間位置時的讀音，不是時間順序的讀音
   - 本句「ごはんの後で」表示時間順序（用餐之後），不是空間位置
   - **記憶要點**：「後」表示空間時讀「うしろ」，表示時間時讀「あと」

3. **まえ** (mae)
   - ❌ **不正確**
   - **意思**：前面、之前
   - **原因**：意思完全相反，「まえ」是「前」的讀音，表示「之前」，而本句需要「之後」
   - 如果說「ごはんの前で」才用「まえ」
   - **記憶要點**：「前」（まえ）和「後」（あと）是相反的意思

4. **あと** (ato)
   - ✅ **正確答案**
   - **意思**：之後、後面（時間順序）
   - **原因**：完全正確
   - 「後」在表示時間順序時讀作「あと」
   - 「ごはんの後で」表示「在用餐之後」，符合句子意思
   - **記憶要點**：這是「後」在時間順序上的標準讀音

**記憶要點總結：**
- 「後」有兩個主要讀音：
  - **あと** (ato)：時間上的「之後」
  - **うしろ** (ushiro)：空間上的「後面」
- 本句是時間順序，所以讀作「あと」
- 「前」（まえ）和「後」（あと）是相反的意思
- 「次」（つぎ）和「後」（あと）意思相近但不同

**相關詞彙：**
- 後で（あとで）：之後
- 後ろ（うしろ）：後面（空間）
- 前（まえ）：前面、之前
- 次（つぎ）：下一個
- ごはんの後で（用餐之後）
- 勉強の後で（學習之後）
- 会議の後で（會議之後）

**常見搭配：**
- ～の後で：在...之後
- 後で～する：之後做...
- ～の前に：在...之前

### 問題 3

もういちど**言って**ください。

1. いって
2. きって
3. まって
4. たって

**單字解說：**
- **もういちど** (mō ichido)
  - 詞性：副詞
  - 意思：再一次、再一遍
  - 構成：もう（再、又）+ 一度（いちど，一次）
  - 用法：表示重複某個動作
  - 例：もういちど言ってください（請再說一遍）、もういちど見てください（請再看一遍）

- **言って** (itte)
  - 原形：**言う** (iu) - 說、講、告訴
  - 詞性：動詞（五段動詞）
  - 活用：這是「言う」的**て形**（連用形 + て）
  - 讀音：いって (itte)
  - 意思：說（て形）
  - 用法：用於請求、命令等句型
  - 注意：「言う」的て形是「言って」，不是「言いて」（特殊變化）

- **ください** (kudasai)
  - 詞性：補助動詞（敬語表達）
  - 意思：請（做某事）
  - 用法：接在動詞て形後面，表示禮貌的請求或指示
  - 語感：比命令形更客氣，但比「～てくださいませんか」更直接

**文法解說：**

**句型：もういちど + 動詞て形 + ください**
- **結構**：もういちど + 言って + ください
- **意思**：請再說一遍
- **用法**：用於禮貌地請求對方重複剛才說的話或動作

**本句分析：**
- **もういちど**（副詞）→ 再一次（修飾動詞）
- **言って**（動詞て形）→ 說（動作）
- **ください**（補助動詞）→ 請（禮貌請求）
- **整體意思**：請再說一遍

**重要文法點：**

1. **「もういちど」的用法**：
   - 結構：もういちど + 動詞
   - 意思：再一次、再一遍
   - 用法：表示重複某個動作
   - 例：もういちど言ってください（請再說一遍）

2. **「言う」的活用**：
   - 基本形：言う (iu)
   - ます形：言います (iimasu)
   - て形：言って (itte) ← 本句使用
   - ない形：言わない (iwanai)
   - た形：言った (itta)
   - **注意**：「言う」的て形是「言って」，不是「言いて」（特殊變化）

3. **「～てください」的用法**：
   - 結構：動詞て形 + ください
   - 意思：請（做某事）
   - 用法：用於禮貌地請求或指示對方做某事
   - 語感：客氣但直接，常用於指示、請求

4. **動詞て形的變化規則**：
   - 五段動詞「言う」→ 言って（特殊變化）
   - 五段動詞「切る」→ 切って（きって）
   - 五段動詞「待つ」→ 待って（まって）
   - 五段動詞「立つ」→ 立って（たって）

**題目相關解說：**

本題要求選擇「言って」的正確讀音。這是 JLPT N5 常見的動詞て形讀音題型，重點在於：
- 正確識別動詞原形
- 掌握動詞て形的變化規則
- 區分相似讀音的動詞
- 注意特殊變化的動詞

**選項分析：**

1. **いって** (itte)
   - ✅ **正確答案**
   - **原形**：言う (iu) - 說
   - **原因**：完全正確
   - 「言う」的て形是「言って」(itte)
   - 符合「もういちど言ってください」（請再說一遍）的語境
   - **記憶要點**：這是「言う」的標準て形讀音

2. **きって** (kitte)
   - ❌ **不正確**
   - **原形**：切る (kiru) - 切、剪
   - **原因**：動詞不同，意思完全不同
   - 「きって」是「切る」的て形，意思是「切、剪」
   - 如果說「もういちど切ってください」才是「請再切一次」
   - **記憶要點**：「言う」（說）和「切る」（切）是完全不同的動詞

3. **まって** (matte)
   - ❌ **不正確**
   - **原形**：待つ (matsu) - 等、等待
   - **原因**：動詞不同，意思完全不同
   - 「まって」是「待つ」的て形，意思是「等、等待」
   - 如果說「もういちど待ってください」才是「請再等一次」
   - **記憶要點**：「言う」（說）和「待つ」（等）是完全不同的動詞

4. **たって** (tatte)
   - ❌ **不正確**
   - **原形**：立つ (tatsu) - 站、站立
   - **原因**：動詞不同，意思完全不同
   - 「たって」是「立つ」的て形，意思是「站、站立」
   - 如果說「もういちど立ってください」才是「請再站一次」
   - **記憶要點**：「言う」（說）和「立つ」（站）是完全不同的動詞

**記憶要點總結：**
- 「言う」的て形是「言って」(itte)，不是「言いて」
- 要區分相似讀音的動詞：
  - 言う (iu) → 言って (itte) - 說
  - 切る (kiru) → 切って (kitte) - 切
  - 待つ (matsu) → 待って (matte) - 等
  - 立つ (tatsu) → 立って (tatte) - 站
- 「もういちど～てください」是常用句型，表示「請再...一次」

**相關詞彙：**
- 言う (iu)：說
- 言って (itte)：說（て形）
- もういちど (mō ichido)：再一次
- 切る (kiru)：切
- 切って (kitte)：切（て形）
- 待つ (matsu)：等
- 待って (matte)：等（て形）
- 立つ (tatsu)：站
- 立って (tatte)：站（て形）

**常見搭配：**
- もういちど言ってください：請再說一遍
- もういちど見てください：請再看一遍
- もういちど聞いてください：請再聽一遍
- もういちど読んでください：請再讀一遍

### 問題 4

ちかくに**山**があります。

1. かわ
2. やま
3. いけ
4. うみ

**單字解說：**
- **ちかく** (chikaku)
  - 詞性：名詞（由形容詞「近い」名詞化而來）
  - 意思：附近、近處
  - 原形：近い (chikai) - 形容詞，意思是「近的」
  - 用法：作為名詞使用，表示「附近」這個概念
  - 例：ちかくに（在附近）、駅のちかく（車站附近）

- **に** (ni)
  - 詞性：助詞（格助詞）
  - 意思：在、到（表示場所、位置）
  - 用法：接在名詞後面，表示場所或位置
  - 本句用法：表示存在的位置

- **山** (yama)
  - 詞性：名詞
  - 意思：山、山岳
  - 讀音：やま (yama)
  - 用法：指自然地理中的山
  - 例：高い山（高山）、山に登る（登山）

- **が** (ga)
  - 詞性：助詞（主格助詞）
  - 意思：表示主語
  - 用法：在存在句中，表示存在的主體
  - 本句用法：表示「山」是存在的主體

- **あります** (arimasu)
  - 原形：**ある** (aru) - 有、存在
  - 詞性：動詞（五段動詞）
  - 活用：あります（現在形）
  - 意思：有、存在（用於無生命物體）
  - 用法：表示無生命物體的存在
  - 注意：有生命物體用「います」

**文法解說：**

**句型：場所 + に + 名詞 + が + あります**
- **結構**：ちかく + に + 山 + が + あります
- **意思**：附近有山
- **用法**：表示某個場所存在某個無生命物體

**本句分析：**
- **ちかくに**（場所 + に）→ 在附近（存在的位置）
- **山**（名詞）→ 山（存在的主體）
- **が**（主格助詞）→ 表示主語
- **あります**（動詞）→ 有、存在（無生命物體）
- **整體意思**：附近有山

**重要文法點：**

1. **「～に～があります」的用法**：
   - 結構：場所 + に + 名詞 + が + あります
   - 意思：在某個地方有某個東西
   - 用法：表示無生命物體的存在

### 問題 10

2. なか
3. そと

**單字解說：**
- **かさ** (kasa)
  - 詞性：名詞
  - 意思：傘、雨傘
  - 構成：傘（かさ）
  - 用法：指雨傘或遮陽傘
  - 例：かさをさす（撐傘）、かさを閉じる（收傘）

- **は** (wa)
  - 詞性：助詞（主題標記）
  - 意思：表示句子的主題或主語
  - 用法：雖然寫作「は」，但讀作「wa」
  - 注意：用於提示主題

- **外** (soto)
  - 詞性：名詞
  - 意思：外面、外部、戶外
  - 讀音：そと (soto)
  - 用法：表示外部、戶外的位置
  - 注意：與「中」（裡面）相對
  - 例：外に出る（到外面）、外にいる（在外面）

- **に** (ni)
  - 詞性：助詞（格助詞）
  - 意思：在、到（表示場所、位置）
  - 用法：接在名詞後面，表示場所或位置
  - 本句用法：表示存在的位置

- **あります** (arimasu)
  - 原形：**ある** (aru) - 有、存在
  - 詞性：動詞（五段動詞）
  - 活用：あります（現在形）
  - 意思：有、存在（用於無生命物體）
  - 用法：表示無生命物體的存在

**文法解說：**

**句型：名詞 + は + 場所 + に + あります**
- **結構**：かさ + は + 外 + に + あります
- **意思**：傘在外面
- **用法**：表示某個物品存在於某個位置

**本句分析：**
- **かさ**（名詞）→ 傘（主題）
- **は**（主題標記）→ 提示主題
- **外に**（場所 + に）→ 在外面（存在的位置）
- **あります**（動詞）→ 有、存在（無生命物體）
- **整體意思**：傘在外面

**重要文法點：**

1. **「～は～にあります」的用法**：
   - 結構：名詞 + は + 場所 + に + あります
   - 意思：某個東西在某個地方
   - 用法：表示無生命物體的存在位置
   - 例：かさは外にあります（傘在外面）

2. **「に」表示存在位置的用法**：
   - 接在場所名詞後面，表示存在的位置
   - 例：外に（在外面）、中に（在裡面）

3. **「あります」vs「います」**：
   - **あります**：用於無生命物體（東西、建築物等）
   - **います**：用於有生命物體（人、動物等）
   - 本句「かさ」是無生命物體，所以用「あります」

**題目相關解說：**

本題要求選擇「外」的正確讀音。這是 JLPT N5 常見的漢字讀音題型，重點在於：
- 正確識別漢字的讀音
- 理解句子意思，選擇符合語境的詞彙
- 區分相似意思的位置相關詞彙

**選項分析：**

1. **いえ** (ie)
   - ❌ **不正確**
   - **漢字**：家

   - **原因**：意思完全不同
   - 「いえ」是「家」的讀音，意思是「家、房子」，不是位置概念

2. **なか** (naka)
   - ❌ **不正確**
   - **漢字**：中
   - **意思**：裡面、內部
   - **原因**：意思完全相反
   - 「なか」是「中」的讀音，意思是「裡面、內部」，與「外」（外面）意思相反
   - 如果說「かさは中にあります」才是「傘在裡面」
   - **記憶要點**：「外」（外面）和「中」（裡面）是相反的意思

   - **漢字**：外

   - **原因**：完全正確
   - 「そと」是「外」的標準讀音

4. **にわ** (niwa)

   - **原因**：意思不同

**記憶要點總結：**
- 「外」讀作「そと」(soto)，是標準讀音
- 要區分位置相關的詞彙：
  - **內外**：外（そと）- 外面、中（なか）- 裡面
  - **場所**：家（いえ）- 家、庭（にわ）- 庭院

**單字解說：**
- **さとうさん** (Satō-san)
  - 詞性：名詞（人名 + 敬稱）

  - 詞性：助詞（主題標記）
  - 意思：表示句子的主題或主語
  - 用法：雖然寫作「は」，但讀作「wa」

  - 詞性：名詞（外來語）
  - 意思：吉他
  - 來源：來自英語 "guitar"
  - 用法：指吉他樂器

- **を** (o)
  - 詞性：助詞（賓格助詞）
  - 意思：表示動作的對象
  - 用法：接在名詞後面，表示動詞的賓語

  - 詞性：副詞

**句型：名詞 + は + 名詞 + を + 副詞 + 動詞**
- **結構**：さとうさん + は + ギター + を + じょうずに + ( )
- **意思**：佐藤先生很擅長( )吉他
- **用法**：說明某人很擅長做某個動作

**本句分析：**
- **さとうさん**（名詞）→ 佐藤先生（主題）
- **は**（主題標記）→ 提示主題
- **ギターを**（名詞 + を）→ 吉他（動作對象）
- **じょうずに**（副詞）→ 擅長地（修飾動詞）
- **( )**（動詞）→ 需要填入的動詞
- **整體意思**：佐藤先生很擅長( )吉他

**重要文法點：**

1. **「～をじょうずに～」的用法**：
   - 結構：名詞 + を + じょうずに + 動詞
   - 意思：很擅長做...
   - 用法：表示某人很擅長某個動作
   - 例：ギターをじょうずに弾く（很擅長彈吉他）、ピアノをじょうずに弾く（很擅長彈鋼琴）

   - 詞性：副詞
   - 意思：擅長地、熟練地
   - 用法：修飾動詞，表示動作做得很好

3. **樂器相關動詞**：
   - **弾く** (hiku)：彈奏（樂器）
   - **歌う** (utau)：唱歌
   - **聞く** (kiku)：聽
   - **遊ぶ** (asobu)：玩

**題目相關解說：**

本題要求選擇正確的動詞填入括號。這是 JLPT N5 常見的動詞選擇題型，重點在於：
- 理解句子意思
- 根據語境選擇合適的動詞
- 理解樂器相關動詞的用法

**選項分析：**

   - 如果說「さとうさんは音楽をじょうずに聞きます」語境也不對

3. **ひきます** (hikimasu)
   - ✅ **正確答案**
   - **原形**：弾く (hiku) - 彈、演奏
   - **原因**：完全正確
   - 「弾く」是「彈奏樂器」的意思，專門用於樂器
   - 「ギターを弾く」是標準表達，意思是「彈吉他」

4. **あそびます** (asobimasu)

   - **原形**：遊ぶ (asobu) - 玩、遊玩
   - **原因**：動詞不合適

   - **記憶要點**：樂器應該用「弾く」，不是「遊ぶ」

**記憶要點總結：**
- 彈奏樂器用「弾く」(hiku)
- 「歌う」用於唱歌，不用於樂器
- 「聞く」用於聽，不用於彈樂器
- 「遊ぶ」用於玩，不用於彈樂器

### 問題 21

テーブルにおさらとはしを( )ください。

1. ならべて
2. とって
3. たべて
4. あらって

**題目解析：**
- **題目意思**：請在桌子上（ ）盤子和筷子。
- **文法重點**：這題考查「て形 + ください」的禮貌請求句型
- **語境**：在餐桌上擺放餐具的場景

**單字解釋：**

**題目中的單字：**
- **テーブル** (tēburu)：桌子、餐桌
- **に** (ni)：助詞，表示地點、位置（在、到）
- **おさら** (osara)：盤子、碟子（「お」是敬語前綴）
- **はし** (hashi)：筷子
- **ください** (kudasai)：請（禮貌請求的結尾）

**選項動詞：**
- **ならべる** (naraberu)：排列、擺放、整理
- **とる** (toru)：拿、取、取得
- **たべる** (taberu)：吃
- **あらう** (arau)：洗、清洗

**文法解釋：**

**「て形 + ください」句型：**
- **結構**：動詞て形 + ください
- **意思**：請（做某事）
- **用法**：用於禮貌地請求對方做某事
- **例句**：
  - 並べてください：請排列/請擺放
  - 取ってください：請拿
  - 食べてください：請吃
  - 洗ってください：請洗

**助詞「を」的用法：**
- **「おさらとはしを」**：盤子和筷子（作為動作的對象）
- **助詞「を」**：表示動作的受詞（直接對象）
- **助詞「と」**：表示「和、與」，連接兩個名詞

**各選項分析：**

1. **ならべて** (narabete)
   - ✅ **正確答案**
   - **原形**：並べる (naraberu) - 排列、擺放、整理
   - **原因**：完全符合語境
   - 「並べる」是「排列、擺放」的意思，專門用於將物品整齊地放在某處
   - 「テーブルにおさらとはしを並べてください」意思是「請在桌子上擺放盤子和筷子」
   - 這是準備餐桌時常用的表達方式
   - **記憶要點**：「並べる」用於排列、擺放物品

2. **とって** (totte)
   - ❌ **不正確**
   - **原形**：取る (toru) - 拿、取、取得
   - **原因**：動詞意思不合適
   - 「取る」是「拿、取」的意思，表示從某處拿取東西
   - 「テーブルにおさらとはしを取ってください」意思是「請在桌子上拿盤子和筷子」，語意不通
   - 如果要說「拿盤子和筷子」，應該是「おさらとはしを取ってください」（從某處拿），而不是「テーブルに取る」
   - **記憶要點**：「取る」表示拿取，不表示擺放

3. **たべて** (tabete)
   - ❌ **不正確**
   - **原形**：食べる (taberu) - 吃
   - **原因**：動詞意思完全不合適
   - 「食べる」是「吃」的意思，用於進食
   - 「テーブルにおさらとはしを食べてください」意思是「請在桌子上吃盤子和筷子」，語意荒謬
   - 盤子和筷子是餐具，不是食物，不能吃
   - **記憶要點**：「食べる」用於吃食物，不用於餐具

4. **あらって** (aratte)
   - ❌ **不正確**
   - **原形**：洗う (arau) - 洗、清洗
   - **原因**：動詞意思不合適
   - 「洗う」是「洗」的意思，用於清洗物品
   - 「テーブルにおさらとはしを洗ってください」意思是「請在桌子上洗盤子和筷子」，語意不通
   - 如果要說「洗盤子和筷子」，應該是「おさらとはしを洗ってください」（清洗餐具），而不是「テーブルに洗う」
   - 清洗餐具通常在廚房的水槽進行，不是在桌子上
   - **記憶要點**：「洗う」表示清洗，不表示擺放

**記憶要點總結：**
- 擺放餐具用「並べる」(naraberu)
- 「取る」用於拿取，不用於擺放
- 「食べる」用於吃食物，不用於餐具
- 「洗う」用於清洗，不用於擺放

**動詞對比：**

| 動詞 | 讀音 | 意思 | 用法 |
|------|------|------|------|
| 並べる | ならべる | 排列、擺放 | 用於整理、排列物品 |
| 取る | とる | 拿、取 | 用於從某處拿取東西 |
| 食べる | たべる | 吃 | 用於進食 |
| 洗う | あらう | 洗 | 用於清洗物品 |

**「並べる」的活用：**
- 基本形：並べる (naraberu)
- ます形：並べます (narabemasu)
- 過去形：並べました (narabemashita)
- て形：並べて (narabete) ← 本句使用
- ない形：並べない (narabenai)

**相關詞彙：**
- 並べる（ならべる）：排列、擺放
- テーブル：桌子、餐桌
- おさら（お皿）：盤子、碟子
- はし（箸）：筷子
- 取る（とる）：拿、取
- 食べる（たべる）：吃
- 洗う（あらう）：洗

**常見搭配：**
- テーブルに並べる：在桌子上擺放
- おさらを並べる：擺放盤子
- はしを並べる：擺放筷子
- おさらとはしを並べる：擺放盤子和筷子
- テーブルにおさらとはしを並べてください：請在桌子上擺放盤子和筷子

**餐桌相關表達：**
- テーブルに並べる：在桌子上擺放
- おさらを置く：放盤子
- はしを置く：放筷子
- コップを並べる：擺放杯子
- ナイフとフォークを並べる：擺放刀叉

**「て形 + ください」的相關句型：**
- 動詞て形 + ください：請（做某事）
- 動詞て形 + くださいませんか：能否請您（更禮貌）
- 動詞て形 + もらえますか：能否請您（更禮貌）

### 問題 22

けさそうじをしたからへやは( )です。

1. きれい
2. きたない
3. あかるい
4. くらい

**題目解析：**
- **題目意思**：因為今天早上打掃了，所以房間是（ ）的。
- **文法重點**：這題考查「から」表示原因的句型，以及形容詞的用法
- **語境**：打掃房間後的結果描述

**單字解釋：**

**題目中的單字：**
- **けさ** (kesa)：今天早上、今早（名詞・時間名詞）
- **そうじ** (sōji)：打掃、清掃（名詞）
- **を** (o)：助詞，表示動作的受詞
- **した** (shita)：做了（動詞・「する」的過去形）
- **から** (kara)：因為、由於（助詞・表示原因）
- **へや** (heya)：房間（名詞）
- **は** (wa)：助詞，表示主題
- **です** (desu)：是（助動詞・禮貌判斷句結尾）

**選項形容詞：**
- **きれい** (kirei)：乾淨、漂亮、美麗（な形容詞）
- **きたない** (kitanai)：髒、骯髒（い形容詞）
- **あかるい** (akarui)：明亮、亮的（い形容詞）
- **くらい** (kurai)：暗、暗的、暗的（い形容詞）

**文法解釋：**

**「から」表示原因的句型：**
- **結構**：原因句 + から + 結果句
- **意思**：因為...所以...
- **用法**：用於說明原因和結果的關係
- **例句**：
  - そうじをしたから、へやはきれいです：因為打掃了，所以房間很乾淨
  - あついから、エアコンをつけます：因為很熱，所以開空調
  - いそがしいから、やすみません：因為很忙，所以不休息

**「～をした」的用法：**
- **結構**：名詞 + を + する
- **意思**：做某事、進行某動作
- **過去形**：名詞 + を + した（做了某事）
- **例句**：
  - そうじをする：打掃
  - そうじをした：打掃了（過去）
  - べんきょうをする：學習
  - べんきょうをした：學習了（過去）

**形容詞的分類：**
- **い形容詞**：以「い」結尾的形容詞（如：あかるい、くらい、きたない）
- **な形容詞**：需要加「な」的形容詞（如：きれいな）
- **形容詞 + です**：禮貌形結尾

**各選項分析：**

1. **きれい** (kirei)
   - ✅ **正確答案**
   - **詞性**：な形容詞（乾淨、漂亮）
   - **原因**：完全符合語境和邏輯
   - 「きれい」是「乾淨、漂亮」的意思
   - 「けさそうじをしたからへやはきれいです」意思是「因為今天早上打掃了，所以房間很乾淨」
   - 打掃後的結果就是房間變乾淨，這是符合邏輯的因果關係
   - **記憶要點**：打掃後房間會變「きれい」（乾淨）

2. **きたない** (kitanai)
   - ❌ **不正確**
   - **詞性**：い形容詞（髒、骯髒）
   - **原因**：邏輯矛盾
   - 「きたない」是「髒、骯髒」的意思
   - 「けさそうじをしたからへやはきたないです」意思是「因為今天早上打掃了，所以房間很髒」，這在邏輯上完全矛盾
   - 打掃的目的是讓房間變乾淨，而不是變髒
   - **記憶要點**：打掃後房間應該變乾淨，不是變髒

3. **あかるい** (akarui)
   - ❌ **不正確**
   - **詞性**：い形容詞（明亮、亮的）
   - **原因**：意思不合適
   - 「あかるい」是「明亮、亮的」的意思，用於描述光線、亮度
   - 「けさそうじをしたからへやはあかるいです」意思是「因為今天早上打掃了，所以房間很明亮」
   - 雖然打掃可能會讓房間看起來更明亮（因為乾淨），但「あかるい」主要用於描述光線的亮度，不是打掃的直接結果
   - 打掃的直接結果應該是「きれい」（乾淨），而不是「あかるい」（明亮）
   - **記憶要點**：「あかるい」用於描述光線亮度，不是打掃的直接結果

4. **くらい** (kurai)
   - ❌ **不正確**
   - **詞性**：い形容詞（暗、暗的）

**單字解釋：**

**題目中的單字：**

- **語境**：描述物品位置的場景（圖片顯示眼鏡在桌子上）

**單字解釋：**

**題目中的單字：**
- **めがね** (megane)：眼鏡（名詞）
- **は** (wa)：助詞，表示主題
- **つくえ** (tsukue)：桌子（名詞）
- **の** (no)：助詞，表示所有、修飾
- **に** (ni)：助詞，表示地點、位置
- **あります** (arimasu)：有、存在（動詞・「ある」的禮貌形）

**選項位置詞：**
- **そば** (soba)：旁邊、附近（名詞）
- **よこ** (yoko)：旁邊、側面（名詞）
- **した** (shita)：下面、下方（名詞）
- **うえ** (ue)：上面、上方（名詞）

**文法解釋：**

**「～にあります」表示位置的句型：**
- **結構**：物品 + は + 地點 + の + 位置 + に + あります
- **意思**：某物在某處的某個位置
- **用法**：用於表示無生命物體的位置
- **例句**：
  - めがねはつくえの上にあります：眼鏡在桌子上
  - 本はつくえの下にあります：書在桌子下
  - 車は家のそばにあります：車在房子旁邊

**位置詞的用法：**
- **上（うえ）**：上面、上方
- **下（した）**：下面、下方
- **横（よこ）**：旁邊、側面
- **そば**：旁邊、附近
- **前（まえ）**：前面
- **後ろ（うしろ）**：後面
- **中（なか）**：裡面
- **外（そと）**：外面

**各選項分析：**

1. **そば** (soba)
   - ❌ **不正確**
   - **意思**：旁邊、附近
   - **原因**：位置不符
   - 圖片顯示眼鏡在桌子上，不是在桌子旁邊
   - 「つくえのそば」意思是「桌子旁邊」，不是「桌子上」
   - **記憶要點**：そば = 旁邊，不是上面

2. **よこ** (yoko)
   - ❌ **不正確**
   - **意思**：旁邊、側面
   - **原因**：位置不符
   - 圖片顯示眼鏡在桌子上，不是在桌子旁邊
   - 「つくえのよこ」意思是「桌子旁邊/側面」，不是「桌子上」
   - **記憶要點**：よこ = 旁邊/側面，不是上面

3. **した** (shita)
   - ❌ **不正確**
   - **意思**：下面、下方
   - **原因**：位置不符
   - 圖片顯示眼鏡在桌子上，不是在桌子下面
   - 「つくえのした」意思是「桌子下面」，不是「桌子上」
   - **記憶要點**：した = 下面，不是上面

4. **うえ** (ue)
   - ✅ **正確答案**
   - **意思**：上面、上方
   - **原因**：完全符合圖片內容
   - 圖片顯示眼鏡在桌子上，所以答案是「うえ」
   - 「つくえのうえ」意思是「桌子上」，符合圖片內容
   - **記憶要點**：うえ = 上面

**記憶要點總結：**
- うえ = 上面（本題答案）
- した = 下面
- よこ = 旁邊/側面
- そば = 旁邊/附近
