# 🎴 日語重點複習 Anki 卡片生成 Prompt 指引

本檔案包含用於將任何日語學習文件（如 `unit2.5/page30.md`）轉換為高質量 Anki 複習卡片的 AI Prompt。

---

## 📋 提示詞 (Prompt) 模板

> **使用方法**：複製以下框中的 Prompt，並將下方 `[在此貼上文件內容或指定檔案]` 替換為欲處理的 Markdown 文件內容。

```text
你是一位專業的日語教學專家與 Anki 記憶卡片設計師。
請針對以下提供的大綱/筆記文件內容，精確提煉出「高頻單字」與「核心文法」，並生成符合標準結構的 Anki 複習卡片。

---

### 📥 【輸入內容】
japanese/unit2.5/page30.md

---

### 🎯 【生成目標與規則】

#### 1. 卡片種類與標準格式：
請將內容分為以下兩大類別生成卡片：

##### A. 單字卡 (Vocabulary Card)
- **Front (正面)**：日文單字（漢字/假名）
- **Back (背面)**：
  - **讀音**：假名標音 + 羅馬拼音（Romaji）
  - **詞性**：名詞 / い形容詞 / な形容詞 / 動詞 (含類型) / 助詞 / 疑問詞 等
  - **中文意思**：精確中文翻譯
  - **例句與翻譯**：包含「日文例句 + 羅馬拼音 + 中文翻譯」
  - **補充說明 (選填)**：若有特殊發音（如長音 gēmu）、連音或近義詞對比請註記。

##### B. 文法卡 (Grammar Card)
- **Front (正面)**：核心文法句型 / 關鍵字 (例：`名詞 + の + 名詞` 或 `い形容詞修飾名詞`)
- **Back (背面)**：
  - **核心意思**：中文簡單說明
  - **句型結構**：清楚標示接續方式（如：代名詞/名詞 + の + 名詞）
  - **重點細節/易錯提示**：提示常見錯誤（例如：代名詞「私」屬於名詞需加「の」；「い形容詞」修飾名詞不加「の」）
  - **經典例句**：提供 1~2 組完整「日文例句 + 羅馬拼音 + 中文翻譯」

---

#### 2. 輸出格式需求（提供兩種）：

1. **Markdown 預覽格式**：使用 Markdown 標題、Front / Back 清單標示，便於閱讀與校對。
2. **Anki CSV/TSV 匯入格式**：提供一個 `tsv` 程式碼區塊（使用 Tab `\t` 分隔欄位，雙引號包覆多行內容），包含 `Front` 與 `Back` 兩欄，方便使用者一鍵複製並直接匯入 Anki。

---

### 💡 範例輸出參考 (Example Output Style)

#### [Markdown 預覽]
### Card 1：私のかさ
**Front:** 私のかさ
**Back:**
- **讀音：** わたしのかさ (watashi no kasa)
- **文法說明：** 代名詞「私」（屬於名詞）+ 助詞「の」（的）+ 名詞「かさ」
- **結構：** 名詞 ＋ の ＋ 名詞
- **意思：** 我的傘
- **例句：** これは私のかさです。(Kore wa watashi no kasa desu. / 這是我的傘。)

## 🛠️ 使用說明與技巧

1. **直接複製 Prompt**：可將此 Prompt 加入 Prompt library 或複製給 AI Agent 使用。
2. **大量產生處理**：若文件較長，可指定「請先針對『對話①與對話②』生成」，分批處理以維持卡片品質。
3. **Anki 匯入設定**：
   - 複製 TSV 程式碼區塊內容並儲存為 `.txt` 或 `.csv`。
   - 在 Anki 中選擇「匯入檔案 (Import File)」。
   - 欄位分隔符號選擇 `Tab`，並勾選「允許卡片中使用 HTML」。
