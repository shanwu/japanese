## 📊 N4 考制架構、分值與及格標準 (Scoring & Test Structure)

JLPT N4 滿分為 **180 分**，合格判定採「總分合格線」與「各科目單項門檻線（得點區分基準點）」雙軌制：

```mermaid
pie title JLPT N4 分數分佈 (滿分 180 分)
    "言語知識 (文字・語彙・文法) + 読解" : 120
    "聴解 (聽力)" : 60
```

### 1. 及格門檻與合格標準表

| 得點科目區分 | 測驗內容 | 得點範圍 | 基準點 (單項最低門檻) | 合格判定條件 |
| :--- | :--- | :---: | :---: | :--- |
| **言語知識・読解** | 文字・語彙（25分鐘）<br>文法・読解（55分鐘） | 0 ～ 120 分 | **38 分** | ① 總得分 $\ge$ **90 分**<br>② 言語知識・読解 $\ge$ **38 分**<br>③ 聴解 $\ge$ **19 分**<br>*(兩科目皆不可低於基準點)* |
| **聴解** | 課題理解 / 要點理解 / 發話表現 / 即時應答（35分鐘） | 0 ～ 60 分 | **19 分** |
| **合計 (Total)** | **全科目總體檢定** | **0 ～ 180 分** | **總分門檻 90 分** |

## 🎯 第三部分：近 5 年 N4 真題高頻失分點與必考文法矩陣

依據 2020～2024 年真題出現頻率精算，以下六大語法板塊佔據文法大題 70% 分值：

```mermaid
flowchart TD
    M1["1. 動詞變態體系<br>(被動形 れる/られる ＋ 使役形 せる/させる)"] --> PASS["N4 合格核心"]
    M2["2. 授受動詞與請求<br>(あげる / もらう / くれる / ていただく)"] --> PASS
    M3["3. 假定與條件表達<br>(と・ば・たら・なら 4大區隔)"] --> PASS
    M4["4. 時態與情態副詞<br>(～たところ / ～ばかり / ～ことにする)"] --> PASS
    M5["5. 敬語基礎骨架<br>(尊敬語 お/ご～になる vs 謙讓語 お/ご～する)"] --> PASS
    M6["6. 形容詞過去式與否定<br>(～かった / ～くなかった / よかった)"] --> PASS
```

1. **被動與使役被動（受身・使役受身）**：
   - 考點：母にしかられました（被媽媽罵）、友達を待たせている（讓朋友等待）、田中さんは彼女をよろこばせた（田中讓女友開心）。
2. **授受動詞（やりもらい）**：
   - 考點：トマトを切ってもらえる？（能幫我切番茄嗎？）、花をプレゼントしてくれた（為我送了花）。
3. **假定條件四天王**：
   - `と`（自然恆常結果）
   - `ば`（假定假設）
   - `たら`（完成後接續／口語最常用）
   - `なら`（接對方話題給予建議）
4. **傳聞 vs 推量 vs 樣態**：
   - `～そうだ`（聽說 / 看起來快要...）
   - `～によると`（根據...所說，必搭配傳聞そうだ）
5. **形容詞時態與否定（本課 Unit 3 核心）**：
   - 促音停頓：`高かった` (takakatta)
   - 否定過去：`高くなかった` (takakunakatta)
   - 特殊不規則：`いい ➔ よかった / よくなかった`（大考每年必出）
