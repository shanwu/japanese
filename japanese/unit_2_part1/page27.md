# 「これ・それ・あれ」の練習 (Practice with "これ・それ・あれ")

## 例文 (Example Dialogues)

### 例 1 (Example 1) ①

**A:** これは だれのかばんですか。
（これは だれのかばんですか。）
Kore wa dare no kaban desu ka?
Whose bag is this?
這是誰的包包？

**B:** それは 田中さんの かばんです。
（それは たなかさんの かばんです。）
Sore wa Tanaka-san no kaban desu.
That is Mr. Tanaka's bag.
那是田中先生的包包。

---

### 例 2 (Example 2) ②

**A:** あれは 日本の車ですか。
（あれは にほんのくるまですか。）
Are wa Nihon no kuruma desu ka?
Is that a Japanese car?
那是日本的車嗎？

**B:** はい。あれは 日本の車です。
（はい。あれは にほんのくるまです。）
Hai. Are wa Nihon no kuruma desu.
Yes. That is a Japanese car.
是的。那是日本的車。

## やってみよう! (Yatte miyou!) - Let's try!

### 例 (Example)

**A:** （これ）、たんじょう日のプレゼントです。
（（これ）、たんじょうびのプレゼントです。）
(Kore), tanjoubi no purezento desu.
This is a birthday present.
這是生日禮物。

**B:** ありがとう。
Arigatou.
Thank you.
謝謝。

### 練習問題 1 (Practice Question 1)

**A:** （　　）は だれのかさですか。
（（　　）は だれのかさですか。）
(　　) wa dare no kasa desu ka?
Whose umbrella is (　　)?
（　　）是誰的傘？

**B:** （　　）は 私のかさです。
（（　　）は わたしのかさです。）
(　　) wa watashi no kasa desu.
(　　) is my umbrella.
（　　）是我的傘。

---

### 練習問題 2 (Practice Question 2)

**A:** （　　）は 何ですか。
（（　　）は なんですか。）
(　　) wa nan desu ka?
What is (　　)?
（　　）是什麼？

**B:** （　　）は 電話の会社です。
（（　　）は でんわのかいしゃです。）
(　　) wa denwa no kaisha desu.
(　　) is a telephone company.
（　　）是電話公司。

---

### 練習問題 3 (Practice Question 3)

**A:** （　　）かばんは いくらですか。
（（　　）かばんは いくらですか。）
(　　) kaban wa ikura desu ka?
How much is (　　) bag?
（　　）包包多少錢？

**B:** 48,000円です。
（よんまんはっせんえんです。）
Yonmanhassen-en desu.
It's 48,000 yen.
是48,000日元。
