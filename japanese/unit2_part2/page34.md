# 助数詞一覧表 - Counter Suffixes Reference Chart

## 學習目標 (Learning Objectives)

**できること (What you can do):**
- 様々な助数詞の読み方を理解し、正しく発音できる。
- Can understand and correctly pronounce various counter suffixes.
- 能夠理解各種助數詞的讀法，並正確發音。
- 数字と助数詞の組み合わせによる発音変化を理解できる。
- Can understand pronunciation changes when numbers combine with counter suffixes.
- 能夠理解數字與助數詞組合時的發音變化。
- 適切な助数詞を選択して使用できる。
- Can select and use appropriate counter suffixes.
- 能夠選擇並使用適當的助數詞。

## 発音変化の規則 (Pronunciation Change Rules)

### 規則1: 促音化 (Sokuon - Small っ)

**說明**: 某些數字後面，助數詞的開頭會變成促音（小っ）。

**適用助數詞**:
- **ほん**: 1本 (ippon), 6本 (roppon), 8本 (happon), 10本 (juppon)
- **はい**: 1杯 (ippai), 6杯 (roppai), 8杯 (happai), 10杯 (juppai)
- **こ**: 1個 (ikko), 6個 (rokko), 8個 (hakko), 10個 (jukko)
- **かい**: 1階 (ikkai), 6階 (rokkai), 8階 (hakkai), 10階 (jukkai)
- **さつ**: 1冊 (issatsu), 8冊 (hassatsu), 10冊 (jussatsu)
- **さい**: 1歳 (issai), 8歳 (hassai), 10歳 (jussai)

**規則總結**: 1、6、8、10後面，助數詞的開頭會變成促音。

---

### 規則2: 濁音化 (Dakuon - Voiced Sound)

**說明**: 某些數字後面，助數詞的開頭會變成濁音（ば、だ、が等）。

**適用助數詞**:
- **ほん**: 3本 (sanbon) - 「ほん」→「ぼん」
- **はい**: 3杯 (sanbai) - 「はい」→「ばい」
- **ばん**: 3番 (sanpan) - 「ばん」→「ぱん」

**規則總結**: 3後面，某些助數詞的開頭會變成濁音或半濁音。

---

### 規則3: 特殊讀法 (Special Readings)

**說明**: 某些助數詞的數字讀法完全特殊，不能用一般的數字讀法。

**適用助數詞**:
- **つ**: 所有數字讀法都特殊（ひとつ、ふたつ、みっつ等）
- **にん**: 1人 (hitori)、2人 (futari) 的讀法特殊

**規則總結**: 需要特別記憶這些特殊讀法。

---

### 規則4: 數字本身的變化 (Number Pronunciation Changes)

**說明**: 某些數字在特定助數詞前會改變讀法。

**例子**:
- **4**: 一般讀作「よん」，但在「円」前讀作「よ」（4円 = よえん）
- **1**: 一般讀作「いち」，但在某些助數詞前讀作「いっ」（1個 = いっこ）
- **6**: 一般讀作「ろく」，但在某些助數詞前讀作「ろっ」（6本 = ろっぽん）
- **8**: 一般讀作「はち」，但在某些助數詞前讀作「はっ」（8本 = はっぽん）
- **10**: 一般讀作「じゅう」，但在某些助數詞前讀作「じゅっ」（10本 = じゅっぽん）

## 練習問題 (Practice Exercises)

### 練習1: 選擇正確的助數詞

請選擇適當的助數詞填入空白處：

1. パンを2（    ）食べます。
   Pan o ni-(    ) tabemasu.
   吃2片麵包。

2. 本を3（    ）読みました。
   Hon o san-(    ) yomimashita.
   讀了3本書。

3. コーヒーを2（    ）飲みます。
   Kōhī o ni-(    ) nomimasu.
   喝2杯咖啡。

4. ペンを5（    ）買いました。
   Pen o go-(    ) kaimashita.
   買了5支筆。

5. りんごを4（    ）ください。
   Ringo o yottsu kudasai.
   請給我4個蘋果。

**答案 (Answers)**:
1. まい (mai) - パンを2枚食べます。
2. さつ (satsu) - 本を3冊読みました。
3. はい (hai) - コーヒーを2杯飲みます。
4. ほん (hon) - ペンを5本買いました。
5. つ (tsu) - りんごを4つください。

---

### 練習2: 選擇正確的讀法

請選擇正確的讀法：

1. 3本: さんほん / さんぼん
2. 4円: よんえん / よえん
3. 1歳: いちさい / いっさい
4. 2人: ににん / ふたり
5. 6杯: ろくはい / ろっぱい

**答案 (Answers)**:
1. さんぼん (sanbon) - 「3本」時，「ほん」會變成「ぼん」
2. よえん (yo-en) - 「4円」時，「よん」會變成「よ」
3. いっさい (issai) - 「1歳」時，「いち」會變成「いっ」
4. ふたり (futari) - 「2人」有特殊讀法，不是「ににん」
5. ろっぱい (roppai) - 「6杯」時，「6」會變成「ろっ」，「はい」會變成「ぱい」

---

### 練習3: 完成句子

請完成以下句子：

1. 私は（    ）歳です。
   Watashi wa (    )-sai desu.
   我25歲。

2. 教室に（    ）人います。
   Kyōshitsu ni (    )-nin imasu.
   教室裡有8個人。

3. エレベーターで（    ）階へ行きます。
   Erebētā de (    )-kai e ikimasu.
   搭電梯去10樓。

4. 切手を（    ）枚買いました。
   Kitte o (    )-mai kaimashita.
   買了7張郵票。

5. この本は（    ）円です。
   Kono hon wa (    )-en desu.
   這本書是5000日元。

**答案 (Answers)**:
1. にじゅうご (nijūgo) - 私は25歳です。
2. はちにん (hachinin) - 教室に8人います。
3. じゅっかい (jukkai) - エレベーターで10階へ行きます。
4. ななまい (nana-mai) - 切手を7枚買いました。
5. ごせん (gosen) - この本は5000円です。

## 実用例文 (Practical Example Sentences)

### 購物場景 (Shopping Scene)

**店員**: いらっしゃいませ。何かお探しですか。
Irasshaimase. Nani ka osagashi desu ka.
歡迎光臨。您在找什麼嗎？

**顧客**: りんごを5つください。
Ringo o itsutsu kudasai.
請給我5個蘋果。

**店員**: かしこまりました。他には何か？
Kashikomarimashita. Hoka ni wa nani ka?
知道了。還有其他需要的嗎？

**顧客**: コーヒーを2杯ください。
Kōhī o ni-hai kudasai.
請給我2杯咖啡。

## 助数詞の選択ガイド (Counter Suffix Selection Guide)

### 物品形狀分類 (Classification by Object Shape)

**扁平物品** → まい (枚)
- 紙、CD、盤子、郵票、照片、T恤

**細長物品** → ほん (本)
- 筆、傘、筷子、樹木、瓶子、花

**圓形物品** → つ (個) 或 こ (個)
- 蘋果、橘子、球、雞蛋

**立體小物品** → こ (個)
- 硬幣、糖果、小玩具

**機器、車輛** → だい (台)
- 電腦、電視、車、洗衣機

**書籍** → さつ (冊)
- 書、雜誌、字典

**飲料、液體** → はい (杯)
- 茶、咖啡、酒、米飯

**人數** → にん (人)
- 人（注意1人、2人的特殊讀法）

**樓層** → かい (階)
- 建築物的樓層

**順序、號碼** → ばん (番)
- 順序、排名、號碼

**貨幣** → えん (円)
- 日元

**年齡** → さい (歳)
- 年齡

## 學習重點總結 (Key Learning Points)

1. **助数詞的重要性**: 日語中計算物品時必須使用適當的助數詞
2. **發音變化**: 助數詞會影響數字的讀法，需要特別記憶
3. **特殊讀法**: 「つ」和「にん」的數字讀法完全特殊
4. **促音化**: 1、6、8、10後面，某些助數詞會變成促音
5. **濁音化**: 3後面，某些助數詞會變成濁音或半濁音
6. **選擇適當的助數詞**: 根據物品的形狀、性質選擇助數詞

## 延伸學習 (Extended Learning)

### 更多助数詞 (More Counter Suffixes)

- **匹** (hiki): 用於小動物
  - 1匹: いっぴき (ippiki)
  - 2匹: にひき (nihiki)
  - 3匹: さんびき (sanbiki)

- **頭** (tō): 用於大動物
  - 1頭: いっとう (ittō)
  - 2頭: にとう (nitō)
  - 3頭: さんとう (santō)

- **羽** (wa): 用於鳥類
  - 1羽: いちわ (ichi-wa)
  - 2羽: にわ (ni-wa)
  - 3羽: さんば (sanba)

- **足** (soku): 用於鞋子、襪子
  - 1足: いっそく (issoku)
  - 2足: にそく (ni-soku)
  - 3足: さんぞく (sanzoku)

### 相關句型 (Related Patterns)

- **～を～ます**: 做...（動作）
  - パンを2枚食べます。(Pan o ni-mai tabemasu.) - 吃2片麵包。

- **～に～があります**: 在...有...
  - 机の上に本が3冊あります。(Tsukue no ue ni hon ga san-satsu arimasu.) - 桌子上有3本書。

- **～をください**: 請給我...
  - りんごを3つください。(Ringo o mittsu kudasai.) - 請給我3個蘋果。

- **～は～です**: ～是～
  - 私は25歳です。(Watashi wa nijūgo-sai desu.) - 我25歲。

---

**學習建議 (Learning Tips):**
- 多練習各種助數詞的讀法
- 特別注意發音變化的規則
- 記住「つ」和「にん」的特殊讀法
- 根據物品的形狀、性質選擇適當的助數詞
- 多做實際應用練習，熟悉助數詞的使用
