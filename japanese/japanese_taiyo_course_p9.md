# 「どこですか」＋「何／なん」＋「どうですか／いかがですか」完整解說
零基礎友好版：詳細說明 + 實用例子 + 常見錯誤提醒

────────────────────────────────

## 📚 零基礎入門：什麼是疑問詞？

### 💡 疑問詞 = 問問題的關鍵字

**疑問詞就是用來問問題的關鍵字。**

想像一下：
- **中文**：這是**什麼**？→ 「什麼」是疑問詞
- **日文**：これは**何**ですか。→ 「何」是疑問詞
  - kore wa nan desu ka.

**為什麼要學疑問詞？**
✅ 日常對話中，問問題是基本技能  
✅ 在商店、餐廳、學校等場合，經常需要問問題  
✅ 掌握疑問詞，就能問出各種問題  

**日語常見疑問詞：**
- **だれ**：誰
- **どこ**：哪裡
- **何**：什麼
- **いつ**：什麼時候
- **いくら**：多少錢
- **どう**：怎麼樣

| 想問的資訊 | 疑問詞 | 記憶口訣 |

### 1.1 人：だれ／どなた

**基本規則：**
- **だれ**：誰（普通，朋友、同事）
- **どなた**：哪位（比較客氣，對長輩、客人）

**實用例句：**

**一般場合（だれ）：**
```
あの人はだれですか。
ano hito wa dare desu ka.
那個人是誰？
```

**禮貌場合（どなた）：**
```
あの方はどなたですか。
ano kata wa donata desu ka.
那位是誰呢？（較禮貌）
```

**單字解說：**
- **あの** (ano)
  - 詞性：連體詞（指示詞）
  - 意思：那個（遠稱）
  - 用法：修飾名詞，表示距離說話者和聽話者都較遠的事物
  - 注意：不能單獨使用，必須接名詞
  - 例：あの本（那本書）、あの人（那個人）

- **方** (kata)
  - 詞性：名詞
  - 意思：人、位（敬語形式）
  - 用法：比「人」(hito) 更禮貌的說法，用於指稱他人
  - 注意：這是「人」的敬語形式，表示尊重
  - 例：この方（這位）、あの方（那位）

- **は** (wa)
  - 詞性：助詞（主題標記）
  - 意思：表示句子的主題或主語
  - 用法：雖然寫作「は」，但讀作「wa」
  - 注意：用於提示主題，不是表示動作的對象

- **どなた** (donata)
  - 詞性：疑問詞（敬語形式）
  - 意思：誰（禮貌的說法）
  - 用法：比「だれ」(dare) 更禮貌的疑問詞
  - 注意：用於詢問他人身份時的禮貌表達
  - 例：どなたですか（請問是哪位？）

- **です** (desu)
  - 詞性：判斷助動詞（敬體）
  - 意思：是（表示斷定）
  - 用法：接在名詞、形容詞後面，構成敬體判斷句

- **か** (ka)
  - 詞性：終助詞
  - 意思：表示疑問
  - 用法：放在句尾，將陳述句變成疑問句

**文法解說：**

**句型：あの + 名詞 + は + 疑問詞 + ですか**
- **結構**：あの + 名詞 + は + 疑問詞 + ですか
- **意思**：那個...是誰？
- **用法**：用於詢問遠處的人的身份

**本句分析：**
- **あの**（連體詞）→ 修飾「方」，表示「那個」
- **方**（名詞）→ 人（敬語形式）
- **は**（助詞）→ 提示主題
- **どなた**（疑問詞）→ 誰（敬語形式）
- **です**（判斷助動詞）→ 表示斷定
- **か**（終助詞）→ 表示疑問
- **整體意思**：那位是誰呢？（禮貌的說法）

**重要文法點：**

1. **「あの」vs「この」「その」**：
   - この (kono)：這個（近稱，靠近說話者）
   - その (sono)：那個（中稱，靠近聽話者）
   - あの (ano)：那個（遠稱，距離雙方都遠）

2. **「方」vs「人」**：
   - 人 (hito)：人（一般說法）
   - 方 (kata)：人（敬語，更禮貌）
   - 使用「方」表示對所指對象的尊重

3. **「どなた」vs「だれ」**：
   - だれ (dare)：誰（一般說法）
   - どなた (donata)：誰（敬語，更禮貌）
   - 使用「どなた」表示禮貌和尊重

4. **敬語的使用場合**：
   - 對長輩、上司、客戶等使用
   - 正式場合、商務場合
   - 表示對他人的尊重

**相關例句：**
- あの方はどなたですか。→ 那位是誰呢？（禮貌）
- あの人はだれですか。→ 那個人是誰？（一般）
- この方はどなたですか。→ 這位是誰呢？（禮貌）
- その方はどなたですか。→ 那位是誰呢？（禮貌）

**禮貌程度比較：**
- あの人はだれですか。（一般）
- あの方はだれですか。（中等禮貌）
- あの方はどなたですか。（最禮貌）

**更多實用場景：**

**場景1：在聚會上**
```
A：あの人はだれですか。
   ano hito wa dare desu ka.
   那個人是誰？

B：田中さんです。
   Tanaka-san desu.
   是田中先生。
```

**場景2：在辦公室（禮貌）**
```
A：あの方はどなたですか。
   ano kata wa donata desu ka.
   那位是誰呢？

B：部長です。
   buchō desu.
   是部長。
```

**⚠️ 常見錯誤提醒：**
- ❌ 錯誤：對長輩用「だれ」
- ✅ 正確：對長輩、客人用「どなた」

### 1.2 地點：どこ／どちら

**基本規則：**
- **どこ**：哪裡（一般）
- **どちら**：哪一邊／哪裡（較客氣，也可以表示「哪一個」）

**實用例句：**

**一般場合（どこ）：**
```

A：トイレはどこですか。
   toire wa doko desu ka.
   廁所在哪裡？

B：あそこです。
   asoko desu.
   在那裡。

B：右です。
   migi desu.
   在右邊。

B：左です。
   hidari desu.
   在左邊。

B：2階です。
   ni-kai desu.
   在2樓。

B：駅の近くです。
   eki no chikaku desu.
   在車站附近。

B：まっすぐ行ってください。
   massugu itte kudasai.
   請直走。
```

**禮貌場合（どちら）：**
```
学校はどちらですか。
gakkō wa dochira desu ka.
學校在哪一邊？（較客氣）
```

**更多實用場景：**

**場景1：在車站問路**
```
A：すみません、トイレはどこですか。
   sumimasen, toire wa doko desu ka.
   不好意思，廁所在哪裡？

B：あそこです。
   asoko desu.
   在那裡。
```

**場景2：在商店問位置**
```
A：銀行はどちらですか。
   ginkō wa dochira desu ka.
   銀行在哪一邊？

B：まっすぐ行ってください。
   massugu itte kudasai.
   請直走。
```
   **單字解說：**
   - **まっすぐ** (massugu)
   - 詞性：副詞
   - 意思：筆直地、一直地、直接地
   - 用法：修飾動詞，表示方向或動作的方式
   - 例：まっすぐ進む（筆直前進）、まっすぐ見る（直視）

   - **行って** (itte)
   - 原形：**行く** (iku) - 去、前往
   - 詞性：動詞（五段動詞）
   - 活用：這是「行く」的**て形**（連用形 + て）
   - 注意：「行く」的て形是「行って」，不是「行いて」（特殊變化）

   - **ください** (kudasai)
   - 詞性：補助動詞（敬語表達）
   - 意思：請（做某事）
   - 用法：接在動詞て形後面，表示禮貌的請求或指示
   - 語感：比命令形更客氣，但比「～てくださいませんか」更直接

   **文法解說：**

   **句型：動詞て形 + ください**
   - **結構**：動詞て形 + ください
   - **意思**：請（做某事）
   - **用法**：用於禮貌地請求或指示對方做某事
   - **語調**：客氣但直接，常用於指示、請求

   **本句分析：**
   - **まっすぐ**（副詞）→ 修飾動詞「行って」
   - **行って**（動詞て形）→ 表示「去」的動作
   - **ください**（補助動詞）→ 表示禮貌的請求
   - **整體意思**：請筆直地走 / 請直走

   **相關例句：**
   - まっすぐ行ってください。→ 請直走。
   - 右に曲がってください。→ 請向右轉。
   - ここで待ってください。→ 請在這裡等。
   - ゆっくり話してください。→ 請慢慢說。

   **動詞「行く」的活用：**
   - 基本形：行く (iku)
   - ます形：行きます (ikimasu)
   - て形：行って (itte) ← 本句使用
   - ない形：行かない (ikanai)
   - た形：行った (itta)

**場景3：在咖啡廳**
```
A：コーヒーショップはどこですか。
   kōhī shoppu wa doko desu ka.
   咖啡廳在哪裡？

B：駅の近くです。
   eki no chikaku desu.
   在車站附近。
```

**單字解說：**
- **駅** (eki)
  - 詞性：名詞
  - 意思：車站、火車站
  - 用法：指鐵路、地鐵等交通設施的車站
  - 例：東京駅（東京車站）、駅前（車站前）

- **の** (no)
  - 詞性：格助詞（助詞）
  - 意思：表示所屬、位置關係、修飾關係
  - 用法：連接兩個名詞，前面的名詞修飾後面的名詞
  - 本句用法：表示「車站的」→ 修飾「近く」
  - 例：私の本（我的書）、学校の近く（學校附近）

- **近く** (chikaku)
  - 原形：**近い** (chikai) - 形容詞，意思是「近的」
  - 詞性：名詞（由形容詞詞幹 + く 轉化而來）
  - 意思：附近、近處
  - 用法：作為名詞使用，表示「附近」這個概念
  - 注意：形容詞「近い」的「近」+「く」=「近く」（名詞化）

- **です** (desu)
  - 詞性：判斷助動詞（敬體）
  - 意思：是（表示斷定、說明）
  - 用法：接在名詞、形容詞後面，構成敬體判斷句
  - 語感：禮貌、正式的語氣

**文法解說：**

**句型：名詞 + の + 名詞 + です**
- **結構**：名詞₁ + の + 名詞₂ + です
- **意思**：名詞₁ 的 名詞₂ / 在名詞₁ 的名詞₂
- **用法**：表示位置、所屬、修飾關係

**本句分析：**
- **駅**（名詞）→ 車站
- **の**（格助詞）→ 表示修飾關係
- **近く**（名詞）→ 附近
- **です**（判斷助動詞）→ 表示斷定
- **整體意思**：在車站附近 / 是車站附近

**重要文法點：**

1. **「の」的用法**：
   - 表示所屬：私の本（我的書）
   - 表示位置：駅の近く（車站附近）
   - 表示修飾：日本語の本（日語書）

2. **形容詞名詞化（～く）**：
   - 近い（形容詞）→ 近く（名詞）
   - 遠い（形容詞）→ 遠く（名詞）
   - 多く（形容詞「多い」的名詞化，但較少用）

3. **「です」的用法**：
   - 接名詞：学生です（是學生）
   - 接形容詞：近いです（很近）
   - 表示禮貌的斷定語氣

**相關例句：**
- 駅の近くです。→ 在車站附近。
- 学校の近くです。→ 在學校附近。
- 銀行の近くです。→ 在銀行附近。
- 駅の前です。→ 在車站前面。
- 駅の隣です。→ 在車站旁邊。

**位置相關表達：**
- 近く（附近）
- 前（前面）
- 後ろ（後面）
- 隣（旁邊）
- 中（裡面）
- 外（外面）

**場景4：二選一（どちら的特殊用法）**
```
A：コーヒーとお茶と、どちらがいいですか。
   kōhī to o-cha to, dochira ga ii desu ka.
   咖啡和茶，你要哪一個呢？（比較客氣）

B：コーヒーがいいです。
   kōhī ga ii desu.
   我想要咖啡。
```

**單字解說：**
**A句（問句）：**
- **コーヒー** (kōhī)
  - 詞性：名詞
  - 意思：咖啡
  - 來源：外來語（來自英語 "coffee"）
  - 用法：直接使用，不需要敬語前綴

- **と** (to)
  - 詞性：助詞（並列助詞）
  - 意思：和、與
  - 用法：連接兩個或多個名詞，表示並列關係
  - 注意：每個名詞後面都要加「と」（最後一個可以省略）
  - 例：りんごとバナナ（蘋果和香蕉）

- **お茶** (o-cha)
  - 詞性：名詞
  - 意思：茶
  - 構成：お（敬語前綴）+ 茶（cha）
  - 用法：「お」是美化語前綴，使表達更禮貌
  - 注意：這是固定搭配，不能說「茶」或「お茶茶」

- **どちら** (dochira)
  - 詞性：疑問詞
  - 意思：哪一個（二選一）、哪一邊
  - 用法：用於從兩個選項中選擇一個
  - 注意：比「どれ」更客氣，適合正式場合
  - 例：AとB、どちらがいいですか（A和B，哪一個好？）

- **が** (ga)
  - 詞性：助詞（主格助詞）
  - 意思：表示主語
  - 用法：在疑問句中，表示被選擇的對象
  - 注意：在「どちらがいいですか」中，「が」表示選擇的主語

- **いい** (ii)
  - 詞性：形容詞
  - 意思：好的、可以的、想要的
  - 用法：在選擇句中表示「想要」「喜歡」「可以」
  - 注意：也可以說「良い」(yoi)，但「いい」更常用
  - 例：これがいいです（這個好/我要這個）

- **です** (desu)
  - 詞性：判斷助動詞（敬體）
  - 意思：是（表示斷定）
  - 用法：接在名詞、形容詞後面，構成敬體判斷句

- **か** (ka)
  - 詞性：終助詞
  - 意思：表示疑問
  - 用法：放在句尾，將陳述句變成疑問句

**B句（答句）：**
- **コーヒーがいいです** 中的單字與A句相同，不再重複說明

**文法解說：**

**句型1：名詞₁ + と + 名詞₂ + と、どちらがいいですか**
- **結構**：名詞₁ + と + 名詞₂ + と、どちら + が + いい + です + か
- **意思**：名詞₁和名詞₂，你要哪一個？
- **用法**：用於提供兩個選項讓對方選擇
- **語感**：客氣、禮貌，適合餐廳、商店等場合

**句型2：名詞 + が + いいです**
- **結構**：名詞 + が + いい + です
- **意思**：我要名詞 / 名詞比較好
- **用法**：表示選擇或偏好
- **語感**：禮貌地表達自己的選擇

**本句分析：**

**A句結構：**
- **コーヒーとお茶と** → 並列結構，列出兩個選項
- **どちら** → 疑問詞，詢問選擇
- **が** → 主格助詞，表示被選擇的主語
- **いいですか** → 詢問對方想要哪一個
- **整體意思**：咖啡和茶，你要哪一個呢？

**B句結構：**
- **コーヒー** → 選擇的對象
- **が** → 主格助詞，表示選擇的主語
- **いいです** → 表示選擇或偏好
- **整體意思**：我想要咖啡 / 咖啡比較好

**重要文法點：**

1. **「と」的並列用法**：
   - 基本形式：AとB（A和B）
   - 多個並列：AとBとC（A、B和C）
   - 最後的「と」可以省略：AとB（A和B）
   - 本句：コーヒーとお茶と（咖啡和茶）

2. **「どちら」vs「どれ」**：
   - どれ (dore)：哪一個（從多個選項中選擇，一般說法）
   - どちら (dochira)：哪一個（從兩個選項中選擇，較客氣）
   - 使用場合：餐廳、商店等正式場合用「どちら」

3. **「が」在選擇句中的用法**：
   - 在疑問句中：どちらがいいですか（哪一個好？）
   - 在答句中：コーヒーがいいです（咖啡好/我要咖啡）
   - 「が」表示被選擇的主語

4. **「いい」的用法**：
   - 基本意思：好的、可以的
   - 在選擇句中：表示「想要」「喜歡」「可以」
   - 例：これがいいです（我要這個）

5. **「お」前綴（美化語）**：
   - お茶 (o-cha)：茶
   - お水 (o-mizu)：水
   - お酒 (o-sake)：酒
   - 用法：使表達更禮貌、優雅

**相關例句：**
- コーヒーとお茶と、どちらがいいですか。→ 咖啡和茶，你要哪一個？
- コーヒーがいいです。→ 我想要咖啡。
- りんごとバナナと、どちらがいいですか。→ 蘋果和香蕉，你要哪一個？
- りんごがいいです。→ 我想要蘋果。
- 赤と青と、どちらがいいですか。→ 紅色和藍色，你要哪一個？
- 赤がいいです。→ 我想要紅色。

**使用場合：**
- 餐廳點餐
- 商店購物
- 選擇顏色、大小等
- 任何需要二選一的場合

**💡 補充說明：**
- 「どちら」除了問地點，也可以用在「二選一」的情況
- 比「どれ」更客氣，適合在餐廳、商店等場合使用
- 連結前一課的「AかBか」邏輯：二選一時用「どちら」

### 1.3 物品：どれ／どの

**基本規則：**
- **どれ**：哪一個（在三個以上中，單獨指物）
- **どの＋名詞**：哪一個～（後面一定要接名詞）

**實用例句：**

**どれ（單獨使用）：**
```
日本語のCDはどれですか。
Nihongo no shīdī wa dore desu ka.
哪一片是日文 CD？
```

**どの（+名詞）：**
```
どのかばんが田中さんのですか。
dono kaban ga Tanaka-san no desu ka.
哪一個包包是田中先生的？
```

**為什麼這裡使用「が」？**
- **疑問詞作主語時使用「が」**：本句中「どのかばん」（哪一個包包）是疑問詞作主語，所以必須使用「が」而不是「は」
- **「が」vs「は」的區別**：
  - 疑問詞作主語 → 用「が」：どのかばん**が**田中さんのですか
  - 疑問詞作謂語 → 用「は」：このかばん**は**どのかばんですか
- **記憶要點**：疑問詞是「未知」的，作為主語時用「が」；「は」用於提示已知的主題

**更多實用場景：**

**場景1：在書店**
```
A：日本語の本はどれですか。
   Nihongo no hon wa dore desu ka.
   日語書是哪一本？

B：これです。
   kore desu.
   是這本。
```

**場景2：在餐廳**
```
A：どのかさが佐藤さんのですか。
   dono kasa ga Satō-san no desu ka.
   哪一把傘是佐藤先生的？

B：あの青いかさです。
   ano aoi kasa desu.
   那把藍色的傘。
```

**⚠️ 常見錯誤提醒：**
- ❌ 錯誤：どれかばん（どれ後面不能接名詞）
- ✅ 正確：どのかばん（どの後面要接名詞）

### 1.4 狀態／感想：どう・どうですか・いかがですか

**基本規則：**
- **どう**：如何、怎麼樣（問方法／狀態）
- **どうですか**：覺得怎麼樣？（一般）
- **いかがですか**：比「どうですか」更客氣的說法（對上司、客人）

**實用例句：**

**一般場合（どうですか）：**
```
日本の生活はどうですか。
Nihon no seikatsu wa dō desu ka.
在日本的生活怎麼樣？
```

**禮貌場合（いかがですか）：**
```
日本の生活はいかがですか。
Nihon no seikatsu wa ikaga desu ka.
在日本的生活如何呢？（對老師或上司）
```

**更多實用場景：**

**場景1：詢問食物**
```
A：このラーメンはどうですか。
   kono rāmen wa dō desu ka.
   這碗拉麵怎麼樣？

B：とてもおいしいです。
   totemo oishii desu.
   非常好吃。
```

**場景2：詢問工作（禮貌）**
```
A：新しい仕事はいかがですか。
   atarashii shigoto wa ikaga desu ka.
   新工作如何呢？

B：とても楽しいです。
   totemo tanoshii desu.
   非常愉快。
```

**場景3：詢問學習**
```
A：日本語の勉強はどうですか。
   Nihongo no benkyō wa dō desu ka.
   日語學習怎麼樣？

B：少し難しいですが、おもしろいです。
   sukoshi muzukashii desu ga, omoshiroi desu.
   有點難，但很有趣。
```

### 1.5 原因：どうして・なぜ

**基本規則：**
- **どうして**：為什麼（比較口語、情緒感一點，帶「怎麼會這樣？」的味道）
- **なぜ**：為什麼（稍微中性、冷靜一點，在書面和口語都常用）

**實用例句：**

**口語（どうして）：**
```
どうして遅れましたか。
dōshite okuremashita ka.
為什麼遲到了？
（帶點情緒：「怎麼會遲到？」）
```

**中性／正式（なぜ）：**
```
なぜ会社をやめたんですか。
naze kaisha o yametan desu ka.
為什麼辭職呢？
（比較中性、冷靜的詢問）
```

**語感對比：**
```
どうしてそんなことを言うんですか。
dōshite sonna koto o iu n desu ka.
你怎麼會說這種話？（帶點情緒）

なぜそんなことを言うんですか。
naze sonna koto o iu n desu ka.
為什麼這麼說？（比較中性）
```

**單字解說：**

**句子1：どうしてそんなことを言うんですか**

- **どうして** (dōshite)
  - 詞性：疑問副詞
  - 意思：為什麼、怎麼會
  - 用法：詢問原因或理由，帶有情感色彩
  - 語感：較口語化，可能帶有驚訝、不滿、困惑等情緒
  - 例：どうして遅れたんですか（為什麼遲到了？）

- **そんな** (sonna)
  - 詞性：連體詞（指示詞）
  - 意思：那樣的、那種的
  - 用法：修飾名詞，表示距離較遠或指代前面提到的內容
  - 注意：不能單獨使用，必須接名詞
  - 例：そんなこと（那種事）、そんな人（那種人）

- **こと** (koto)
  - 詞性：名詞
  - 意思：事情、事、內容
  - 用法：指抽象的事物、內容、行為
  - 注意：與「もの」（東西、物品）相對，「こと」指抽象概念
  - 例：そんなこと（那種事）、いいこと（好事）

- **を** (o)
  - 詞性：助詞（賓格助詞）
  - 意思：表示動作的對象
  - 用法：接在名詞後面，表示動詞的賓語
  - 注意：雖然寫作「を」，但讀作「o」
  - 例：本を読む（讀書）、コーヒーを飲む（喝咖啡）

- **言う** (iu)
  - 詞性：動詞（五段動詞）
  - 意思：說、講、告訴
  - 活用：基本形「言う」，ます形「言います」，て形「言って」
  - 用法：表示說話、表達意見
  - 例：真実を言う（說實話）、名前を言う（說名字）

- **ん** (n)
  - 詞性：助詞（「の」的口語形式）
  - 意思：表示說明、解釋
  - 用法：接在動詞、形容詞後面，用於說明原因、理由
  - 注意：這是「の」的口語形式，在「です」「だ」前面時變成「ん」
  - 例：行くんです（要去）、高いんです（很貴）

- **です** (desu)
  - 詞性：判斷助動詞（敬體）
  - 意思：是（表示斷定）
  - 用法：接在名詞、形容詞後面，構成敬體判斷句

- **か** (ka)
  - 詞性：終助詞
  - 意思：表示疑問
  - 用法：放在句尾，將陳述句變成疑問句

**句子2：なぜそんなことを言うんですか**

- **なぜ** (naze)
  - 詞性：疑問副詞
  - 意思：為什麼
  - 用法：詢問原因或理由，較正式、中性
  - 語感：較正式、冷靜，不帶強烈情緒
  - 例：なぜ遅れたんですか（為什麼遲到了？）

- 其他單字與句子1相同，不再重複說明

**文法解說：**

**句型：疑問詞 + そんな + こと + を + 動詞 + ん + です + か**
- **結構**：疑問詞（どうして/なぜ）+ そんなこと + を + 動詞 + ん + です + か
- **意思**：為什麼會說那種話？
- **用法**：詢問對方說某種話的原因，可能帶有驚訝、不滿等情緒

**本句分析：**

**句子1：どうしてそんなことを言うんですか**
- **どうして**（疑問副詞）→ 為什麼（帶情緒）
- **そんなこと**（名詞）→ 那種事
- **を**（賓格助詞）→ 表示動作對象
- **言う**（動詞）→ 說
- **ん**（助詞）→ 表示說明
- **です**（判斷助動詞）→ 敬體
- **か**（終助詞）→ 表示疑問
- **整體意思**：你怎麼會說這種話？（帶點情緒）

**句子2：なぜそんなことを言うんですか**
- **なぜ**（疑問副詞）→ 為什麼（中性）
- 其他結構與句子1相同
- **整體意思**：為什麼這麼說？（比較中性）

**重要文法點：**

1. **「どうして」vs「なぜ」的區別**：
   - **どうして** (dōshite)：
     - 較口語化
     - 可能帶有驚訝、不滿、困惑等情緒
     - 適合日常對話
     - 例：どうしてそんなことをしたんですか（你怎麼會做那種事？）
   
   - **なぜ** (naze)：
     - 較正式、中性
     - 冷靜地詢問原因
     - 適合正式場合、書面語
     - 例：なぜ遅れたんですか（為什麼遲到了？）

2. **「そんな」的用法**：
   - そんな + 名詞：那樣的名詞
   - 表示距離較遠或指代前面提到的內容
   - 例：そんなこと（那種事）、そんな人（那種人）

3. **「こと」vs「もの」**：
   - こと：抽象的事情、內容、行為
   - もの：具體的物品、東西
   - 例：そんなこと（那種事）vs そんなもの（那種東西）

4. **「～んです」的用法**：
   - 動詞/形容詞 + んです（= の的口語形式）
   - 表示說明、解釋原因或理由
   - 例：言うんです（要說）、高いんです（很貴）

5. **「を」的用法**：
   - 表示動作的對象（賓語）
   - 接在名詞後面
   - 例：こと + を + 言う（說事情）

**相關例句：**
- どうしてそんなことを言うんですか。→ 你怎麼會說這種話？（帶情緒）
- なぜそんなことを言うんですか。→ 為什麼這麼說？（中性）
- どうして遅れたんですか。→ 為什麼遲到了？（帶情緒）
- なぜ遅れたんですか。→ 為什麼遲到了？（中性）
- どうしてそんなことをしたんですか。→ 你怎麼會做那種事？（帶情緒）
- なぜそんなことをしたんですか。→ 為什麼做那種事？（中性）

**使用場合：**
- **どうして**：日常對話、表達驚訝或不滿時
- **なぜ**：正式場合、冷靜詢問原因時、書面語

**更多實用場景：**

**場景1：詢問遲到原因**
```
A：どうして遅れましたか。
   dōshite okuremashita ka.
   為什麼遲到了？

B：電車が遅れました。
   densha ga okuremashita.
   電車延誤了。
```

**為什麼這裡使用「が」？**
- **新信息的主語使用「が」**：本句中「電車」是回答問題時提供的新信息（說明遲到的原因），所以使用「が」而不是「は」
- **「が」vs「は」的區別**：
  - 新信息的主語 → 用「が」：電車**が**遅れました（電車延誤了）
  - 已知的主題 → 用「は」：電車**は**遅れました（電車延誤了，但可能是在談論已知的電車）
- **記憶要點**：回答「為什麼」時，說明原因的主語通常用「が」；「は」用於提示已知的主題

**場景2：詢問選擇原因**
```
A：どうして日本語を勉強しますか。
   dōshite Nihongo o benkyō shimasu ka.
   為什麼學日語？

B：日本へ行きたいからです。
   Nihon e ikitai kara desu.
   因為想去日本。
```

**單字解說：**
- **日本** (Nihon)
  - 詞性：名詞
  - 意思：日本
  - 用法：國家名稱
  - 注意：也可以讀作「にっぽん」(Nippon)，但「にほん」(Nihon) 更常用

- **へ** (e)
  - 詞性：助詞（方向助詞）
  - 意思：往、向、到
  - 用法：表示移動的方向或目的地
  - 注意：雖然寫作「へ」，但在現代日語中通常讀作「e」
  - 例：日本へ行く（去日本）、学校へ行く（去學校）

- **行きたい** (ikitai)
  - 原形：**行く** (iku) - 去、前往
  - 詞性：動詞（五段動詞）+ 助動詞「たい」
  - 意思：想去
  - 構成：行く（去）+ たい（想要）= 行きたい（想去）
  - 用法：表示願望、想要做某事
  - 注意：「たい」接在動詞ます形（去掉ます）後面
  - 例：食べたい（想吃）、飲みたい（想喝）

- **から** (kara)
  - 詞性：助詞（接續助詞）
  - 意思：因為、由於
  - 用法：表示原因、理由，接在句子後面
  - 注意：可以接在動詞、形容詞、名詞後面
  - 例：暑いから（因為熱）、時間がないから（因為沒時間）

- **です** (desu)
  - 詞性：判斷助動詞（敬體）
  - 意思：是（表示斷定）
  - 用法：接在名詞、形容詞後面，構成敬體判斷句
  - 本句用法：接在「から」後面，使表達更禮貌

**文法解說：**

**句型：名詞 + へ + 動詞たい形 + から + です**
- **結構**：名詞 + へ + 動詞たい形 + から + です
- **意思**：因為想去名詞（的地方）
- **用法**：用於說明原因或理由，表示「因為想要做某事」

**本句分析：**
- **日本**（名詞）→ 目的地
- **へ**（方向助詞）→ 表示移動方向
- **行きたい**（動詞たい形）→ 想去
- **から**（接續助詞）→ 表示原因
- **です**（判斷助動詞）→ 使表達更禮貌
- **整體意思**：因為想去日本

**重要文法點：**

1. **「へ」vs「に」的區別**：
   - **へ** (e)：強調移動的方向、過程
   - **に** (ni)：強調移動的目的地、到達點
   - 本句：日本へ行きたい（強調「往日本的方向」）
   - 也可以說：日本に行きたい（強調「到達日本」）
   - 兩者在很多情況下可以互換

2. **「～たい」的用法**：
   - 接續：動詞ます形（去掉ます）+ たい
   - 意思：想要做某事
   - 活用：行きたい（想去）、行きたくない（不想去）、行きたかった（想去過）
   - 注意：主語通常是第一人稱（我），或詢問第二人稱（你）

3. **「から」表示原因**：
   - 基本用法：句子 + から
   - 意思：因為...
   - 語感：較主觀，表示說話者的理由或判斷
   - 例：暑いから（因為熱）、行きたいから（因為想去）

4. **「～からです」的用法**：
   - 結構：句子 + から + です
   - 意思：因為...（禮貌說法）
   - 用法：回答「どうして」「なぜ」等疑問詞時使用
   - 例：どうして日本語を勉強しますか。→ 日本へ行きたいからです。

5. **「へ」的讀音**：
   - 寫法：へ
   - 讀音：現代日語中通常讀作「e」，而不是「he」
   - 例：日本へ (Nihon e)、学校へ (gakkō e)

**相關例句：**
- 日本へ行きたいからです。→ 因為想去日本。
- アメリカへ行きたいからです。→ 因為想去美國。
- 学校へ行きたいからです。→ 因為想去學校。
- どうして日本語を勉強しますか。→ 為什麼學日語？
  - 日本へ行きたいからです。→ 因為想去日本。
- どうして英語を勉強しますか。→ 為什麼學英語？
  - アメリカへ行きたいからです。→ 因為想去美國。

**使用場合：**
- 回答「為什麼」的問題
- 說明學習、選擇的原因
- 表達願望和理由

### 1.6 內容：何・何の

**基本規則：**
- **何（なに）**：什麼（一般情況）
- **何の**：什麼樣的～／哪一種的～（問種類）

**實用例句：**

**何（一般）：**
```
これは何ですか。
kore wa nan desu ka.
這是什麼？
```

**何の（問種類）：**
```
それは何のざっしですか。
sore wa nan no zasshi desu ka.
那是什麼雜誌？（比方：漫畫雜誌？學術雜誌？）
```

**更多實用場景：**

**場景1：在商店**
```
A：これは何ですか。
   kore wa nan desu ka.
   這是什麼？

B：日本のおかしです。
   Nihon no okashi desu.
   是日本的點心。
```

**場景2：在書店**
```
A：これは何の本ですか。
   kore wa nan no hon desu ka.
   這是什麼樣的書？

B：日本語の参考書です。
   Nihongo no sankōsho desu.
   是日語參考書。
```

**場景3：在餐廳**
```
A：これは何の料理ですか。
   kore wa nan no ryōri desu ka.
   這是什麼料理？

B：日本のカレーです。
```

## 2️⃣ 課本會話例句逐句解說

### 2.1 例①：それは何のざっしですか。

**對話：**

```
A：それは　何の　ざっし　ですか。
   sore wa nan no zasshi desu ka.
   那是什麼雜誌呢？（什麼類型的雜誌？）

B：漢字の　ざっし　です。
   kanji no zasshi desu.
   是「漢字」的雜誌。（專門談漢字的雜誌）
```

**語法重點：**
- **何の＋名詞**：問「性質／種類／主題／用途」
  - 何のざっし → 什麼雜誌（漫畫雜誌？新聞雜誌？）
  - 何のえいが → 什麼電影（例如：戰爭片？愛情片？）
  - 何の本 → 關於什麼的書（主題）
  - 何のアプリ → 做什麼用的 APP（用途）

**對比例句：**

**問「是什麼」：**
```
これは何ですか。
kore wa nan desu ka.
這是什麼？（單純不知道是什麼東西）
```

**問「是什麼種類」：**
```
これは何の本ですか。
kore wa nan no hon desu ka.
這是什麼樣的書？（問種類：日文參考書？小說？漫畫？）
```

**更多實用例子：**

**場景1：在書店**
```
A：これは何の本ですか。
   kore wa nan no hon desu ka.
   這是什麼樣的書？

B：日本語の参考書です。
   Nihongo no sankōsho desu.
   是日語參考書。
```

**場景2：在電影院**
```
A：これは何の映画ですか。
   kore wa nan no eiga desu ka.
   這是什麼電影？

B：アクション映画です。
   akushon eiga desu.
   是動作片。
```

### 2.2 例②：テストはいつですか。

**對話：**


**語法重點：**
- 問「日期／時候」用 **いつ**

**對比例句：**

```
   是這週六。
```

## 3️⃣ 「やってみよう１」：填入正確的疑問詞

### 3.1 例題

**題目：**
```
A：それは（　何　）ですか。
B：これは　日本の　おかしです。
```

**【解答】**
```
A：それは何ですか。
B：これは日本のおかしです。
```

**說明：**
- 問「那是什麼？」→ 用 **何**
- 回答「這是日本的點心。」

---

### 3.2 題目 1

**題目：**
```
A：日本語の　CDは（　　　　）ですか。
B：これです。
```

**【解答】**
```
A：日本語の　CDはどれですか。
B：これです。
```

**說明：**
- 有好幾片 CD，其中只有一片是「日文 CD」
- 問「哪一個是～？」→ 用 **どれ**（單獨指物）
- 不能用「何」，因為不是問「那是什麼」，而是「哪一個」

**⚠️ 常見錯誤提醒：**
- ❌ 錯誤：日本語のCDは何ですか。（問「是什麼」）
- ✅ 正確：日本語のCDはどれですか。（問「哪一個」）

---

### 3.3 題目 2

**題目：**
```
A：入試（にゅうし）は（　　　　）ですか。
B：８時（はちじ）です。
```

**【解答】**
```
A：入試は何時（なんじ）ですか。
B：８時です。
```

**說明：**
- 問具體「幾點」的時間，用「何時（なんじ）」
- 「いつ」問的是「什麼時候」（可能是哪一天、哪個時段）
- 在本題裡，我們要問的是「幾點開始」，所以用「何時（なんじ）」比較精確

**語感差異對比：**

**問「什麼時候」（哪一天／時段）：**
```
入試はいつですか。→ 来週の水曜日です。
考試是什麼時候？→ 下週三。
（問的是「哪一天舉行」，回答可能是日期或星期）
```

**問「幾點」（具體時間）：**
```
入試は何時ですか。→ ８時です。
考試幾點開始？→ 8點。
（問的是「具體幾點」，回答是具體時間）
```

**💡 實際使用：**
- 「入試はいつですか」在日常會話裡也很自然，通常對方會回答「◯月◯日」或「来週の水曜日」，也可能包含時間
- 「入試は何時ですか」則比較明確是在問「幾點開始」
- 本題因為回答是「８時」，所以用「何時」更精確

---

### 3.4 題目 3

**題目：**
```
A：にぎやかな町ですね。（　　　　）町ですか。
B：東京です。
```

**【解答】**
```

```

**說明：**
- 「どこの＋名詞」：問「哪裡的～」

- 這裡說「是很熱鬧的城市呢，是哪裡的城市？」→ 回答：東京

## 4️⃣ 「何」的兩種讀音：なに vs なん

### 📌 重要規則（零基礎必看！）

**「何」有兩種讀音：**
- **なに**：一般情況
- **なん**：後面接量詞或 n/t/d 開頭的字

### 4.1 一般情況：念「なに」

**直接問「這是什麼？」、「你在做什麼？」的 **何**，通常唸「なに」。**

**例句：**

```
これは何（なに）ですか。
kore wa nani desu ka.
這是什麼？

何（なに）をしますか。
nani o shimasu ka.
你要做什麼？
```

**💡 實際使用補充：**
- 口語裡，「これはなんですか」和「これはなにですか」都可以聽到
- 在「です」「だ」「ですか」前面，多數人會說「なん」：
  - これはなんですか。（實際發音）
- 在本課中，我們只要記住：
  - 一般情況說「なに」
  - 後面接數量詞或 n/t/d 開頭時多半讀「なん」
- 就足夠應付初級程度

**更多例子：**

```
A：これは何ですか。
   kore wa nan desu ka.
   這是什麼？

B：本です。
   hon desu.
   是書。
```

---

### 4.2 後面接「量詞／數量詞」：念「なん」

**後面跟「人、時、回、月、年」等「數量詞」時，多半唸「なん」。**

**常見組合：**
- 何人 → なんにん（幾個人）
- 何時 → なんじ（幾點）
- 何回 → なんかい（幾次）
- 何月 → なんがつ（幾月）
- 何年 → なんねん（哪一年）

**例句：**

```
クラスに学生は何人いますか。
kurasu ni gakusei wa nan-nin imasu ka.
班上有幾個學生？

今は何時ですか。
ima wa nan-ji desu ka.
現在幾點？

日本へ行くのは何月ですか。
Nihon e iku no wa nan-gatsu desu ka.
去日本是幾月？
```

**更多實用例子：**

**場景1：問時間**
```
A：今は何時ですか。
   ima wa nan-ji desu ka.
   現在幾點？

B：３時です。
   san-ji desu.
   是3點。
```

**場景2：問人數**
```
A：パーティーには何人来ますか。
   pātī ni wa nan-nin kimasu ka.
   派對會來幾個人？

B：１０人です。
   jū-nin desu.
   是10個人。
```

---

### 4.3 後面接 n/t/d 開頭的字：多半唸「なん」

**後面接 n/t/d 開頭的字時，多半唸「なん」。**

**常見組合：**
- 何度 → なんど（幾次／多少度數）
- 何日 → なんにち（幾號／幾天）
- 何点 → なんてん（幾分／幾點）

**例句：**

```
きょうは何度ですか。
kyō wa nan-do desu ka.
今天多少度？

試験は何日ですか。
shiken wa nan-nichi desu ka.
考試是幾號？
```

**更多實用例子：**

**場景1：問溫度**
```
A：きょうは何度ですか。
   kyō wa nan-do desu ka.
   今天多少度？

B：２５度です。
   nijūgo-do desu.
   是25度。
```

**場景2：問日期**
```
A：誕生日は何日ですか。
   tanjōbi wa nan-nichi desu ka.
   生日是幾號？

B：15日です。
   jūgo-nichi desu.
   是15號。
```

### 💡 記憶技巧

**口訣：**
- **一般情況** → なに（這是什麼？）
- **數量詞** → なん（幾個人？幾點？）
- **n/t/d開頭** → なん（幾度？幾號？）

**快速判斷：**
1. 後面有「人、時、回、月、年」→ なん
2. 後面是 n/t/d 開頭 → なん
3. 其他情況 → なに

## 5️⃣ 疑問詞句裡的「は」和「が」

### 📌 重要規則（零基礎必看！）

**疑問詞的位置決定用「は」還是「が」：**
- 疑問詞在 **主題位置（話題）** 時 → 用 **は**
- 疑問詞在 **主語位置** 時 → 用 **が**
- 問題句用哪個助詞，回答句一般就跟著用哪個

### 5.1 型①：N は だれですか。

**對話：**

```
A：あの人は　だれですか。
   ano hito wa dare desu ka.
   那個人是誰？

B：あの人は　橋本さんです。
   ano hito wa Hashimoto-san desu.
   那個人是橋本先生。
```

**語法重點：**
- 問：**「那個人」是誰？**
  - 話題是「あの人」，所以用「は」
- 回答也用「は」：
  - あの人は橋本さんです

**句型：**
- A：N は　疑問詞　ですか
- B：N は　～です

**更多例子：**

```
A：この町はどこですか。
   kono machi wa doko desu ka.
   這個城市是在哪裡？

B：この町は大阪です。
   kono machi wa Ōsaka desu.
   這個城市是大阪。
```

**實用場景：**

**場景1：問人**
```
A：あの人はだれですか。
   ano hito wa dare desu ka.
   那個人是誰？

B：田中さんです。
   Tanaka-san desu.
   是田中先生。
```

**場景2：問地點**
```
A：学校はどこですか。
   gakkō wa doko desu ka.
   學校在哪裡？

B：駅の近くです。
   eki no chikaku desu.
   在車站附近。
```

---

### 5.2 型②：どの人が田中さんですか。

**對話：**

```
A：どの人が　田中さんですか。
   dono hito ga Tanaka-san desu ka.
   哪一個人是田中先生？

B：あの人が　田中さんです。
   ano hito ga Tanaka-san desu.
   那個人是田中先生。
```

**語法重點：**
- 問：**哪一個人是田中先生？**
  - 這裡真正在問的是「誰是田中」，所以「どの人」是主語 → 用 **が**
- 回答也用「が」對應：
  - あの人が田中さんです

**句型：**
- A：疑問詞 ＋ が　～ですか
- B：～が　～です

**更多例子：**

```
A：どのかばんが山田さんのですか。
   dono kaban ga Yamada-san no desu ka.
   哪一個包包是山田先生的？

B：その青いかばんが山田さんのです。
   sono aoi kaban ga Yamada-san no desu.
   那個藍色的包包是山田先生的。
```

**實用場景：**

**場景1：問物品**
```
A：どれがあなたの本ですか。
   dore ga anata no hon desu ka.
   哪一本是你的書？

B：これが私の本です。
   kore ga watashi no hon desu.
   這本是我的書。
```

**場景2：問人**
```
A：だれがパーティーに行きますか。
   dare ga pātī ni ikimasu ka.
   誰會去派對？

B：田中さんが行きます。
   Tanaka-san ga ikimasu.
   田中先生會去。
```

### 💡 記憶技巧

**口訣：**
- **問「N是～？」** → N は 疑問詞ですか（用は）
- **問「哪個是～？」** → 疑問詞が ～ですか（用が）

**對比：**
- あの人はだれですか。→ 那個人是誰？（主題已知，用は）
- だれが行きますか。→ 誰會去？（主語未知，用が）

---

### 🧠 超簡單記憶圖（一眼看懂版）

**問「那個人是誰？」→ 主題已知（那個人），問補充資訊 → 用「は」**
```
あの人はだれですか。
ano hito wa dare desu ka.
那個人是誰？

→ あの人は田中さんです。
   ano hito wa Tanaka-san desu.
   那個人是田中先生。
```

**問「誰會去？」→ 真正想知道的是「誰」，主語未知 → 用「が」**
```
だれが行きますか。
dare ga ikimasu ka.
誰會去？

→ 田中さんが行きます。
   Tanaka-san ga ikimasu.
   田中先生會去。
```

**簡單理解：**
- 已經知道「那個人」，只是不知道「是誰」→ 用は
- 不知道「誰」會去，想知道「誰」→ 用が

## 6️⃣ 「やってみよう！」：選「は」還是「が」

### 6.1 例題

**題目：**
```
これは（　は／が　）何ですか。
```

**【解答】**
```
これは何ですか。
```

**說明：**
- 主題是「これ」（這個）
- 問「這個是什麼？」→ **「これは何ですか。」** 是固定句型，可以直接整句記住

---

### 6.2 題目 1

**題目：**
```
A：このかさ（　は／が　）だれのですか。
B：佐藤さんのです。
```

**【解答】**
```
A：このかさはだれのですか。
B：佐藤さんのです。
```

**說明：**
- 話題是「這把傘」，在問「這把傘是誰的？」
- 因此用「は」
- 回答直接說「佐藤さんのです。」（= 佐藤先生的）

---

### 6.3 題目 2

**題目：**
```
A：それ（　は／が　）伊藤さんの　車ですか。
B：はい、伊藤さんの　車です。
```

**【解答】**
```
A：それは伊藤さんの車ですか。
B：はい、伊藤さんの車です。
```

**說明：**
- 話題是「それ」（那個東西）
- 問「那是伊藤先生的車嗎？」→ 用「は」
- 回答重複確認：「是的，是伊藤先生的車。」

---

### 6.4 題目 3

**題目：**
```
A：だれ（　は／が　）パーティーに　行きますか。
B：田中さんと　鈴木さん（　は／が　）行きます。
```

**【解答】**
```
A：だれがパーティーに行きますか。
B：田中さんと鈴木さんが行きます。
```

**說明：**
- 這句是真正問「**誰會去** 派對？」→ 主語未知 → 用 **が**
- 回答時，把「誰」換成實際的人名，也用 **が**：
  - 田中さんが行きます。→ 田中先生會去
  - 田中さんと鈴木さんが行きます。→ 田中和鈴木會去

**✅ 小結：**
- 問「誰是～？」時：あの人はだれですか。→ 主題已知 → 用 **は**
- 問「誰會～？」時：だれが行きますか。→ 主語未知 → 用 **が**

---

### 6.5 題目 4

**題目：**
```
A：鈴木さんの　勉強（　は／が　）どうですか。
B：とても　おもしろいです。
```

**【解答】**
```
A：鈴木さんの勉強はどうですか。
B：とてもおもしろいです。
```

**說明：**
- 問「**關於鈴木先生的學習情況**，感覺如何？」→ 把「鈴木さんの勉強」當主題
- 問感想／評價，多半用「～はどうですか。」→ 主題＋は

## 7️⃣ 「どうですか」vs「いかがですか」

### 7.1 禮貌地詢問狀態：いかがですか

**基本規則：**
- 想說得更有禮貌時，用 **「いかがですか」** 代替「どうですか」

**例句：**

```
A：日本の　生活は　いかがですか。
   Nihon no seikatsu wa ikaga desu ka.
   在日本的生活如何呢？

B：とても　楽しいです。
   totemo tanoshii desu.
   非常愉快。
```

**對比：**

**一般（どうですか）：**
```
日本の生活はどうですか。
Nihon no seikatsu wa dō desu ka.
在日本的生活怎麼樣？
```

**禮貌（いかがですか）：**
```
日本の生活はいかがですか。
Nihon no seikatsu wa ikaga desu ka.
在日本的生活如何呢？（對老師或上司）
```

**更多實用例子：**

**場景1：詢問工作**
```
A：仕事はどうですか。／仕事はいかがですか。
   shigoto wa dō desu ka. / shigoto wa ikaga desu ka.
   工作如何？

B：とても楽しいです。
   totemo tanoshii desu.
   非常愉快。
```

**場景2：詢問新居**
```
A：新しいアパートの住み心地はいかがですか。
   atarashii apāto no sumigokochi wa ikaga desu ka.
   新公寓住起來怎麼樣呢？

B：とても快適です。
   totemo kaiteki desu.
   非常舒適。
```

---

### 7.2 用「どうですか」來推薦／招待

**基本規則：**
- 「どうですか」也可以用來 **向對方提出建議或邀請**

**課本例句：**

```
A：お茶、どうですか／いかがですか。
   o-cha, dō desu ka / ikaga desu ka.
   要不要喝茶呢？

B：ありがとうございます。いただきます。
   arigatō gozaimasu. itadakimasu.
   謝謝。我就不客氣了。
```

**說明：**
- A 在「請你喝茶」：
  - 普通：お茶、どうですか
  - 較客氣：お茶、いかがですか
- B 的回答「いただきます」是比較客氣的「我就不客氣喝了」

**更多實用例子：**

**場景1：在咖啡廳**
```
A：コーヒーはどうですか。
   kōhī wa dō desu ka.
   要不要喝咖啡？

B：ありがとうございます。
   arigatō gozaimasu.
   謝謝。
```

**場景2：在餐廳**
```
A：もう一杯、いかがですか。
   mō ippai, ikaga desu ka.
   再來一杯如何呢？

B：いいえ、けっこうです。
   iie, kekkō desu.
   不用了，謝謝。
```

**場景3：推薦書籍**
```
A：この本、どうですか。よかったら読んでください。
   kono hon, dō desu ka. yokattara yonde kudasai.
   這本書怎麼樣？如果你有興趣可以看看。

B：ありがとうございます。読んでみます。
   arigatō gozaimasu. yonde mimasu.
   謝謝。我會看看。
```

**場景4：婉拒（禮貌回應）**
```
A：ケーキはいかがですか。
   kēki wa ikaga desu ka.
   要不要來點蛋糕呢？

B：ありがとうございます。でも、今はちょっと……。
   arigatō gozaimasu. demo, ima wa chotto...
   謝謝，不過現在有點……（含蓄地婉拒）
```

**💡 日文婉拒小技巧：**
- 日文裡經常用「今はちょっと……」（現在有點……）當作婉拒
- 不會直接說「不要」，而是用含蓄的方式表達
- 這是日文社交禮儀的重要一環

### ✅ 小結

- 問感想／狀態 → 「～はどうですか。／～はいかがですか。」
- 禮貌程度：いかがですか ＞ どうですか
- 提議或招待 → 「お茶、どうですか。」、「ケーキはいかがですか。」
