# 「どこですか」＋「何／なん」＋「どうですか／いかがですか」完整解說
零基礎友好版：詳細說明 + 實用例子 + 常見錯誤提醒

## 📚 零基礎入門：什麼是疑問詞？

### 💡 疑問詞 = 問問題的關鍵字

**疑問詞就是用來問問題的關鍵字。**

想像一下：
- **中文**：這是**什麼**？→ 「什麼」是疑問詞
- **日文**：これは**何**ですか。→ 「何」是疑問詞

**為什麼要學疑問詞？**
✅ 日常對話中，問問題是基本技能  
✅ 在商店、餐廳、學校等場合，經常需要問問題  
✅ 掌握疑問詞，就能問出各種問題  

**日語常見疑問詞：**
- **だれ**：誰
- **どこ**：哪裡
- **何**：什麼
- **いつ**：什麼時候
- **いくら**：多少錢
- **どう**：怎麼樣

## 1️⃣ 疑問詞總整理：誰？哪裡？哪個？什麼時候？多少錢？

### 💡 疑問詞選擇技巧

**不知道某類資訊時，就選對應的疑問詞：**

| 想問的資訊 | 疑問詞 | 記憶口訣 |
|----------|--------|---------|
| **人** | だれ／どなた | 誰 |
| **地點** | どこ／どちら | 哪裡 |
| **物品** | どれ／どの | 哪一個 |
| **內容** | 何／何の | 什麼 |
| **時間** | いつ／何時 | 什麼時候 |
| **價格** | いくら | 多少錢 |
| **方法** | どう／何で | 怎樣 |

### 1.1 人：だれ／どなた

**基本規則：**
- **だれ**：誰（普通，朋友、同事）
- **どなた**：哪位（比較客氣，對長輩、客人）

**實用例句：**

**一般場合（だれ）：**
```
あの人はだれですか。
ano hito wa dare desu ka.
那個人是誰？
```

**禮貌場合（どなた）：**
```
あの方はどなたですか。
ano kata wa donata desu ka.
那位是誰呢？（較禮貌）
```

**更多實用場景：**

**場景1：在聚會上**
```
A：あの人はだれですか。
   ano hito wa dare desu ka.
   那個人是誰？

B：田中さんです。
   Tanaka-san desu.
   是田中先生。
```

**場景2：在辦公室（禮貌）**
```
A：あの方はどなたですか。
   ano kata wa donata desu ka.
   那位是誰呢？

B：部長です。
   buchō desu.
   是部長。
```

**⚠️ 常見錯誤提醒：**
- ❌ 錯誤：對長輩用「だれ」
- ✅ 正確：對長輩、客人用「どなた」

---

### 1.2 地點：どこ／どちら

**基本規則：**
- **どこ**：哪裡（一般）
- **どちら**：哪一邊／哪裡（較客氣，也可以表示「哪一個」）

**實用例句：**

**一般場合（どこ）：**
```
トイレはどこですか。
toire wa doko desu ka.
廁所在哪裡？
```

**禮貌場合（どちら）：**
```
学校はどちらですか。
gakkō wa dochira desu ka.
學校在哪一邊？（較客氣）
```

**更多實用場景：**

**場景1：在車站問路**
```
A：すみません、トイレはどこですか。
   sumimasen, toire wa doko desu ka.
   不好意思，廁所在哪裡？

B：あそこです。
   asoko desu.
   在那裡。
```

**場景2：在商店問位置**
```
A：銀行はどちらですか。
   ginkō wa dochira desu ka.
   銀行在哪一邊？

B：まっすぐ行ってください。
   massugu itte kudasai.
   請直走。
```

**場景3：在咖啡廳**
```
A：コーヒーショップはどこですか。
   kōhī shoppu wa doko desu ka.
   咖啡廳在哪裡？

B：駅の近くです。
   eki no chikaku desu.
   在車站附近。
```

**場景4：二選一（どちら的特殊用法）**
```
A：コーヒーとお茶と、どちらがいいですか。
   kōhī to o-cha to, dochira ga ii desu ka.
   咖啡和茶，你要哪一個呢？（比較客氣）

B：コーヒーがいいです。
   kōhī ga ii desu.
   我想要咖啡。
```

**💡 補充說明：**
- 「どちら」除了問地點，也可以用在「二選一」的情況
- 比「どれ」更客氣，適合在餐廳、商店等場合使用
- 連結前一課的「AかBか」邏輯：二選一時用「どちら」

### 1.3 物品：どれ／どの

**基本規則：**
- **どれ**：哪一個（在三個以上中，單獨指物）
- **どの＋名詞**：哪一個～（後面一定要接名詞）

**實用例句：**

**どれ（單獨使用）：**
```
日本語のCDはどれですか。
Nihongo no shīdī wa dore desu ka.
哪一片是日文 CD？
```

**どの（+名詞）：**
```
どのかばんが田中さんのですか。
dono kaban ga Tanaka-san no desu ka.
哪一個包包是田中先生的？
```

**更多實用場景：**

**場景1：在書店**
```
A：日本語の本はどれですか。
   Nihongo no hon wa dore desu ka.
   日語書是哪一本？

B：これです。
   kore desu.
   是這本。
```

**場景2：在餐廳**
```
A：どのかさが佐藤さんのですか。
   dono kasa ga Satō-san no desu ka.
   哪一把傘是佐藤先生的？

B：あの青いかさです。
   ano aoi kasa desu.
   那把藍色的傘。
```

**⚠️ 常見錯誤提醒：**
- ❌ 錯誤：どれかばん（どれ後面不能接名詞）
- ✅ 正確：どのかばん（どの後面要接名詞）

### 1.4 狀態／感想：どう・どうですか・いかがですか

**基本規則：**
- **どう**：如何、怎麼樣（問方法／狀態）
- **どうですか**：覺得怎麼樣？（一般）
- **いかがですか**：比「どうですか」更客氣的說法（對上司、客人）

**實用例句：**

**一般場合（どうですか）：**
```
日本の生活はどうですか。
Nihon no seikatsu wa dō desu ka.
在日本的生活怎麼樣？
```

**禮貌場合（いかがですか）：**
```
日本の生活はいかがですか。
Nihon no seikatsu wa ikaga desu ka.
在日本的生活如何呢？（對老師或上司）
```

**更多實用場景：**

**場景1：詢問食物**
```
A：このラーメンはどうですか。
   kono rāmen wa dō desu ka.
   這碗拉麵怎麼樣？

B：とてもおいしいです。
   totemo oishii desu.
   非常好吃。
```

**場景2：詢問工作（禮貌）**
```
A：新しい仕事はいかがですか。
   atarashii shigoto wa ikaga desu ka.
   新工作如何呢？

B：とても楽しいです。
   totemo tanoshii desu.
   非常愉快。
```

**場景3：詢問學習**
```
A：日本語の勉強はどうですか。
   Nihongo no benkyō wa dō desu ka.
   日語學習怎麼樣？

B：少し難しいですが、おもしろいです。
   sukoshi muzukashii desu ga, omoshiroi desu.
   有點難，但很有趣。
```

### 1.5 原因：どうして・なぜ

**基本規則：**
- **どうして**：為什麼（比較口語、情緒感一點，帶「怎麼會這樣？」的味道）
- **なぜ**：為什麼（稍微中性、冷靜一點，在書面和口語都常用）

**實用例句：**

**口語（どうして）：**
```
どうして遅れましたか。
dōshite okuremashita ka.
為什麼遲到了？
（帶點情緒：「怎麼會遲到？」）
```

**中性／正式（なぜ）：**
```
なぜ会社をやめたんですか。
naze kaisha o yametan desu ka.
為什麼辭職呢？
（比較中性、冷靜的詢問）
```

**語感對比：**
```
どうしてそんなことを言うんですか。
dōshite sonna koto o iu n desu ka.
你怎麼會說這種話？（帶點情緒）

なぜそんなことを言うんですか。
naze sonna koto o iu n desu ka.
為什麼這麼說？（比較中性）
```

**更多實用場景：**

**場景1：詢問遲到原因**
```
A：どうして遅れましたか。
   dōshite okuremashita ka.
   為什麼遲到了？

B：電車が遅れました。
   densha ga okuremashita.
   電車延誤了。
```

**場景2：詢問選擇原因**
```
A：どうして日本語を勉強しますか。
   dōshite Nihongo o benkyō shimasu ka.
   為什麼學日語？

B：日本へ行きたいからです。
   Nihon e ikitai kara desu.
   因為想去日本。
```

### 1.6 內容：何・何の

**基本規則：**
- **何（なに）**：什麼（一般情況）
- **何の**：什麼樣的～／哪一種的～（問種類）

**實用例句：**

**何（一般）：**
```
これは何ですか。
kore wa nan desu ka.
這是什麼？
```

**何の（問種類）：**
```
それは何のざっしですか。
sore wa nan no zasshi desu ka.
那是什麼雜誌？（比方：漫畫雜誌？學術雜誌？）
```

**更多實用場景：**

**場景1：在商店**
```
A：これは何ですか。
   kore wa nan desu ka.
   這是什麼？

B：日本のおかしです。
   Nihon no okashi desu.
   是日本的點心。
```

**場景2：在書店**
```
A：これは何の本ですか。
   kore wa nan no hon desu ka.
   這是什麼樣的書？

B：日本語の参考書です。
   Nihongo no sankōsho desu.
   是日語參考書。
```

**場景3：在餐廳**
```
A：これは何の料理ですか。
   kore wa nan no ryōri desu ka.
   這是什麼料理？

B：日本のカレーです。
   Nihon no karē desu.
   是日本咖哩。
```

### 1.7 時間：いつ

**基本規則：**
- **いつ**：何時、什麼時候（不一定是幾點，也可以是「哪一天」）

**實用例句：**

```
テストはいつですか。
tesuto wa itsu desu ka.
測驗是什麼時候？
```

**更多實用場景：**

**場景1：詢問會議時間**
```
A：会議はいつですか。
   kaigi wa itsu desu ka.
   會議是什麼時候？

B：来週の水曜日です。
   raishū no suiyōbi desu.
   是下週三。
```

**場景2：詢問考試時間**
```
A：試験はいつですか。
   shiken wa itsu desu ka.
   考試是什麼時候？

B：来月の15日です。
   raigetsu no jūgo-nichi desu.
   是下個月15號。
```

**場景3：詢問生日**
```
A：誕生日はいつですか。
   tanjōbi wa itsu desu ka.
   生日是什麼時候？

B：12月25日です。
   jūni-gatsu nijūgo-nichi desu.
   是12月25日。
```

**基本規則：**

## 2️⃣ 課本會話例句逐句解說

### 2.1 例①：それは何のざっしですか。

**對話：**

```
A：それは　何の　ざっし　ですか。
   sore wa nan no zasshi desu ka.
   那是什麼雜誌呢？（什麼類型的雜誌？）

B：漢字の　ざっし　です。
   kanji no zasshi desu.
   是「漢字」的雜誌。（專門談漢字的雜誌）
```

**語法重點：**
- **何の＋名詞**：問「性質／種類／主題／用途」
  - 何のざっし → 什麼雜誌（漫畫雜誌？新聞雜誌？）
  - 何のえいが → 什麼電影（例如：戰爭片？愛情片？）
  - 何の本 → 關於什麼的書（主題）
  - 何のアプリ → 做什麼用的 APP（用途）

**對比例句：**

**問「是什麼」：**
```
これは何ですか。
kore wa nan desu ka.
這是什麼？（單純不知道是什麼東西）
```

**問「是什麼種類」：**
```
これは何の本ですか。
kore wa nan no hon desu ka.
這是什麼樣的書？（問種類：日文參考書？小說？漫畫？）
```

**更多實用例子：**

**場景1：在書店**
```
A：これは何の本ですか。
   kore wa nan no hon desu ka.
   這是什麼樣的書？

B：日本語の参考書です。
   Nihongo no sankōsho desu.
   是日語參考書。
```

**場景2：在電影院**
```
A：これは何の映画ですか。
   kore wa nan no eiga desu ka.
   這是什麼電影？

B：アクション映画です。
   akushon eiga desu.
   是動作片。
```

### 2.2 例②：テストはいつですか。

**對話：**

```
A：テストは　いつ　ですか。
   tesuto wa itsu desu ka.
   測驗是什麼時候？

B：来週の　水曜日　です。
   raishū no suiyōbi desu.
   是下週三。
```

**語法重點：**
- 問「日期／時候」用 **いつ**
- 回答不用再說「テストは」，只回答「來週の水曜日です」就可以（上下文已知是談測驗）

**對比例句：**

```
映画はいつですか。
eiga wa itsu desu ka.
電影（放映）是什麼時候？

会議はいつですか。
kaigi wa itsu desu ka.
會議是什麼時候？
```

**更多實用例子：**

**場景1：詢問考試時間**
```
A：試験はいつですか。
   shiken wa itsu desu ka.
   考試是什麼時候？

B：来週の月曜日です。
   raishū no getsuyōbi desu.
   是下週一。
```

**場景2：詢問派對時間**
```
A：パーティーはいつですか。
   pātī wa itsu desu ka.
   派對是什麼時候？

B：今週の土曜日です。
   konshū no doyōbi desu.
   是這週六。
```

### 2.4 例④：日本のおべんとうはどうですか。

**對話：**

```
A：日本の　おべんとうは　どうですか。
   Nihon no obentō wa dō desu ka.
   日本的便當怎麼樣？（覺得如何？）

B：おいしいです。
   oishii desu.
   很好吃。
```

**語法重點：**
- **～はどうですか**：問對方的感想、評價
  - 日本の生活はどうですか。→ 生活如何？
  - 新しい仕事はどうですか。→ 新工作怎麼樣？

**更多實用例子：**

**場景1：詢問食物**
```
A：このラーメンはどうですか。
   kono rāmen wa dō desu ka.
   這碗拉麵怎麼樣？

B：とてもおいしいです。
   totemo oishii desu.
   非常好吃。
```

**場景2：詢問學習**
```
A：日本語の勉強はどうですか。
   Nihongo no benkyō wa dō desu ka.
   日語學習怎麼樣？

B：少し難しいですが、おもしろいです。
   sukoshi muzukashii desu ga, omoshiroi desu.
   有點難，但很有趣。
```

**場景3：詢問工作**
```
A：新しい仕事はどうですか。
   atarashii shigoto wa dō desu ka.
   新工作怎麼樣？

B：忙しいですが、楽しいです。
   isogashii desu ga, tanoshii desu.
   很忙，但很愉快。
```

## 3️⃣ 「やってみよう１」：填入正確的疑問詞

### 3.1 例題

**題目：**
```
A：それは（　何　）ですか。
B：これは　日本の　おかしです。
```

**【解答】**
```
A：それは何ですか。
B：これは日本のおかしです。
```

**說明：**
- 問「那是什麼？」→ 用 **何**
- 回答「這是日本的點心。」

---

### 3.2 題目 1

**題目：**
```
A：日本語の　CDは（　　　　）ですか。
B：これです。
```

**【解答】**
```
A：日本語の　CDはどれですか。
B：これです。
```

**說明：**
- 有好幾片 CD，其中只有一片是「日文 CD」
- 問「哪一個是～？」→ 用 **どれ**（單獨指物）
- 不能用「何」，因為不是問「那是什麼」，而是「哪一個」

**⚠️ 常見錯誤提醒：**
- ❌ 錯誤：日本語のCDは何ですか。（問「是什麼」）
- ✅ 正確：日本語のCDはどれですか。（問「哪一個」）

---

### 3.3 題目 2

**題目：**
```
A：入試（にゅうし）は（　　　　）ですか。
B：８時（はちじ）です。
```

**【解答】**
```
A：入試は何時（なんじ）ですか。
B：８時です。
```

**說明：**
- 問具體「幾點」的時間，用「何時（なんじ）」
- 「いつ」問的是「什麼時候」（可能是哪一天、哪個時段）
- 在本題裡，我們要問的是「幾點開始」，所以用「何時（なんじ）」比較精確

**語感差異對比：**

**問「什麼時候」（哪一天／時段）：**
```
入試はいつですか。→ 来週の水曜日です。
考試是什麼時候？→ 下週三。
（問的是「哪一天舉行」，回答可能是日期或星期）
```

**問「幾點」（具體時間）：**
```
入試は何時ですか。→ ８時です。
考試幾點開始？→ 8點。
（問的是「具體幾點」，回答是具體時間）
```

**💡 實際使用：**
- 「入試はいつですか」在日常會話裡也很自然，通常對方會回答「◯月◯日」或「来週の水曜日」，也可能包含時間
- 「入試は何時ですか」則比較明確是在問「幾點開始」
- 本題因為回答是「８時」，所以用「何時」更精確

---

### 3.4 題目 3

**題目：**
```
A：にぎやかな町ですね。（　　　　）町ですか。
B：東京です。
```

**【解答】**
```
A：にぎやかな町ですね。どこの町ですか。
B：東京です。
```

**說明：**
- 「どこの＋名詞」：問「哪裡的～」

- 這裡說「是很熱鬧的城市呢，是哪裡的城市？」→ 回答：東京

**更多例子：**

A：どこの国から来ましたか。
   dono kuni kara kimashita ka.

B：中国から来ました。
   Chūgoku kara kimashita.
   我從中國來。

### 3.6 題目 5

**題目：**
```
A：（　　　　）で　西田さんの　家へ　行きますか。
B：電車で　行きます。
```

**【解答】**
```
A：何で　西田さんの　家へ　行きますか。
B：電車で　行きます。
```

**說明：**
- 問交通工具，用「何で（なんで）」=「用什麼交通工具」
- 回答用「～で」：
  - 電車で行きます。→ 坐電車去
  - バスで行きます。→ 坐公車去

**也可以用「どうやって」詢問方法：**
```
A：どうやって西田さんの家へ行きますか。
   dōyatte Nishida-san no ie e ikimasu ka.
   怎麼去西田先生的家？

B：電車で行きます。
   densha de ikimasu.
   坐電車去。
```

**💡 小提醒：**
- 「何で（なんで）」在句子裡多半是「用什麼方法／用什麼交通工具」
- 但是單獨說「なんで？」的時候，常常表示「為什麼？」
- 本課先記住「何で行きますか」＝「用什麼去？」就好
- 未來你會看到「なんで？」表示「為什麼？」，別嚇到，那是另一個用法

**更多實用例子：**

**場景1：問交通工具**
```

   gakkō e wa nan de ikimasu ka.
   怎麼去學校？

B：自転車で行きます。
   jitensha de ikimasu.
   騎腳踏車去。
```

**場景2：問方法**
```
A：どうやって日本語を勉強しますか。
   dōyatte Nihongo o benkyō shimasu ka.
   怎麼學日語？

B：アプリで勉強します。
   apuri de benkyō shimasu.
   用APP學習。
```

## 4️⃣ 「何」的兩種讀音：なに vs なん

### 📌 重要規則（零基礎必看！）

**「何」有兩種讀音：**
- **なに**：一般情況
- **なん**：後面接量詞或 n/t/d 開頭的字

### 4.1 一般情況：念「なに」

**直接問「這是什麼？」、「你在做什麼？」的 **何**，通常唸「なに」。**

**例句：**

```
これは何（なに）ですか。
kore wa nani desu ka.
這是什麼？

何（なに）をしますか。
nani o shimasu ka.
你要做什麼？
```

**💡 實際使用補充：**
- 口語裡，「これはなんですか」和「これはなにですか」都可以聽到
- 在「です」「だ」「ですか」前面，多數人會說「なん」：
  - これはなんですか。（實際發音）
- 在本課中，我們只要記住：
  - 一般情況說「なに」
  - 後面接數量詞或 n/t/d 開頭時多半讀「なん」
- 就足夠應付初級程度

**更多例子：**

```
A：これは何ですか。
   kore wa nan desu ka.
   這是什麼？

B：本です。
   hon desu.
   是書。
```

---

### 4.2 後面接「量詞／數量詞」：念「なん」

**後面跟「人、時、回、月、年」等「數量詞」時，多半唸「なん」。**

**常見組合：**
- 何人 → なんにん（幾個人）
- 何時 → なんじ（幾點）
- 何回 → なんかい（幾次）
- 何月 → なんがつ（幾月）
- 何年 → なんねん（哪一年）

**例句：**

```
クラスに学生は何人いますか。
kurasu ni gakusei wa nan-nin imasu ka.
班上有幾個學生？

今は何時ですか。
ima wa nan-ji desu ka.
現在幾點？

日本へ行くのは何月ですか。
Nihon e iku no wa nan-gatsu desu ka.
去日本是幾月？
```

**更多實用例子：**

**場景1：問時間**
```
A：今は何時ですか。
   ima wa nan-ji desu ka.
   現在幾點？

B：３時です。
   san-ji desu.
   是3點。
```

**場景2：問人數**
```
A：パーティーには何人来ますか。
   pātī ni wa nan-nin kimasu ka.
   派對會來幾個人？

B：１０人です。
   jū-nin desu.
   是10個人。
```

---

### 4.3 後面接 n/t/d 開頭的字：多半唸「なん」

**後面接 n/t/d 開頭的字時，多半唸「なん」。**

**常見組合：**
- 何度 → なんど（幾次／多少度數）
- 何日 → なんにち（幾號／幾天）
- 何点 → なんてん（幾分／幾點）

**例句：**

```
きょうは何度ですか。
kyō wa nan-do desu ka.
今天多少度？

試験は何日ですか。
shiken wa nan-nichi desu ka.
考試是幾號？
```

**更多實用例子：**

**場景1：問溫度**
```
A：きょうは何度ですか。
   kyō wa nan-do desu ka.
   今天多少度？

B：２５度です。
   nijūgo-do desu.
   是25度。
```

**場景2：問日期**
```
A：誕生日は何日ですか。
   tanjōbi wa nan-nichi desu ka.
   生日是幾號？

B：15日です。
   jūgo-nichi desu.
   是15號。
```

### 💡 記憶技巧

**口訣：**
- **一般情況** → なに（這是什麼？）
- **數量詞** → なん（幾個人？幾點？）
- **n/t/d開頭** → なん（幾度？幾號？）

**快速判斷：**
1. 後面有「人、時、回、月、年」→ なん
2. 後面是 n/t/d 開頭 → なん
3. 其他情況 → なに

## 5️⃣ 疑問詞句裡的「は」和「が」

### 📌 重要規則（零基礎必看！）

**疑問詞的位置決定用「は」還是「が」：**
- 疑問詞在 **主題位置（話題）** 時 → 用 **は**
- 疑問詞在 **主語位置** 時 → 用 **が**
- 問題句用哪個助詞，回答句一般就跟著用哪個

### 5.1 型①：N は だれですか。

**對話：**

```
A：あの人は　だれですか。
   ano hito wa dare desu ka.
   那個人是誰？

B：あの人は　橋本さんです。
   ano hito wa Hashimoto-san desu.
   那個人是橋本先生。
```

**語法重點：**
- 問：**「那個人」是誰？**
  - 話題是「あの人」，所以用「は」
- 回答也用「は」：
  - あの人は橋本さんです

**句型：**
- A：N は　疑問詞　ですか
- B：N は　～です

**更多例子：**

```
A：この町はどこですか。
   kono machi wa doko desu ka.
   這個城市是在哪裡？

B：この町は大阪です。
   kono machi wa Ōsaka desu.
   這個城市是大阪。
```

**實用場景：**

**場景1：問人**
```
A：あの人はだれですか。
   ano hito wa dare desu ka.
   那個人是誰？

B：田中さんです。
   Tanaka-san desu.
   是田中先生。
```

**場景2：問地點**
```
A：学校はどこですか。
   gakkō wa doko desu ka.
   學校在哪裡？

B：駅の近くです。
   eki no chikaku desu.
   在車站附近。
```

---

### 5.2 型②：どの人が田中さんですか。

**對話：**

```
A：どの人が　田中さんですか。
   dono hito ga Tanaka-san desu ka.
   哪一個人是田中先生？

B：あの人が　田中さんです。
   ano hito ga Tanaka-san desu.
   那個人是田中先生。
```

**語法重點：**
- 問：**哪一個人是田中先生？**
  - 這裡真正在問的是「誰是田中」，所以「どの人」是主語 → 用 **が**
- 回答也用「が」對應：
  - あの人が田中さんです

**句型：**
- A：疑問詞 ＋ が　～ですか
- B：～が　～です

**更多例子：**

```
A：どのかばんが山田さんのですか。
   dono kaban ga Yamada-san no desu ka.
   哪一個包包是山田先生的？

B：その青いかばんが山田さんのです。
   sono aoi kaban ga Yamada-san no desu.
   那個藍色的包包是山田先生的。
```

**實用場景：**

**場景1：問物品**
```
A：どれがあなたの本ですか。
   dore ga anata no hon desu ka.
   哪一本是你的書？

B：これが私の本です。
   kore ga watashi no hon desu.
   這本是我的書。
```

**場景2：問人**
```
A：だれがパーティーに行きますか。
   dare ga pātī ni ikimasu ka.
   誰會去派對？

B：田中さんが行きます。
   Tanaka-san ga ikimasu.
   田中先生會去。
```

### 💡 記憶技巧

**口訣：**
- **問「N是～？」** → N は 疑問詞ですか（用は）
- **問「哪個是～？」** → 疑問詞が ～ですか（用が）

**對比：**
- あの人はだれですか。→ 那個人是誰？（主題已知，用は）
- だれが行きますか。→ 誰會去？（主語未知，用が）

---

### 🧠 超簡單記憶圖（一眼看懂版）

**問「那個人是誰？」→ 主題已知（那個人），問補充資訊 → 用「は」**
```
あの人はだれですか。
ano hito wa dare desu ka.
那個人是誰？

→ あの人は田中さんです。
   ano hito wa Tanaka-san desu.
   那個人是田中先生。
```

**問「誰會去？」→ 真正想知道的是「誰」，主語未知 → 用「が」**
```
だれが行きますか。
dare ga ikimasu ka.
誰會去？

→ 田中さんが行きます。
   Tanaka-san ga ikimasu.
   田中先生會去。
```

**簡單理解：**
- 已經知道「那個人」，只是不知道「是誰」→ 用は
- 不知道「誰」會去，想知道「誰」→ 用が

## 6️⃣ 「やってみよう！」：選「は」還是「が」

### 6.1 例題

**題目：**
```
これは（　は／が　）何ですか。
```

**【解答】**
```
これは何ですか。
```

**說明：**
- 主題是「これ」（這個）
- 問「這個是什麼？」→ **「これは何ですか。」** 是固定句型，可以直接整句記住

---

### 6.2 題目 1

**題目：**
```
A：このかさ（　は／が　）だれのですか。
B：佐藤さんのです。
```

**【解答】**
```
A：このかさはだれのですか。
B：佐藤さんのです。
```

**說明：**
- 話題是「這把傘」，在問「這把傘是誰的？」
- 因此用「は」
- 回答直接說「佐藤さんのです。」（= 佐藤先生的）

---

### 6.3 題目 2

**題目：**
```
A：それ（　は／が　）伊藤さんの　車ですか。
B：はい、伊藤さんの　車です。
```

**【解答】**
```
A：それは伊藤さんの車ですか。
B：はい、伊藤さんの車です。
```

**說明：**
- 話題是「それ」（那個東西）
- 問「那是伊藤先生的車嗎？」→ 用「は」
- 回答重複確認：「是的，是伊藤先生的車。」

---

### 6.4 題目 3

**題目：**
```
A：だれ（　は／が　）パーティーに　行きますか。
B：田中さんと　鈴木さん（　は／が　）行きます。
```

**【解答】**
```
A：だれがパーティーに行きますか。
B：田中さんと鈴木さんが行きます。
```

**說明：**
- 這句是真正問「**誰會去** 派對？」→ 主語未知 → 用 **が**
- 回答時，把「誰」換成實際的人名，也用 **が**：
  - 田中さんが行きます。→ 田中先生會去
  - 田中さんと鈴木さんが行きます。→ 田中和鈴木會去

**✅ 小結：**
- 問「誰是～？」時：あの人はだれですか。→ 主題已知 → 用 **は**
- 問「誰會～？」時：だれが行きますか。→ 主語未知 → 用 **が**

---

### 6.5 題目 4

**題目：**
```
A：鈴木さんの　勉強（　は／が　）どうですか。
B：とても　おもしろいです。
```

**【解答】**
```
A：鈴木さんの勉強はどうですか。
B：とてもおもしろいです。
```

**說明：**
- 問「**關於鈴木先生的學習情況**，感覺如何？」→ 把「鈴木さんの勉強」當主題
- 問感想／評價，多半用「～はどうですか。」→ 主題＋は

## 7️⃣ 「どうですか」vs「いかがですか」

### 7.1 禮貌地詢問狀態：いかがですか

**基本規則：**
- 想說得更有禮貌時，用 **「いかがですか」** 代替「どうですか」

**例句：**

```
A：日本の　生活は　いかがですか。
   Nihon no seikatsu wa ikaga desu ka.
   在日本的生活如何呢？

B：とても　楽しいです。
   totemo tanoshii desu.
   非常愉快。
```

**對比：**

**一般（どうですか）：**
```
日本の生活はどうですか。
Nihon no seikatsu wa dō desu ka.
在日本的生活怎麼樣？
```

**禮貌（いかがですか）：**
```
日本の生活はいかがですか。
Nihon no seikatsu wa ikaga desu ka.
在日本的生活如何呢？（對老師或上司）
```

**更多實用例子：**

**場景1：詢問工作**
```
A：仕事はどうですか。／仕事はいかがですか。
   shigoto wa dō desu ka. / shigoto wa ikaga desu ka.
   工作如何？

B：とても楽しいです。
   totemo tanoshii desu.
   非常愉快。
```

**場景2：詢問新居**
```
A：新しいアパートの住み心地はいかがですか。
   atarashii apāto no sumigokochi wa ikaga desu ka.
   新公寓住起來怎麼樣呢？

B：とても快適です。
   totemo kaiteki desu.
   非常舒適。
```

---

### 7.2 用「どうですか」來推薦／招待

**基本規則：**
- 「どうですか」也可以用來 **向對方提出建議或邀請**

**課本例句：**

```
A：お茶、どうですか／いかがですか。
   o-cha, dō desu ka / ikaga desu ka.
   要不要喝茶呢？

B：ありがとうございます。いただきます。
   arigatō gozaimasu. itadakimasu.
   謝謝。我就不客氣了。
```

**說明：**
- A 在「請你喝茶」：
  - 普通：お茶、どうですか
  - 較客氣：お茶、いかがですか
- B 的回答「いただきます」是比較客氣的「我就不客氣喝了」

**更多實用例子：**

**場景1：在咖啡廳**
```
A：コーヒーはどうですか。
   kōhī wa dō desu ka.
   要不要喝咖啡？

B：ありがとうございます。
   arigatō gozaimasu.
   謝謝。
```

**場景2：在餐廳**
```
A：もう一杯、いかがですか。
   mō ippai, ikaga desu ka.
   再來一杯如何呢？

B：いいえ、けっこうです。
   iie, kekkō desu.
   不用了，謝謝。
```

**場景3：推薦書籍**
```
A：この本、どうですか。よかったら読んでください。
   kono hon, dō desu ka. yokattara yonde kudasai.
   這本書怎麼樣？如果你有興趣可以看看。

B：ありがとうございます。読んでみます。
   arigatō gozaimasu. yonde mimasu.
   謝謝。我會看看。
```

**場景4：婉拒（禮貌回應）**
```
A：ケーキはいかがですか。
   kēki wa ikaga desu ka.
   要不要來點蛋糕呢？

B：ありがとうございます。でも、今はちょっと……。
   arigatō gozaimasu. demo, ima wa chotto...
   謝謝，不過現在有點……（含蓄地婉拒）
```

**💡 日文婉拒小技巧：**
- 日文裡經常用「今はちょっと……」（現在有點……）當作婉拒
- 不會直接說「不要」，而是用含蓄的方式表達
- 這是日文社交禮儀的重要一環

### ✅ 小結

- 問感想／狀態 → 「～はどうですか。／～はいかがですか。」
- 禮貌程度：いかがですか ＞ どうですか
- 提議或招待 → 「お茶、どうですか。」、「ケーキはいかがですか。」

### 【練習5】自由造句（進階挑戰）

**題目：** 請用下列疑問詞各造一組「問句＋回答」

1. どこ
2. 何
3. いくら
4. いつ
5. だれ

**【參考答案】**

**1. どこ**
```
A：トイレはどこですか。
   toire wa doko desu ka.
   廁所在哪裡？

B：あそこです。
   asoko desu.
   在那裡。
```

**2. 何**
```
A：これは何ですか。
   kore wa nan desu ka.
   這是什麼？

B：本です。
   hon desu.
   是書。
```

**3. いくら**
```
A：この本はいくらですか。
   kono hon wa ikura desu ka.
   這本書多少錢？

B：１０００円です。
   sen-en desu.
   是1000日圓。
```

**4. いつ**
```
A：会議はいつですか。
   kaigi wa itsu desu ka.
   會議是什麼時候？

B：来週の月曜日です。
   raishū no getsuyōbi desu.
   是下週一。
```

**5. だれ**
```
A：あの人はだれですか。
   ano hito wa dare desu ka.
   那個人是誰？

B：田中さんです。
   Tanaka-san desu.
   是田中先生。
```

**💡 練習建議：**
- 可以根據自己的實際生活情況造句
- 例如：問學校位置、問商品價格、問會議時間等
- 這樣可以讓學習更貼近實際使用

### 📋 疑問詞＋は／が

| 句型 | 助詞 | 例子 |
|------|------|------|
| **N は 疑問詞ですか** | は | あの人はだれですか。 |
| **疑問詞が ～ですか** | が | だれが行きますか。 |

**記憶口訣：**
- 問「N是～？」→ 用は
- 問「哪個是～？」→ 用が
