# 5. 新しい 電子辞書 - New Electronic Dictionary

## 學習目標 (Learning Objectives)

本課學習如何用形容詞和名詞修飾其他名詞，詳細描述人物、物品等。

**重點**: 學習三種修飾名詞的方法：
1. い形容詞 (i-adjective) + 名詞
2. な形容詞 (na-adjective) + 名詞
3. 名詞 + の (noun + の) + 名詞

---

## 文法概念：如何描述名詞 (Grammar: How to Describe Nouns)

### 核心概念 (Core Concept)

**日文說明**:
どんな人か、どんなものかなどをくわしく説明するときは、名詞の前に説明のことばを言う。
Donna hito ka, donna mono ka nado o kuwashiku setsumei suru toki wa, meishi no mae ni setsumei no kotoba o iu.

**中文翻譯**:
當你要詳細說明是什麼樣的人、什麼樣的東西等時，要在名詞前面說描述的話。

**英文翻譯**:
When you describe a noun in detail, such as what sort of person or thing it is, use explanatory words before the noun.

**零基礎理解**:
- 在日語中，描述性的詞語（形容詞）要放在被描述的名詞**前面**
- 這與中文類似：例如「新的書」= 「新しい本」
- 有三種方式可以修飾名詞

---

## 三種修飾名詞的方法 (Three Ways to Modify Nouns)

### 方法1: い形容詞 (i-adjective) + 名詞

**結構**: い形容詞 + 名詞

**特點**:
- い形容詞以「い」結尾
- 直接放在名詞前面，**不需要加「の」**
- 不需要加任何助詞

**例子**:
- 大きい + かばん = 大きいかばん (大的包包)
- 新しい + 本 = 新しい本 (新的書)
- おもしろい + ゲーム = おもしろいゲーム (有趣的遊戲)

---

### 方法2: な形容詞 (na-adjective) + 名詞

**結構**: な形容詞 + な + 名詞

**特點**:
- な形容詞修飾名詞時，要加「な」
- 「な」是連接形容詞和名詞的助詞

**例子**:
- きれいな + くつ = きれいなくつ (漂亮的鞋子)
- 静かな + 部屋 = 静かな部屋 (安靜的房間)
- 親切な + 人 = 親切な人 (親切的人)

---

### 方法3: 名詞 + の + 名詞

**結構**: 名詞1 + の + 名詞2

**特點**:
- 用「の」連接兩個名詞
- 表示所有關係、修飾關係
- 相當於中文的「的」

**例子**:
- 私 + の + かさ = 私のかさ (我的傘)
- 日本 + の + 車 = 日本の車 (日本的車)
- 学校 + の + 先生 = 学校の先生 (學校的老師)

## 對話範例 (Dialogue Examples)

### 對話①: 詢問物品的所有者

**A**: これはだれのかさですか。
Kore wa dare no kasa desu ka.
這是誰的傘？

**B**: あ、すみません。私のかさです。
A, sumimasen. Watashi no kasa desu.
啊，不好意思。是我的傘。

#### 單字解說 (Vocabulary)

**1. だれ (dare)**
- **讀音**: だれ (dare)
- **詞性**: 疑問代名詞 (question pronoun)
- **意思**: 誰、哪個人
- **例句**:
  - だれですか。
    Dare desu ka.
    是誰？
  - だれの本ですか。
    Dare no hon desu ka.
    是誰的書？

**2. かさ (kasa)**
- **讀音**: かさ (kasa)
- **詞性**: 名詞 (noun)
- **意思**: 傘、雨傘
- **例句**:
  - かさを忘れました。
    Kasa o wasuremashita.
    忘記帶傘了。
  - 私のかさです。
    Watashi no kasa desu.
    是我的傘。

**3. すみません (sumimasen)**
- **讀音**: すみません (sumimasen)
- **詞性**: 感嘆詞 (interjection)
- **意思**: 不好意思、對不起、謝謝
- **使用場合**: 
  - 道歉時
  - 打擾別人時
  - 感謝時（較正式）
- **例句**:
  - すみません、これは私のです。
    Sumimasen, kore wa watashi no desu.
    不好意思，這是我的。
  - すみません、道を教えてください。
    Sumimasen, michi o oshiete kudasai.
    不好意思，請告訴我路怎麼走。

**4. 私 (watashi)**
- **讀音**: わたし (watashi)
- **詞性**: 代名詞 (pronoun)
- **意思**: 我（第一人稱）
- **例句**:
  - 私は学生です。
    Watashi wa gakusei desu.
    我是學生。
  - 私の本です。
    Watashi no hon desu.
    是我的書。

#### 文法解說 (Grammar Explanation)

**「だれの」的用法**:
- **結構**: だれ + の + 名詞
- **意思**: 誰的...
- **用法**: 詢問物品的所有者
- **例句**:
  - だれのかさですか。
    Dare no kasa desu ka.
    是誰的傘？
  - だれの本ですか。
    Dare no hon desu ka.
    是誰的書？
  - だれの車ですか。
    Dare no kuruma desu ka.
    是誰的車？

**「私の」的用法**:
- **結構**: 私 + の + 名詞
- **意思**: 我的...
- **用法**: 表示所有關係
- **例句**:
  - 私のかさです。
    Watashi no kasa desu.
    是我的傘。
  - 私の本です。
    Watashi no hon desu.
    是我的書。

### 對話②: 描述日常活動

**A**: 毎日、インターネットでおもしろい ゲームをします。
Mainichi, intaanetto de omoshiroi geemu o shimasu.
每天，我在網路上玩有趣的遊戲。

**B**: そうですか。
Sou desu ka.
是這樣啊。

#### 單字解說 (Vocabulary)

**1. 毎日 (mainichi)**
- **讀音**: まいにち (mainichi)
- **詞性**: 名詞・副詞 (noun/adverb)
- **意思**: 每天、每日
- **拆解**: 毎 (mai - 每) + 日 (nichi - 日)
- **例句**:
  - 毎日本を読みます。
    Mainichi hon o yomimasu.
    每天讀書。
  - 毎日学校へ行きます。
    Mainichi gakkō e ikimasu.
    每天去學校。

**2. インターネット (intaanetto)**
- **讀音**: インターネット (intaanetto)
- **詞性**: 名詞・外來語 (noun・loanword)
- **意思**: 網際網路、網路
- **例句**:
  - インターネットで調べます。
    Intaanetto de shirabemasu.
    在網路上查詢。
  - インターネットで買い物をします。
    Intaanetto de kaimono o shimasu.
    在網路上購物。

**3. おもしろい (omoshiroi)**
- **讀音**: おもしろい (omoshiroi)
- **詞性**: い形容詞 (i-adjective)
- **意思**: 有趣的、有意思的
- **反義詞**: つまらない (tsumaranai) - 無聊的
- **例句**:
  - おもしろい本です。
    Omoshiroi hon desu.
    是有趣的書。
  - この映画はおもしろいです。
    Kono eiga wa omoshiroi desu.
    這部電影很有趣。

**4. ゲーム (geemu)**
- **讀音**: ゲーム (geemu)
- **詞性**: 名詞・外來語 (noun・loanword)
- **意思**: 遊戲
- **例句**:
  - ゲームをします。
    Geemu o shimasu.
    玩遊戲。
  - おもしろいゲームです。
    Omoshiroi geemu desu.
    是有趣的遊戲。

**5. そうですか (sou desu ka)**
- **讀音**: そうですか (sou desu ka)
- **詞性**: 感嘆詞 (interjection)
- **意思**: 是這樣啊、原來如此
- **用法**: 表示理解、回應對方的話
- **例句**:
  - A: 私は学生です。
    Watashi wa gakusei desu.
    我是學生。
  - B: そうですか。
    Sou desu ka.
    是這樣啊。

#### 文法解說 (Grammar Explanation)

**「おもしろいゲーム」的結構**:
- **結構**: い形容詞 + 名詞
- **意思**: 有趣的遊戲
- **重點**: い形容詞直接放在名詞前面，**不需要加「の」**
- **例句**:
  - おもしろいゲームをします。
    Omoshiroi geemu o shimasu.
    玩有趣的遊戲。
  - 大きい本を読みます。
    Ōkii hon o yomimasu.
    讀大本書。

**「インターネットで」的用法**:
- **結構**: 名詞 + で + 動詞
- **意思**: 在網路上...、用網路...
- **助詞「で」**: 表示手段、方法、場所
- **例句**:
  - インターネットで調べます。
    Intaanetto de shirabemasu.
    在網路上查詢。
  - インターネットで買い物をします。
    Intaanetto de kaimono o shimasu.
    在網路上購物。

### 對話③: 讚美物品

**A**: きれいなくつですね。
Kirei na kutsu desu ne.
好漂亮的鞋子啊。

**B**: ありがとうございます。
Arigatō gozaimasu.
謝謝您。

#### 單字解說 (Vocabulary)

**1. きれい (kirei)**
- **讀音**: きれい (kirei)
- **詞性**: な形容詞 (na-adjective)
- **意思**: 漂亮的、美麗的、乾淨的
- **注意**: 雖然以「い」結尾，但這是な形容詞，不是い形容詞
- **例句**:
  - きれいな花です。
    Kirei na hana desu.
    是漂亮的花。
  - きれいな部屋です。
    Kirei na heya desu.
    是乾淨的房間。

**2. くつ (kutsu)**
- **讀音**: くつ (kutsu)
- **詞性**: 名詞 (noun)
- **意思**: 鞋子
- **例句**:
  - 新しいくつを買いました。
    Atarashii kutsu o kaimashita.
    買了新鞋子。
  - くつを履きます。
    Kutsu o hakimasu.
    穿鞋子。

**3. ね (ne)**
- **讀音**: ね (ne)
- **詞性**: 終助詞 (sentence-ending particle)
- **意思**: 啊、呢（表示確認、尋求同意）
- **用法**: 放在句尾，表示說話者希望聽者同意或確認
- **例句**:
  - きれいですね。
    Kirei desu ne.
    好漂亮啊。
  - いい天気ですね。
    Ii tenki desu ne.
    天氣真好啊。

#### 文法解說 (Grammar Explanation)

**「きれいなくつ」的結構**:
- **結構**: な形容詞 + な + 名詞
- **意思**: 漂亮的鞋子
- **重點**: な形容詞修飾名詞時，必須加「な」
- **例句**:
  - きれいなくつを買いました。
    Kirei na kutsu o kaimashita.
    買了漂亮的鞋子。
  - 静かな部屋です。
    Shizuka na heya desu.
    是安靜的房間。

**「～ですね」的用法**:
- **結構**: 形容詞/名詞 + です + ね
- **意思**: ...啊、...呢
- **用法**: 表示讚美、確認、尋求同意
- **例句**:
  - おいしいですね。
    Oishii desu ne.
    真好吃啊。
  - 大きいですね。
    Ōkii desu ne.
    真大啊。

## 重要文法注意事項 (Important Grammar Note)

### ⚠️ い形容詞後面不加「の」

**日文說明**:
い形容詞には「の」がつかない。
I keiyoushi ni wa "no" ga tsukanai.

**中文翻譯**:
い形容詞後面不加「の」。

**英文翻譯**:
Do not add "の" to the end of an い adjective.

### ❌ 錯誤例子 (Wrong Example)

**錯誤**: 大きいのかばんを買います。
Ōkii no kaban o kaimasu.
（這是錯誤的！）

**為什麼錯誤**:
- 「大きい」是い形容詞
- い形容詞修飾名詞時，**直接放在名詞前面**
- **不需要加「の」**

### ✅ 正確例子 (Correct Example)

**正確**: 大きいかばんを買います。
Ōkii kaban o kaimasu.
我要買大的包包。

**為什麼正確**:
- 「大きい」直接放在「かばん」前面
- 不需要任何助詞
- 這是い形容詞修飾名詞的正確方式

### 記憶要點 (Key Points to Remember)

1. **い形容詞**: 直接 + 名詞（不加「の」）
   - 大きい + かばん = 大きいかばん ✅
   - 大きいの + かばん = ❌ 錯誤

2. **な形容詞**: 加「な」+ 名詞
   - きれい + な + くつ = きれいなくつ ✅

3. **名詞**: 加「の」+ 名詞
   - 私 + の + かさ = 私のかさ ✅

## 如何區分い形容詞和な形容詞 (How to Distinguish i-adjectives and na-adjectives)

### 判斷方法

1. **い形容詞的特點**:
   - 以「い」結尾
   - 修飾名詞時，直接放在名詞前面
   - 不需要加「な」或「の」
   - 例子：大きい、小さい、新しい、おもしろい

2. **な形容詞的特點**:
   - 雖然有些以「い」結尾，但修飾名詞時要加「な」
   - 常見的：きれい、静か、親切、便利、有名
   - **注意**: 「きれい」雖然以「い」結尾，但是な形容詞！

3. **記憶技巧**:
   - 如果修飾名詞時需要加「な」，就是な形容詞
   - 如果直接放在名詞前面，就是い形容詞

## 學習重點總結 (Key Learning Points Summary)

### 1. 三種修飾名詞的方法

✅ **い形容詞**: 直接 + 名詞（不加「の」）
- 例：大きいかばん

✅ **な形容詞**: 加「な」+ 名詞
- 例：きれいなくつ

✅ **名詞**: 加「の」+ 名詞
- 例：私のかさ

### 2. 重要規則

⚠️ **い形容詞後面絕對不能加「の」**

### 3. 常用句型

- だれの + 名詞 + ですか - 是誰的...？
- 私の + 名詞 + です - 是我的...
- い形容詞 + 名詞 + を + 動詞 - 做...（修飾的名詞）
- な形容詞 + な + 名詞 + です - 是...（修飾的名詞）
