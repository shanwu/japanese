# 助数詞 Counter Suffixes（計數詞）

## 什麼是助數詞？

助數詞（じょすうし / josuushi）是日語中用來計算不同類型物品的後綴詞。在日語中，不同的物品需要使用不同的計數方式，這與中文的「一張紙」「一本書」「一個人」的概念類似。

**基本結構：** 數字 + 助數詞

例如：
- いちまい（ichimai / 一張）- 用於計算薄平的物品
- いっぽん（ippon / 一支）- 用於計算細長的物品
- ひとり（hitori / 一個人）- 用於計算人數

## 第一組：常用計數詞（1-7）

### 1. ～まい（mai）- 用於薄平的物品

**使用對象：** 紙張、CD、DVD、照片、盤子、T恤等薄平的物品

**讀音變化：**
- 1: いちまい（ichimai / 一張）
- 2: にまい（nimai / 兩張）
- 3: さんまい（sanmai / 三張）
- 4: よんまい（yonmai / 四張）
- 5: ごまい（gomai / 五張）
- 6: ろくまい（rokumai / 六張）
- 7: ななまい（nanamai / 七張）
- 8: はちまい（hachimai / 八張）
- 9: きゅうまい（kyuumai / 九張）
- 10: じゅうまい（juumai / 十張）
- 幾張：なんまい（nanmai / 幾張）

**實用例句：**

1. 紙を三枚ください。
   - Kami wo sanmai kudasai.
   - 請給我三張紙。

2. このTシャツは二千円です。
   - Kono T-shatsu wa nisen en desu.
   - 這件T恤是兩千日元。
   - （註：這裡用「枚」計算T恤的數量）

3. 写真を五枚撮りました。
   - Shashin wo gomai torimashita.
   - 我拍了五張照片。

**文法重點：**
- 「～を」是助詞，表示動作的對象
- 「ください」表示請求，相當於「請給我」
- 「撮りました」是「拍攝」的過去式

### 2. ～台（dai）- 用於機器、車輛、大型家具

**使用對象：** 電腦、汽車、電視、冰箱、洗衣機等機器或大型物品

**讀音變化：**
- 1: いちだい（ichidai / 一台）
- 2: にだい（nidai / 兩台）
- 3: さんだい（sandai / 三台）
- 4: よんだい（yondai / 四台）
- 5: ごだい（godai / 五台）
- 6: ろくだい（rokudai / 六台）
- 7: ななだい（nanadai / 七台）
- 8: はちだい（hachidai / 八台）
- 9: きゅうだい（kyuudai / 九台）
- 10: じゅうだい（juudai / 十台）
- 幾台：なんだい（nandai / 幾台）

**實用例句：**

1. パソコンを一台買いました。
   - Pasokon wo ichidai kaimashita.
   - 我買了一台電腦。

2. 車が二台あります。
   - Kuruma ga nidai arimasu.
   - 有兩輛車。

3. テレビを三台持っています。
   - Terebi wo sandai motte imasu.
   - 我有三台電視。

**文法重點：**
- 「買いました」是「買」的過去式
- 「あります」表示存在（無生命物體）
- 「持っています」表示擁有（持續狀態）

### 3. ～番（ban）- 用於順序、號碼、回合

**使用對象：** 順序、號碼、比賽回合、樓層號碼等

**讀音變化：**
- 1: いちばん（ichiban / 第一號）
- 2: にばん（niban / 第二號）
- 3: さんばん（sanban / 第三號）
- 4: よんばん（yonban / 第四號）
- 5: ごばん（goban / 第五號）
- 6: ろくばん（rokuban / 第六號）
- 7: ななばん（nanaban / 第七號）
- 8: はちばん（hachiban / 第八號）
- 9: きゅうばん（kyuuban / 第九號）
- 10: じゅうばん（juuban / 第十號）
- 第幾號：なんばん（nanban / 第幾號）

**實用例句：**

1. 私は一番です。
   - Watashi wa ichiban desu.
   - 我是第一名。

2. 三番目の駅で降りてください。
   - Sanbanme no eki de orite kudasai.
   - 請在第三站下車。

3. 何番ですか？
   - Nanban desu ka?
   - 是第幾號？

**文法重點：**
- 「～番目」表示「第～個」的意思
- 「降りてください」是「下車」的請求形式
- 「何番」是疑問詞，詢問號碼

### 4. ～円（en）- 用於日圓

**使用對象：** 日圓（日本的貨幣單位）

**讀音變化：**
- 1: いちえん（ichien / 一日圓）
- 2: にえん（nien / 兩日圓）
- 3: さんえん（sanen / 三日圓）
- 4: よえん（yoen / 四日圓）※注意：這裡是「よえん」不是「よんえん」
- 5: ごえん（goen / 五日圓）
- 6: ろくえん（rokuen / 六日圓）
- 7: ななえん（nanaen / 七日圓）
- 8: はちえん（hachien / 八日圓）
- 9: きゅうえん（kyuuen / 九日圓）
- 10: じゅうえん（juuen / 十日圓）
- 多少錢：なんえん（nanen / 多少日圓）

**實用例句：**

1. この本は千円です。
   - Kono hon wa sen en desu.
   - 這本書是一千日圓。

2. コーヒーは三百円です。
   - Koohii wa sanbyaku en desu.
   - 咖啡是三百日圓。

3. いくらですか？ / 何円ですか？
   - Ikura desu ka? / Nan en desu ka?
   - 多少錢？

**文法重點：**
- 「円」是日圓的單位，符號是「¥」
- 「いくら」和「何円」都可以問價格，但「いくら」更常用
- 注意「四円」讀作「よえん」而不是「よんえん」

### 5. ～歳（sai）- 用於年齡

**使用對象：** 人的年齡

**讀音變化：**
- 1: いっさい（issai / 一歲）※注意：這裡是「いっさい」
- 2: にさい（nisai / 兩歲）
- 3: さんさい（sansai / 三歲）
- 4: よんさい（yonsai / 四歲）
- 5: ごさい（gosai / 五歲）
- 6: ろくさい（rokusai / 六歲）
- 7: ななさい（nanasai / 七歲）
- 8: はっさい（hassai / 八歲）※注意：這裡是「はっさい」
- 9: きゅうさい（kyuusai / 九歲）
- 10: じゅっさい（jussai / 十歲）※注意：這裡是「じゅっさい」
- 幾歲：なんさい（nansai / 幾歲）

**實用例句：**

1. 私は二十歳です。
   - Watashi wa nijussai desu.
   - 我二十歲。

2. お子さんは何歳ですか？
   - Okosan wa nansai desu ka?
   - 您的孩子幾歲？

3. 妹は八歳です。
   - Imouto wa hassai desu.
   - 妹妹八歲。

**文法重點：**
- 「歳」也可以寫成「才」（簡體字）
- 「お子さん」是「孩子」的敬語形式
- 注意「一歲」「八歲」「十歲」的讀音有促音變化（小っ）

### 6. ～冊（satsu）- 用於書籍、雜誌

**使用對象：** 書本、雜誌、筆記本等裝訂成冊的物品

**讀音變化：**
- 1: いっさつ（issatsu / 一本）※注意：這裡是「いっさつ」
- 2: にさつ（nisatsu / 兩本）
- 3: さんさつ（sansatsu / 三本）
- 4: よんさつ（yonsatsu / 四本）
- 5: ごさつ（gosatsu / 五本）
- 6: ろくさつ（rokusatsu / 六本）
- 7: ななさつ（nanasatsu / 七本）
- 8: はっさつ（hassatsu / 八本）※注意：這裡是「はっさつ」
- 9: きゅうさつ（kyuusatsu / 九本）
- 10: じゅっさつ（jussatsu / 十本）※注意：這裡是「じゅっさつ」
- 幾本：なんさつ（nansatsu / 幾本）

**實用例句：**

1. 本を三冊買いました。
   - Hon wo sansatsu kaimashita.
   - 我買了三本書。

2. 雑誌を五冊読みました。
   - Zasshi wo gosatsu yomimashita.
   - 我讀了五本雜誌。

3. 図書館で本を十冊借りました。

**文法重點：**

- 「借りました」是「借」的過去式
- 「で」表示動作發生的場所
- 注意「一冊」「八冊」「十冊」的讀音有促音變化

## 第二組：常用計數詞（8-13）

### 7. ～個（ko）- 用於小物品（通用計數詞）

**使用對象：** 蘋果、雞蛋、球、糖果等小而圓的物品（最常用的通用計數詞）

**讀音變化：**
- 1: いっこ（ikko / 一個）※注意：這裡是「いっこ」
- 2: にこ（niko / 兩個）
- 3: さんこ（sanko / 三個）
- 4: よんこ（yonko / 四個）
- 5: ごこ（goko / 五個）
- 6: ろっこ（rokko / 六個）※注意：這裡是「ろっこ」
- 7: ななこ（nanako / 七個）
- 8: はっこ（hakko / 八個）※注意：這裡是「はっこ」
- 9: きゅうこ（kyuuko / 九個）
- 10: じゅっこ（jukko / 十個）※注意：這裡是「じゅっこ」
- 幾個：なんこ（nanko / 幾個）

**實用例句：**

1. りんごを三個買いました。
   - Ringo wo sanko kaimashita.
   - 我買了三個蘋果。

2. 卵を二個ください。
   - Tamago wo niko kudasai.
   - 請給我兩個雞蛋。

3. お菓子を五個食べました。
   - Okashi wo goko tabemashita.
   - 我吃了五個點心。

**文法重點：**
- 「個」是最常用的通用計數詞，當不確定用哪個計數詞時，可以用「個」
- 「食べました」是「吃」的過去式
- 注意多個數字有促音變化（小っ）

### 8. ～階（kai）- 用於樓層、次數

**使用對象：** 建築物的樓層、次數（「回」也可以表示次數）

**讀音變化：**
- 1: いっかい（ikkai / 一樓/一次）
- 2: にかい（nikai / 二樓/兩次）
- 3: さんかい（sankai / 三樓/三次）
- 4: よんかい（yonkai / 四樓/四次）
- 5: ごかい（gokai / 五樓/五次）
- 6: ろっかい（rokkai / 六樓/六次）
- 7: ななかい（nanakai / 七樓/七次）
- 8: はっかい（hakkai / 八樓/八次）
- 9: きゅうかい（kyuukai / 九樓/九次）
- 10: じゅっかい（jukkai / 十樓/十次）
- 幾樓/幾次：なんかい（nankai / 幾樓/幾次）

**實用例句：**

1. 三階に住んでいます。
   - Sankai ni sunde imasu.
   - 我住在三樓。

2. エレベーターで五階まで行きます。
   - Erebeetaa de gokai made ikimasu.

3. この本を三回読みました。

**文法重點：**
- 「住んでいます」表示居住的持續狀態
- 「まで」表示「到～為止」
- 「行きます」是「去」的現在式
- 「階」用於樓層，「回」也可以用於次數

### 11. ～人（nin）- 用於人數

**使用對象：** 人的數量

**讀音變化：**
- 1: ひとり（hitori / 一個人）※注意：這是特殊讀音
- 2: ふたり（futari / 兩個人）※注意：這是特殊讀音
- 3: さんにん（sannin / 三個人）
- 4: よにん（yonin / 四個人）
- 5: ごにん（gonin / 五個人）
- 6: ろくにん（rokunin / 六個人）
- 7: しちにん（shichinin / 七個人）※注意：也可以讀「ななにん」
- 8: はちにん（hachinin / 八個人）
- 9: きゅうにん（kyuunin / 九個人）
- 10: じゅうにん（juunin / 十個人）
- 幾個人：なんにん（nannin / 幾個人）

**實用例句：**

1. 一人で行きます。
   - Hitori de ikimasu.
   - 我一個人去。

   - Kazoku wa yonin desu.

### 12. ～つ（tsu）- 通用計數詞（1-10）

**使用對象：** 通用的計數詞，用於1-10的計數，特別是在沒有特定計數詞時使用

**讀音變化：**
- 1: ひとつ（hitotsu / 一個）※注意：這是特殊讀音
- 2: ふたつ（futatsu / 兩個）※注意：這是特殊讀音
- 3: みっつ（mittsu / 三個）※注意：這是特殊讀音
- 4: よっつ（yottsu / 四個）※注意：這是特殊讀音
- 5: いつつ（itsutsu / 五個）※注意：這是特殊讀音
- 6: むっつ（muttsu / 六個）※注意：這是特殊讀音
- 7: ななつ（nanatsu / 七個）※注意：這是特殊讀音
- 8: やっつ（yattsu / 八個）※注意：這是特殊讀音
- 9: ここのつ（kokonotsu / 九個）※注意：這是特殊讀音
- 10: とお（too / 十個）※注意：這是特殊讀音，沒有「つ」
- 幾個：いくつ（ikutsu / 幾個）

**實用例句：**

1. りんごを一つください。
   - Ringo wo hitotsu kudasai.
   - 請給我一個蘋果。

2. ケーキを三つ買いました。
   - Keeki wo mittsu kaimashita.
   - 我買了三個蛋糕。

3. おいくつですか？
   - Oikutsu desu ka?
   - 您幾歲？（禮貌的問年齡方式）

4. いくつありますか？
   - Ikutsu arimasu ka?
   - 有幾個？

**文法重點：**
- 「つ」計數詞的讀音全部都是特殊的，必須逐一記憶
- 「おいくつ」是「いくつ」的敬語形式，常用於詢問年齡
- 「つ」計數詞只能用於1-10，11以上要用其他計數詞
- 這是日語中最古老的計數方式之一

## 重要文法規則總結

### 1. 促音變化（小っ）

當數字1、6、8、10與某些計數詞結合時，會產生促音（小っ）：

- **1（いち）** → いっ（如：いっさい、いっさつ、いっこ、いっぽん、いっぱい）
- **6（ろく）** → ろっ（如：ろっこ、ろっぽん、ろっぱい）
- **8（はち）** → はっ（如：はっさい、はっさつ、はっこ、はっぽん、はっぱい）
- **10（じゅう）** → じゅっ（如：じゅっさい、じゅっさつ、じゅっこ、じゅっぽん、じゅっぱい）

### 2. 濁音變化

某些計數詞會根據前面的數字產生濁音變化：

- **本（hon）** → ほん/ぼん/ぽん（如：にほん、さんぼん、いっぽん）
- **杯（hai）** → はい/ばい/ぱい（如：にはい、さんばい、いっぱい）

### 3. 特殊讀音

- **一人（hitori）** 和 **二人（futari）** 必須特別記憶
- **四円（yoen）** 不是「よんえん」而是「よえん」
- **つ計數詞** 的1-10全部都是特殊讀音

### 4. 使用時機

- 當不確定用哪個計數詞時，可以用「個（ko）」或「つ」
- 「つ」只能用於1-10，超過10要用其他計數詞
- 「個」可以用於更大的數字

## 練習問題

### 問題1：選擇正確的計數詞

1. ペンを（　　）買いました。
   - A. いちほん  B. いっぽん  C. いちまい

2. コーヒーを（　　）飲みました。
   - A. いちはい  B. いっぱい  C. いちこ

3. 本を（　　）読みました。
   - A. いちさつ  B. いっさつ  C. いちまい

**解答：**
1. B（いっぽん）- 筆是細長物品，用「本」，且「一本」讀作「いっぽん」
2. B（いっぱい）- 飲料用「杯」，且「一杯」讀作「いっぱい」
3. B（いっさつ）- 書本用「冊」，且「一冊」讀作「いっさつ」

### 問題2：填入正確的讀音

1. 私は（　　）です。（我二十歲）
   - 解答：にじゅっさい（nijussai）

2. りんごを（　　）買いました。（買了六個蘋果）
   - 解答：ろっこ（rokko）

3. （　　）で行きますか？（一個人去嗎？）
   - 解答：ひとり（hitori）

### 問題3：翻譯練習

1. 請給我三張紙。
   - 解答：紙を三枚ください。（Kami wo sanmai kudasai.）

2. 我買了五本書。
   - 解答：本を五冊買いました。（Hon wo gosatsu kaimashita.）

3. 咖啡多少錢？
   - 解答：コーヒーはいくらですか？（Koohii wa ikura desu ka?）

## 記憶技巧

1. **分類記憶**：將計數詞按使用對象分類（薄平→まい、細長→ほん、機器→だい等）
2. **特殊讀音標記**：特別標記需要記憶的特殊讀音（一人、二人、つ計數詞等）
3. **促音規則**：記住1、6、8、10容易產生促音
4. **多練習**：在日常生活中嘗試用日語數數，加強記憶

## 補充說明

### 為什麼日語需要這麼多計數詞？

日語的計數系統反映了日本文化對物品分類的重視。不同的計數詞不僅是語法規則，也體現了對物品形狀、性質的細緻觀察。這與中文的「一張紙」「一本書」「一個人」的概念類似，但日語的分類更加細緻。

### 常見錯誤

1. **忘記促音**：容易將「いっぽん」說成「いちほん」
2. **用錯計數詞**：例如用「まい」計算書本（應該用「さつ」）
3. **特殊讀音錯誤**：將「一人」讀成「いちにん」（正確是「ひとり」）

### 實用建議

- 初學者可以先掌握最常用的幾個：個（ko）、本（hon）、枚（mai）、人（nin）
- 遇到不確定的情況，使用「個（ko）」通常不會錯
- 多聽多說，通過實際使用來記憶
