# 助数詞（计数词）練習 - Counter Words Practice

## 學習目標 (Learning Objectives)

**できること (What you can do):**
- 能夠理解和使用日語中不同的計數詞（助数詞）
- 能夠根據物品的形狀和性質選擇正確的計數詞
- 能夠在句子中正確使用計數詞來表達數量
- Understand and use different Japanese counter words (助数詞)
- Choose the correct counter word based on the shape and nature of objects
- Use counter words correctly in sentences to express quantities

---

## 什麼是助数詞？(What are Counter Words?)

在日語中，當我們要數物品時，不能直接說「1、2、3」，而是必須在數字後面加上特定的「助数詞」（計數詞）。不同的物品需要使用不同的助数詞，這取決於物品的形狀、性質或類別。

**In Japanese, when counting objects, you cannot simply say "1, 2, 3" directly. Instead, you must add specific "counter words" (助数詞) after the number. Different objects require different counter words, depending on their shape, nature, or category.**

## 範例句子 (Example Sentences)

### 範例1：まい (mai) - 用於扁平物品

**日文句子：**
私は毎朝、パンを2まい食べます。
Watashi wa maiasa, pan o ni-mai tabemasu.
我每天早上吃兩片麵包。

#### 單字解說 (Vocabulary)

- **私 (わたし / watashi)**: 我（第一人稱代詞）
- **毎朝 (まいあさ / maiasa)**: 每天早上
  - 毎 (まい / mai): 每
  - 朝 (あさ / asa): 早上
- **パン (pan)**: 麵包（來自葡萄牙語）
- **2まい (にまい / ni-mai)**: 兩片
  - 2 (に / ni): 二
  - まい (mai): 片（扁平物品的計數詞）
- **食べます (たべます / tabemasu)**: 吃（動詞，敬體）
  - 原形：食べる (たべる / taberu)

#### 文法解說 (Grammar)

1. **助詞「は」(wa)**: 主題標記，表示「我」是這句話的主題
2. **助詞「を」(o)**: 賓語標記，表示「麵包」是動作的對象
3. **助数詞「まい」(mai)**: 
   - 用於計算扁平、薄片的物品
   - 常見用法：紙張、麵包片、盤子、CD、DVD、照片等
   - 數字讀音變化：1まい (いちまい), 2まい (にまい), 3まい (さんまい), 4まい (よんまい), 5まい (ごまい)

#### 更多實用例句 (More Practical Examples)

1. **紙張：**
   この紙を3まいください。
   Kono kami o san-mai kudasai.
   請給我三張紙。

2. **照片：**
   写真を5まい撮りました。
   Shashin o go-mai torimashita.
   我拍了五張照片。

3. **盤子：**
   お皿を2まい持ってきてください。
   Osara o ni-mai motte kite kudasai.
   請拿兩個盤子來。

### 範例2：さつ (satsu) - 用於書籍

**日文句子：**
つくえの上に本が3さつあります。
Tsukue no ue ni hon ga san-satsu arimasu.
桌子上有三本書。

#### 單字解說 (Vocabulary)

- **つくえ (tsukue)**: 桌子、書桌
- **の (no)**: 助詞，表示「的」或所有關係
- **上 (うえ / ue)**: 上面
- **に (ni)**: 助詞，表示位置「在...」
- **本 (ほん / hon)**: 書
- **が (ga)**: 助詞，表示主語
- **3さつ (さんさつ / san-satsu)**: 三本（書）
  - 3 (さん / san): 三
  - さつ (satsu): 本（書籍的計數詞）
- **あります (arimasu)**: 有、存在（用於無生命的物體）

#### 文法解說 (Grammar)

1. **「～の上に」**: 表示「在...的上面」
   - 結構：名詞 + の + 上 + に
   - 例：机の上に (つくえのうえに) = 在桌子上

2. **助詞「が」vs「は」**:
   - 「が」: 強調主語，用於新信息或存在句
   - 「は」: 強調主題，用於已知信息或對比

3. **助数詞「さつ」(satsu)**:
   - 專門用於計算書籍、雜誌、筆記本等
   - 數字讀音變化：1さつ (いっさつ), 2さつ (にさつ), 3さつ (さんさつ), 4さつ (よんさつ), 5さつ (ごさつ)
   - 注意：1さつ 讀作「いっさつ」，不是「いちさつ」

4. **あります vs います**:
   - あります: 用於無生命的物體（東西、物品）
   - います: 用於有生命的物體（人、動物）

#### 更多實用例句 (More Practical Examples)

1. **買書：**
   本を2さつ買いました。
   Hon o ni-satsu kaimashita.
   我買了兩本書。

2. **借書：**
   図書館から雑誌を5さつ借りました。
   Toshokan kara zasshi o go-satsu karimashita.
   我從圖書館借了五本雜誌。

3. **數書：**
   この本棚には本が何さつありますか。
   Kono hondana ni wa hon ga nan-satsu arimasu ka.
   這個書架上有幾本書？

### 範例3：つ (tsu) - 通用計數詞

**對話內容：**

**A**: すみません。このりんご、3つください。
Sumimasen. Kono ringo, mittsu kudasai.
不好意思。請給我三個蘋果。

**B**: はい、ありがとうございます。
Hai, arigatou gozaimasu.
好的，謝謝。

#### 單字解說 (Vocabulary)

- **すみません (sumimasen)**: 
  - 不好意思、對不起
  - 也可以用來引起注意（類似英文的 "Excuse me"）
- **この (kono)**: 這個（指示代詞，修飾名詞）
- **りんご (ringo)**: 蘋果
- **3つ (みっつ / mittsu)**: 三個
  - 注意：使用「つ」時，1-10的讀音是特殊的
- **ください (kudasai)**: 請給我（禮貌的請求）
- **はい (hai)**: 是的、好的
- **ありがとうございます (arigatou gozaimasu)**: 謝謝（非常禮貌的說法）

#### 文法解說 (Grammar)

1. **助数詞「つ」(tsu)**:
   - 最通用的計數詞，可以用於幾乎所有小物品
   - 特別適合用於：水果、糖果、小玩具、盒子等
   - **重要：1-10的讀音特殊，必須記住！**
     - 1つ (ひとつ / hitotsu) = 一個
     - 2つ (ふたつ / futatsu) = 兩個
     - 3つ (みっつ / mittsu) = 三個
     - 4つ (よっつ / yottsu) = 四個
     - 5つ (いつつ / itsutsu) = 五個
     - 6つ (むっつ / muttsu) = 六個
     - 7つ (ななつ / nanatsu) = 七個
     - 8つ (やっつ / yattsu) = 八個
     - 9つ (ここのつ / kokonotsu) = 九個
     - 10つ (とお / too) = 十個
   - 11以上用普通數字 + つ，但較少使用

2. **「～ください」**:
   - 用於禮貌地請求物品或動作
   - 結構：名詞 + を + ください（給我...）
   - 或：動詞て形 + ください（請...）

3. **「この」系列指示代詞**:
   - この (kono): 這個（近處，說話者附近）
   - その (sono): 那個（近處，聽話者附近）
   - あの (ano): 那個（遠處，雙方都遠）
   - どの (dono): 哪個（疑問詞）

#### 更多實用例句 (More Practical Examples)

1. **買水果：**
   バナナを5つください。
   Banana o itsutsu kudasai.
   請給我五根香蕉。

2. **數糖果：**
   キャンディーが8つあります。
   Kyandii ga yattsu arimasu.
   有八顆糖果。

3. **詢問數量：**
   ケーキはいくつありますか。
   Keeki wa ikutsu arimasu ka.
   有幾個蛋糕？
   （いくつ = 幾個）

### 例題 (Example)

**圖片描述：**
兩把閉合的雨傘，水平放置，一把稍微在另一把的上方。

**答案：**
にほん (ni-hon)
兩把（長條形物品）

#### 解說

**助数詞「ほん」(hon)**:
- 用於計算長條形、圓柱形的物品
- 常見用法：筆、雨傘、樹木、瓶子、香蕉等
- **數字讀音變化（重要！）：**
  - 1本 (いっぽん / ippon)
  - 2本 (にほん / nihon)
  - 3本 (さんぼん / sanbon)
  - 4本 (よんほん / yonhon)
  - 5本 (ごほん / gohon)
  - 6本 (ろっぽん / roppon)
  - 7本 (ななほん / nanahon)
  - 8本 (はっぽん / happon)
  - 9本 (きゅうほん / kyuhon)
  - 10本 (じゅっぽん / juppon)

**完整句子範例：**
傘が2本あります。
Kasa ga ni-hon arimasu.
有兩把雨傘。

三個茶杯配茶碟。一個茶杯在上方，兩個在下方，呈三角形排列。

#### 解說與答案

**答案：**
さんはい (san-hai) 或 みっつ (mittsu)

**助数詞「はい」(hai)**:
- 用於計算杯、碗等容器
- 常見用法：茶杯、咖啡杯、碗、飯碗等
- **數字讀音變化：**
  - 1杯 (いっぱい / ippai)
  - 2杯 (にはい / nihai)
  - 3杯 (さんばい / sanbai)
  - 4杯 (よんはい / yonhai)
  - 5杯 (ごはい / gohai)

  - 7杯 (ななはい / nanahai)
  - 8杯 (はっぱい / happai)
  - 9杯 (きゅうはい / kyuuhai)
  - 10杯 (じゅっぱい / juppai)

**完整句子範例：**
1. コップが3杯あります。
   Koppu ga san-bai arimasu.
   有三個杯子。

2. お茶碗を2杯持ってきてください。
   Ochawan o ni-hai motte kite kudasai.
   請拿兩個飯碗來。

### 練習2 (Exercise 2)

**圖片描述：**
四個扁平、圓形的物品，可能是餅乾或硬幣，排列成兩行，每行兩個。

#### 解說與答案

**答案：**
よんまい (yon-mai) 或 よっつ (yottsu)

**解說：**
- 如果是餅乾、紙張等扁平物品 → 使用「まい」(mai)
- 如果是硬幣 → 使用「まい」(mai) 或「つ」(tsu)
- 如果是小圓形物品 → 也可以使用「つ」(tsu)

**完整句子範例：**
1. クッキーが4まいあります。
   Kukkii ga yon-mai arimasu.
   有四片餅乾。

2. コインを4つ集めました。
   Koin o yottsu atsumemashita.
   我收集了四枚硬幣。

### 練習3 (Exercise 3)

**圖片描述：**
兩個卡通風格的小孩。左邊是一個短黑髮、微笑的男孩。右邊是一個綁辮子、也微笑的女孩。

#### 解說與答案

**答案：**
ににん (ni-nin) 或 ふたり (futari)

**助数詞「にん」(nin) - 用於計算人數**:
- 專門用於計算人
- **數字讀音變化（特殊！）：**
  - 1人 (ひとり / hitori) = 一個人
  - 2人 (ふたり / futari) = 兩個人
  - 3人 (さんにん / sannin) = 三個人
  - 4人 (よにん / yonin) = 四個人
  - 5人 (ごにん / gonin) = 五個人
  - 6人 (ろくにん / rokunin) = 六個人
  - 7人 (ななにん / nananin) = 七個人
  - 8人 (はちにん / hachinin) = 八個人
  - 9人 (きゅうにん / kyuunin) = 九個人
  - 10人 (じゅうにん / juunin) = 十個人

**重要注意事項：**
- 1人和2人使用特殊讀音：ひとり、ふたり
- 3人以上才使用「～にん」的形式

**完整句子範例：**
1. 子供が2人います。
   Kodomo ga futari imasu.
   有兩個小孩。

2. 教室に学生が5人います。
   Kyoushitsu ni gakusei ga go-nin imasu.
   教室裡有五個學生。

3. パーティーに何人来ましたか。
   Paatii ni nan-nin kimashita ka.
   派對來了幾個人？
   （何人 = 幾個人）

**注意：** 計算人時使用「います」，不是「あります」！

### 練習4 (Exercise 4)

**圖片描述：**
一張光碟（CD），顯示其反光表面和中央的孔。

#### 解說與答案

**答案：**
いちまい (ichi-mai)

**解說：**
CD是扁平、圓形的物品，使用「まい」(mai) 作為計數詞。

**完整句子範例：**

2. 音楽CDを3枚買いました。
   Ongaku CD o san-mai kaimashita.
   我買了三張音樂CD。

3. DVDを5枚借りました。
   DVD o go-mai karimashita.
   我借了五張DVD。

**相關單字：**
- CD (シーディー / shiidii): 光碟
- DVD (ディーブイディー / diibuiidii): 數位影音光碟
- 音楽 (おんがく / ongaku): 音樂

### 練習5 (Exercise 5)

**圖片描述：**
三枚日本硬幣。從左到右：一枚大硬幣，上面寫著「500」（500日圓硬幣），和兩枚小硬幣，每枚上面寫著「10」（10日圓硬幣）。

#### 解說與答案

**答案：**
さんまい (san-mai) 或 みっつ (mittsu)

**助数詞用於硬幣：**
- **まい (mai)**: 用於扁平物品，硬幣是扁平的，所以可以用「まい」
- **つ (tsu)**: 通用計數詞，也可以用於硬幣

**完整句子範例：**
1. 硬貨が3枚あります。
   Kouka ga san-mai arimasu.
   有三枚硬幣。

2. コインを5つ集めました。
   Koin o itsutsu atsumemashita.
   我收集了五枚硬幣。

**相關單字：**
- 硬貨 (こうか / kouka): 硬幣（正式說法）
- コイン (koin): 硬幣（外來語，較口語）
- 円 (えん / en): 日圓（日本的貨幣單位）
- 500円 (ごひゃくえん / gohyaku-en): 五百日圓
- 10円 (じゅうえん / juu-en): 十日圓

**其他貨幣相關例句：**
1. 100円玉を10枚持っています。
   Hyaku-en-dama o juu-mai motte imasu.
   我有十枚一百日圓硬幣。

2. おつりを5つもらいました。
   Otsuri o itsutsu moraimashita.
   我收到了五枚找零的硬幣。

## 常用助数詞總整理 (Common Counter Words Summary)

| 助数詞 | 讀音 | 用途 | 1-3的讀音 |
|--------|------|------|-----------|
| つ | tsu | 通用（小物品、水果等） | ひとつ、ふたつ、みっつ |
| まい | mai | 扁平物品（紙、CD、盤子） | いちまい、にまい、さんまい |
| さつ | satsu | 書籍、雜誌 | いっさつ、にさつ、さんさつ |
| ほん | hon | 長條形物品（筆、傘、樹） | いっぽん、にほん、さんぼん |
| はい | hai | 杯、碗等容器 | いっぱい、にはい、さんばい |
| にん | nin | 人數 | ひとり、ふたり、さんにん |
| まい | mai | 硬幣（也可用「つ」） | いちまい、にまい、さんまい |

## 學習重點提醒 (Key Learning Points)

1. **數字讀音變化很重要**：不同的助数詞會影響數字的讀音，必須記住特殊變化。

2. **選擇正確的助数詞**：
   - 看物品的形狀（長條形→ほん，扁平→まい）
   - 看物品的性質（書籍→さつ，人→にん）
   - 不確定時可以用「つ」（但只適用於1-10）

3. **「あります」vs「います」**：
   - あります：無生命的物品
   - います：有生命的人或動物

4. **練習建議**：
   - 每天練習數不同的物品
   - 記住1-10的特殊讀音
   - 多聽多說，熟悉語感
