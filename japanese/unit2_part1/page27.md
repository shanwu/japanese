# 「これ・それ・あれ」の練習 (Practice with "これ・それ・あれ")

## 例文 (Example Dialogues)

### 例 1 (Example 1) ①

**A:** これは だれのかばんですか。
（これは だれのかばんですか。）
Kore wa dare no kaban desu ka?
Whose bag is this?
這是誰的包包？

**B:** それは 田中さんの かばんです。
（それは たなかさんの かばんです。）
Sore wa Tanaka-san no kaban desu.
That is Mr. Tanaka's bag.
那是田中先生的包包。

**📝 單字解說 (Vocabulary):**
- **これ**（kore）：這個（指示代詞，指說話者附近的物品）
- **それ**（sore）：那個（指示代詞，指聽話者附近的物品）
- **だれ**（dare）：誰（疑問詞）
- **だれの**（dare no）：誰的（所有格）
- **かばん**（kaban）：包包、手提包
- **田中**（たなか - tanaka）：田中（日本姓氏）

**📚 文法解說 (Grammar):**
- **これ/それ/あれ**：指示代詞的使用
  - **これ**：說話者附近（我的附近）
  - **それ**：聽話者附近（你的附近）
  - **あれ**：雙方都遠的地方
- **～は～ですか**：疑問句句型
- **だれの+名詞**：詢問所有格，「だれの」表示「誰的」
- **～の+名詞**：表示所有格，「田中さんのかばん」=「田中的包包」

**💡 重點說明 (Key Points):**
- A使用「これ」因為包包在說話者（A）附近
- B使用「それ」因為從B的角度看，包包在聽話者（A）附近

### 例 2 (Example 2) ②

**A:** あれは 日本の車ですか。
（あれは にほんのくるまですか。）
Are wa Nihon no kuruma desu ka?
Is that a Japanese car?
那是日本的車嗎？

**B:** はい。あれは 日本の車です。
（はい。あれは にほんのくるまです。）
Hai. Are wa Nihon no kuruma desu.
Yes. That is a Japanese car.
是的。那是日本的車。

**📝 單字解說 (Vocabulary):**
- **あれ**（are）：那個（指示代詞，指雙方都遠的物品）
- **日本**（にほん - nihon）：日本
- **車**（くるま - kuruma）：車、汽車
- **はい**（hai）：是的、對（肯定回答）

**📚 文法解說 (Grammar):**
- **あれ**：指示代詞，用於指雙方都遠的物品
- **～の+名詞**：表示修飾關係，「日本の車」=「日本的車」
- **～は～ですか**：疑問句句型，詢問判斷
- **はい**：肯定回答，後面可以接完整的句子

**💡 重點說明 (Key Points):**
- 使用「あれ」因為車在雙方都遠的地方
- 「日本の車」中「の」表示修飾關係，不是所有格

## やってみよう! (Yatte miyou!) - Let's try!

### 例 (Example)

**A:** （これ）、たんじょう日のプレゼントです。
（（これ）、たんじょうびのプレゼントです。）
(Kore), tanjoubi no purezento desu.
This is a birthday present.
這是生日禮物。

**B:** ありがとう。
Arigatou.
Thank you.
謝謝。

**📝 單字解說 (Vocabulary):**
- **これ**（kore）：這個（指示代詞）
- **たんじょう日**（たんじょうび - tanjoubi）：生日
- **プレゼント**（purezento）：禮物、贈品
- **ありがとう**（arigatou）：謝謝（感謝用語）

**📚 文法解說 (Grammar):**
- **これ**：指示代詞，指說話者附近的物品
- **～の+名詞**：表示修飾關係，「たんじょう日のプレゼント」=「生日的禮物」
- **～です**：判斷句的禮貌形

**💡 重點說明 (Key Points):**
- 使用「これ」因為禮物在說話者（A）附近，A正在遞給B

### 練習問題 1 (Practice Question 1)

**A:** （　　）は だれのかさですか。
（（　　）は だれのかさですか。）
(　　) wa dare no kasa desu ka?
Whose umbrella is (　　)?
（　　）是誰的傘？

**B:** （　　）は 私のかさです。
（（　　）は わたしのかさです。）
(　　) wa watashi no kasa desu.
(　　) is my umbrella.
（　　）是我的傘。

**📝 單字解說 (Vocabulary):**
- **かさ**（kasa）：傘、雨傘
- **だれ**（dare）：誰（疑問詞）
- **だれの**（dare no）：誰的（所有格）
- **私**（わたし - watashi）：我
- **私の**（watashi no）：我的

**📚 文法解說 (Grammar):**
- **～は～ですか**：疑問句句型
- **だれの+名詞**：詢問所有格
- **～の+名詞**：表示所有格

**💡 正確答案解說 (Answer Explanation):**
- **正確答案：これ**
- **原因分析：**
  1. 根據圖片，A正在拿著傘，傘在說話者（A）附近
  2. 指示代詞的使用規則：
     - **これ**：說話者附近（我的附近）
     - **それ**：聽話者附近（你的附近）
     - **あれ**：雙方都遠
  3. 因為傘在A的手上，屬於A的附近，所以使用「これ」
  4. 答句B也應使用「これ」，因為從對話情境看，B在回答時也指同一個傘（在A附近）

### 練習問題 2 (Practice Question 2)

**A:** （　　）は 何ですか。
（（　　）は なんですか。）
(　　) wa nan desu ka?
What is (　　)?
（　　）是什麼？

**B:** （　　）は 電話の会社です。
（（　　）は でんわのかいしゃです。）
(　　) wa denwa no kaisha desu.
(　　) is a telephone company.
（　　）是電話公司。

**📝 單字解說 (Vocabulary):**
- **何**（なん - nan）：什麼（疑問詞，此處讀作「なん」）
- **電話**（でんわ - denwa）：電話
- **会社**（かいしゃ - kaisha）：公司、企業

**📚 文法解說 (Grammar):**
- **～は～ですか**：疑問句句型
- **何**：疑問詞，詢問事物，此處讀作「なん」（因為後接「です」）
- **～の+名詞**：表示修飾關係，「電話の会社」=「電話公司」

**💡 正確答案解說 (Answer Explanation):**
- **正確答案：あれ**
- **原因分析：**
  1. 根據圖片，A和B都在看遠處的建築物（高樓），建築物在雙方都遠的地方
  2. 指示代詞的使用規則：
     - **これ**：說話者附近
     - **それ**：聽話者附近
     - **あれ**：雙方都遠
  3. 因為建築物在遠處，雙方都指向同一個遠方的建築物，所以使用「あれ」
  4. 答句B也應使用「あれ」，因為指的是同一個遠方的建築物

### 練習問題 3 (Practice Question 3)

**A:** （　　）かばんは いくらですか。
（（　　）かばんは いくらですか。）
(　　) kaban wa ikura desu ka?
How much is (　　) bag?
（　　）包包多少錢？

**B:** 48,000円です。
（よんまんはっせんえんです。）
Yonmanhassen-en desu.
It's 48,000 yen.
是48,000日元。

**📝 單字解說 (Vocabulary):**
- **かばん**（kaban）：包包、手提包
- **いくら**（ikura）：多少錢、多少（疑問詞，詢問價格或數量）
- **円**（えん - en）：日元（日本貨幣單位）
- **48,000**（よんまんはっせん - yonmanhassen）：48,000

**📚 文法解說 (Grammar):**
- **この/その/あの+名詞**：連體詞，必須接名詞
  - **この**：這個+名詞（說話者附近）
  - **その**：那個+名詞（聽話者附近）
  - **あの**：那個+名詞（雙方都遠）
- **～はいくらですか**：詢問價格的句型
- **數字+円**：表示金額

**💡 正確答案解說 (Answer Explanation):**
- **正確答案：その**
- **原因分析：**
  1. 根據圖片，B（店員）正在向A展示包包，包包在聽話者（A）附近，或是在A和B之間
  2. 連體詞的使用規則（與指示代詞相對應）：
     - **この+名詞**：說話者附近
     - **その+名詞**：聽話者附近
     - **あの+名詞**：雙方都遠
  3. 在商店情境中，店員（B）向顧客（A）展示商品時，商品通常在聽話者（A）附近，所以使用「その」
  4. 注意：這裡使用的是連體詞「その」，不是指示代詞「それ」，因為後面接名詞「かばん」

## 📚 Anki 卡片整理 (Anki Cards)

### Card 1：「誰的」與「某人的」所有格說法
**Front:**  
如何用日文詢問「這是誰的包包？」以及回答「那是田中的包包。」？

**Back:**  
- **結構**：**名詞 + の + 名詞**（助詞「の」表示所有格「的」）  
- **疑問詞**：**だれ (dare)** ↔ **だれの (dare no)**（誰的）  
- **Romaji**：dare no kaban / Tanaka-san no kaban  
- **例句**：  
  - 這是誰的包包？  
    - これは誰の包包（かばん）ですか。  
    - Kore wa dare no kaban desu ka?  
  - 那是田中先生的包包。  
    - それは田中さんのかばんです。  
    - Sore wa Tanaka-san no kaban desu.  

---

### Card 2：助詞「の」的兩種主要用法（所有格 vs 修飾關係）
**Front:**  
助詞「の」在以下兩句中，用法有何不同？  
1. 「田中さんのかばん」  
2. 「日本の車」  

**Back:**  
- **用法不同**：  
  1. **所有格（所有/所屬關係）**：表示「...的」。  
     - **田中さんのかばん**（田中的包包）。  
  2. **修飾關係（屬性/產地/材料等）**：表示「...製的」或「...的屬性」，在此句中並非車子屬於日本，而是日本製造的車子。  
     - **日本の車**（日本的車/日本製的車）。  
- **Romaji**：no (possessive vs modifying)  

---

### Card 3：價格疑問詞「いくら」與日圓表達
**Front:**  
日文如何詢問「這個包包多少錢？」以及回答價格「是 48,000 日圓」？（請寫出 48,000 的日文發音）

**Back:**  
- **疑問詞**：**いくら (ikura)**（多少錢）  
- **金額結構**：**數字 + 円 (えん - en)**  
- **數字讀音**：48,000日圓 ＝ **よんまんはっせんえん (yon-man-has-sen-en)**（四萬八千円）  
- **例句**：  
  - 這個包包多少錢？  
    - このかばんはいくらですか。  
    - Kono kaban wa ikura desu ka?  
  - 是 48,000 日圓。  
    - 48,000円です。  
    - Yonmanhassen-en desu.  

---

### Card 4：「これ／それ／あれ」與「この／その／あの」在對話中的視角切換
**Front:**  
在對話中，為什麼 A 問「**これ**はだれのかばんですか」，B 卻回答「**それ**は田中さんのかばんです」？

**Back:**  
- **原因**：因為說話者與聽話者的**空間位置不同**。  
  - 對 A 來說，包包在自己的附近，所以用 **「これ」**（這個）。  
  - 對 B 來說，包包在 A（聽話者）的附近，所以用 **「それ」**（那個）。  
- **空間規律**：  
  - 近自己 ＝ **これ / この**  
  - 近對方 ＝ **それ / その**  
  - 遠離雙方 ＝ **あれ / あの**
