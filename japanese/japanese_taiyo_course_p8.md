# 「か」で作る疑問文（疑問句）完全解説
零基礎友好版：詳細說明 + 實用例子 + 常見錯誤提醒

## 📚 零基礎入門：什麼是疑問句？

### 💡 疑問句 = 問問題

**疑問句就是用來問問題的句子。**

想像一下：
- **中文**：這是書嗎？→ 在句尾加「嗎」就變成問句
- **日文**：これは本です。→ これは本ですか。→ 在句尾加「か」就變成問句

**為什麼要學疑問句？**
✅ 日常對話中，問問題是基本技能  
✅ 在商店、餐廳、學校等場合，經常需要問問題  
✅ 掌握疑問句，就能進行基本對話  

**日語疑問句的規則：**
- 在句尾加「**か**」就變成疑問句
- 語調要上揚（像中文的「嗎？」）
- 回答時用「**はい**」（是）或「**いいえ**」（不是）

## 一、「か」で作る疑問文（問句的基本型）

### 💡 基本規則（零基礎必看）

日文裡，要把「**敘述句**」變成「**問句**」，最基本的做法就是：

> **句子 + か。**

也就是在句尾加上「**か**」，語調上揚，變成疑問文。

**記憶口訣：**
- 中文：句尾加「嗎」→ 這是書**嗎**？
- 日文：句尾加「か」→ これは本です**か**？

**語調提示：**

**疑問句 vs 敘述句的語調差別：**

| 類型 | 例句 | 語調 | 說明 |
|------|------|------|------|
| **敘述句** | これは本です。↘ | 語調下降 | 像中文的句號 |
| **疑問句** | これは本ですか。↗ | 語調上揚 | 像中文的「嗎？」 |

**視覺對比：**
```
これは本です。↘  （敘述句，語調下降）
これは本ですか。↗ （疑問句，語調上揚）
```

**⚠️ 常見錯誤提醒：**
- ❌ 錯誤：これは本です**か**。↘（語調下降，聽起來像敘述句）
- ✅ 正確：これは本です**か**。↗（語調上揚，清楚表示疑問）

**💡 自我檢查建議：**
- 可以錄音自己說，聽聽語調是否上揚
- 或用手勢：說「か」時手指向上指，提醒自己語調上揚

### 📋 三種句型轉換

#### 1️⃣ 名詞句

| 敘述句 | 疑問句 |
|--------|--------|
| **A は B です。**<br>A 是 B。 | **A は B ですか。**<br>A 是 B 嗎？ |

**例句：**

**敘述句：**
```
あの人は鈴木さんです。
ano hito wa Suzuki-san desu.
那個人是鈴木先生。
```

**疑問句：**
```
あの人は鈴木さんですか。
ano hito wa Suzuki-san desu ka.
那個人是鈴木先生嗎？
```

**更多實用例子：**

**場景1：自我介紹時**
```
A：あなたは学生ですか。
   anata wa gakusei desu ka.
   你是學生嗎？

B：はい、学生です。
   hai, gakusei desu.
   是的，我是學生。
```

**場景2：在商店詢問商品**
```
A：これは本ですか。
   kore wa hon desu ka.
   這是書嗎？

B：はい、本です。
   hai, hon desu.
   是的，是書。
```

**場景3：詢問天氣**
```
A：今日は雨ですか。
   kyō wa ame desu ka.
   今天是雨天嗎？

B：いいえ、雨じゃありません。
   iie, ame ja arimasen.
   不，不是雨天。
```

#### 2️⃣ 形容詞句

| 敘述句 | 疑問句 |
|--------|--------|
| **A は 形容詞い です。**<br>A 很～。 | **A は 形容詞い ですか。**<br>A 很～嗎？ |

**例句：**

**敘述句：**
```
この本はおもしろいです。
kono hon wa omoshiroi desu.
這本書很有趣。
```

**疑問句：**
```
この本はおもしろいですか。
kono hon wa omoshiroi desu ka.
這本書有趣嗎？
```

**更多實用例子：**

**場景1：在書店詢問**
```
A：この本はおもしろいですか。
   kono hon wa omoshiroi desu ka.
   這本書有趣嗎？

B：はい、とてもおもしろいです。
   hai, totemo omoshiroi desu.
   是的，非常有趣。
```

**場景2：在商店詢問價格**
```
A：このカメラは高いですか。
   kono kamera wa takai desu ka.
   這台相機貴嗎？

B：いいえ、高くありません。
   iie, takaku arimasen.
   不，不貴。
```

**場景3：詢問天氣**
```
A：今日は寒いですか。
   kyō wa samui desu ka.
   今天冷嗎？

B：はい、とても寒いです。
   hai, totemo samui desu.
   是的，很冷。
```

---

#### 3️⃣ 動詞句（ます形）

| 敘述句 | 疑問句 |
|--------|--------|
| **V ます。**<br>～做、～去…… | **V ますか。**<br>～嗎？ / 要～嗎？ |

**例句：**

**敘述句：**
```
明日、学校へ行きます。
ashita, gakkō e ikimasu.

```

**疑問句：**
```
明日、学校へ行きますか。
ashita, gakkō e ikimasu ka.
明天要去學校嗎？
```

**更多實用例子：**

**場景1：在咖啡廳點餐**
```
A：コーヒーを飲みますか。
   kōhī o nomimasu ka.
   你要喝咖啡嗎？

B：はい、飲みます。
   hai, nomimasu.
   是的，我要喝。
```

**場景2：詢問計畫**
```
A：明日、学校へ行きますか。
   ashita, gakkō e ikimasu ka.
   明天去學校嗎？

B：いいえ、行きません。
   iie, ikimasen.
   不，不去。
```

**場景3：詢問習慣**
```
A：毎日、日本語を勉強しますか。
   mainichi, nihongo o benkyō shimasu ka.
   你每天學日語嗎？

B：はい、勉強します。
   hai, benkyō shimasu.
   是的，我學。
```

**場景4：在餐廳**
```
A：肉を食べますか。
   niku o tabemasu ka.
   你吃肉嗎？

B：いいえ、食べません。
   iie, tabemasen.
   不，我不吃（素食者）。
```

## 二、課本上方的三個基本會話

**場景整體：** 老師示範「です／ます」句加上「か」變成問句，並示範回答方式。

---

### (1) 名詞文的疑問

**對話：**

```
A：鈴木さんですか。
   Suzuki-san desu ka.
   （是鈴木先生嗎？）

B：はい、鈴木です。
   hai, Suzuki desu.
   （是的，我是鈴木。）
```

**說明：**
- 問句是「**名詞＋ですか**」。
- 答案裡一般會把自己的名字再說一次：「**鈴木です**」。
- 也可以說「**はい、そうです**」，下面會詳細說明。

---

### (2) 形容詞文的疑問

**對話：**

```
A：この本、おもしろいですか。
   kono hon, omoshiroi desu ka.
   這本書有趣嗎？

B：はい、とてもおもしろいです。
   hai, totemo omoshiroi desu.
   是的，非常有趣。
```

**說明：**
- 問句是「**形容詞い + ですか**」。
- 回答時，要把那個形容詞再說出來：「**おもしろいです**」。
- **不可以只說「はい、そうです。」**（書上特別說這樣不好）。

---

### (3) 動詞文的疑問

**對話：**

```
A：明日、学校へ行きますか。
   ashita, gakkō e ikimasu ka.
   明天要去學校嗎？

B：いいえ、行きません。
   iie, ikimasen.
   不，不去。
```

**說明：**
- 問句是「**行きますか**」。
- 否定回答改成「**行きません**」。
- 一樣要把動詞再說一遍，**不能只說「いいえ、ちがいます。」**

## 三、「はい」「いいえ」的基本回答

### 💡 回答疑問句的基本規則

**日語回答疑問句的方式：**
- **肯定回答**：はい（是的）
- **否定回答**：いいえ（不是）

**⚠️ 重要提醒：**
- 回答時，要把問句中的關鍵詞再說一遍
- 不能只說「はい」或「いいえ」，要說完整句子
- 例：問「これは本ですか？」→ 答「はい、本です。」（不能只說「はい」）

---

### 1️⃣ 名詞句的問句：A は B ですか。

**回答方式：**
- **肯定：** はい、Bです。／はい、そうです。
- **否定：** いいえ、Bではありません。／いいえ、ちがいます。

**例句：**

**問：**
```
あの人は鈴木さんですか。
ano hito wa Suzuki-san desu ka.
那個人是鈴木先生嗎？
```

**答：**

✅ **はい、鈴木さんです。**
```
hai, Suzuki-san desu.
是的，是鈴木先生。
```

✅ **はい、そうです。**
```
hai, sō desu.
是的，沒錯。（這裡可以用「そうです」）
```

✅ **いいえ、鈴木さんではありません。**
```
iie, Suzuki-san de wa arimasen.
不，不是鈴木先生。
```

✅ **いいえ、ちがいます。**
```
iie, chigaimasu.
不，不是。（這裡可以用「ちがいます」）
```

---

### 2️⃣ 形容詞句的問句：A は 高いですか／おもしろいですか。

**回答方式：**
- **肯定：** はい、高いです。／はい、おもしろいです。
- **否定：** いいえ、高くありません。／いいえ、おもしろくありません。

**例句（對比例很重要）：**

**問：**
```
日本のカメラは高いですか。
Nihon no kamera wa takai desu ka.
日本的相機貴嗎？
```

**答：**

✅ **はい、高いです。**
```
hai, takai desu.
是的，很貴。
```

❌ **はい、そうです。**
```
（課本這裡會標為錯，用來說明「そうです」不能這樣用）
```

---

### 3️⃣ 動詞句的問句：行きますか／見ましたか。

**回答方式：**
- **肯定：** はい、行きます。／はい、見ました。
- **否定：** いいえ、行きません。／いいえ、見ませんでした。

**例句：**

**問：**
```
昨日、新聞を読みましたか。
kinō, shinbun o yomimashita ka.
昨天有看報紙嗎？
```

**答：**

✅ **はい、読みました。**
```
hai, yomimashita.
是的，看了。
```

✅ **いいえ、読みませんでした。**
```
iie, yomimasen deshita.
不，沒看。
```

❌ **いいえ、ちがいます。**
```
（同樣，不能只說「ちがいます」，必須說出動詞）
```

## 四、「そうです」「ちがいます」的使用規則

### 📌 本課採用的初級規則（零基礎必看！）

> **教科書規則（意譯）：**
> 
> 「『そうです』『ちがいます』は、名詞の文の質問に答えるときだけ使います。
> 形容詞や動詞の質問の答えには使いません。」

**中文解說：**
- 「**そうです**」（是的、沒錯）和「**ちがいます**」（不對、不是）
- **在本課的初級規則中，主要用在「名詞＋ですか」這種問句。**
- 問句如果是形容詞句或動詞句，**不能只用「そうです／ちがいます」**，要把關鍵詞再說一遍。

**💡 為什麼教科書這樣要求？**
- 幫助初學者建立正確的句型習慣
- 形容詞和動詞的回答需要具體說明，重複關鍵詞可以強化記憶
- 這是正式場合（商務、學校、初次見面）的標準用法

### ⚠️ 這是初學者最容易犯的錯誤！

**常見錯誤場景：**

**❌ 錯誤1：形容詞句用「そうです」**
```
Q：この本はおもしろいですか。
A：はい、そうです。  ← ❌ 錯誤！
```

**✅ 正確：**
```
Q：この本はおもしろいですか。
A：はい、おもしろいです。  ← ✅ 正確！
```

**❌ 錯誤2：動詞句用「ちがいます」**
```
Q：コーヒーを飲みますか。
A：いいえ、ちがいます。  ← ❌ 錯誤！
```

**✅ 正確：**
```
Q：コーヒーを飲みますか。
A：いいえ、飲みません。  ← ✅ 正確！
```

### 💡 記憶技巧

**口訣：**
- **名詞句** → 可以用「そうです／ちがいます」
- **形容詞句** → 要把形容詞再說一遍
- **動詞句** → 要把動詞再說一遍

**為什麼？**
- 「そうです」意思是「是這樣的」，只能回答「是什麼」的問題
- 形容詞和動詞的問題，需要具體說明「怎麼樣」或「做什麼」

❌ **いいえ、ちがいます。**（不能只用這個）
```
（要把動詞的否定形說出來：「見ませんでした」）
```

**說明：** 動詞句的回答需要具體說明「做什麼」或「不做什麼」，所以要把動詞再說一遍。

## 五、「やってみよう１」：『そうです』的用法練習

### 📝 練習重點

這一部分練習的重點是：
- 看 B 的回答裡用「そうです」對不對。
- 再把錯誤的句子改成正確的句型。

---

### 【例１】（名詞句：可以用「そうです」）

**對話：**

```
A：これは森田さんの本ですか。
   kore wa Morita-san no hon desu ka.
   這是森田先生的書嗎？

B：（○）はい、そうです。　→　はい、森田さんの本です。
   (○) hai, sō desu.  →  hai, Morita-san no hon desu.
   是的，沒錯。→ 是的，是森田先生的書。
```

**說明：**
- 問句是「**森田さんの本ですか**」→ 名詞句。
- 用「**はい、そうです**」沒有問題，然後也可以改寫成完整句：
  「**はい、森田さんの本です。**」

---

### 【例２】（動詞句：不可以用「そうです」）

**對話：**

```
A：きのう、テレビを見ましたか。
   kinō, terebi o mimashita ka.
   昨天有看電視嗎？

B：（×）はい、そうです。　→　はい、見ました。
   (×) hai, sō desu.  →  hai, mimashita.
   （×）是的，沒錯。→（○）是的，看了。
```

**說明：**
- 問句是「**見ましたか**」→ 動詞句。
- 不能用「**はい、そうです**」，要把動詞「見る」的過去形說出來：
  「**見ました。**」

---

### 【問題１】

**對話：**

```
A：この本はおもしろいですか。
   kono hon wa omoshiroi desu ka.
   這本書有趣嗎？

B：（　）はい、そうです。　→　_________________________
```

**【解答】**

❌ **(×)** → ✅ **はい、おもしろいです。**

**說明：**
- 問句是形容詞句「**おもしろいですか**」。
- 所以「**はい、そうです**」不可以，只能用「**はい、おもしろいです。**」

---

### 【問題２】

**對話：**

```
A：日本のカメラは高いですか。
   Nihon no kamera wa takai desu ka.
   日本的相機貴嗎？

B：（　）いいえ、ちがいます。　→　_________________________
```

**【解答】**

❌ **(×)** → ✅ **いいえ、高くありません。**

**說明：**
- 「**高いですか**」是形容詞句。
- 否定回答要再說一次形容詞的否定形：
  「**高くありません**」／「**高くないです**」都可以。
- 「**いいえ、ちがいます**」只適合用在名詞句。

---

### 【問題３】

**對話：**

```
A：あの人は会社員ですか。
   ano hito wa kaishain desu ka.
   那個人是公司職員嗎？

B：（　）はい、そうです。　→　_________________________
```

**【解答】**

✅ **(○)** → ✅ **はい、会社員です。／はい、そうです。**

**說明：**
- 問句是「**会社員ですか**」→ 名詞句。
- 所以「**はい、そうです**」OK，也可以改寫成
  「**はい、会社員です。**」

## 六、「やってみよう２」：AかBか の質問

### 📌 重要原則（零基礎必看！）

> **「『はい』『いいえ』は、『AかBか』という質問の答えには一般不會用。」**

也就是說，當問題是「**Aですか、Bですか**」這種「**二選一**」的句型時，
回答**通常不加「はい／いいえ」**，而是直接說「**Aです**」或「**Bです**」。

### 💡 為什麼一般不會用「はい／いいえ」？

**想像一下：**
- 中文：你要咖啡還是茶？→ 答：咖啡（直接選一個）
- 日文：コーヒーですか、お茶ですか。→ 答：コーヒーです（直接選一個）

**如果用「はい」會比較不自然：**
- ❌ コーヒーですか、お茶ですか。→ はい、コーヒーです。
  - 聽起來有點奇怪，因為問題是「選一個」，不是「是或不是」

**✅ 最自然的做法：**
- コーヒーですか、お茶ですか。→ **コーヒーです。**（直接選一個）
- 或：**コーヒーでお願いします。**（咖啡，麻煩了）

### ⚠️ 常見錯誤提醒

**不太自然：**
```
Q：今日は休みですか、仕事ですか。
A：はい、休みです。  ← 不太自然，通常不加「はい」
```

**✅ 更自然的回答：**
```
Q：今日は休みですか、仕事ですか。
A：休みです。  ← ✅ 最自然！直接選一個
```

### 📋 基本句型

| 問句 | 回答 |
|------|------|
| **Aですか、Bですか。**<br>（是 A 還是 B？） | **Aです。／Bです。** |

---

### 【例】（和課本幾乎同型）

**對話：**

```
A：森田さんは学生ですか、会社員ですか。
   Morita-san wa gakusei desu ka, kaishain desu ka.
   森田先生是學生，還是上班族？

B：× はい、会社員です。
     hai, kaishain desu.
   ○ 会社員です。
     kaishain desu.
```

**說明：**
- 問題已經是「學生嗎？還是上班族？」這是「**二選一**」的問題。
- 你只要選一個答案說出來就好：「**学生です。**」或「**会社員です。**」
- 加上「**はい**」反而會讓句子變得奇怪，所以教科書特別拿出來修正。

---

### 【練習１】

**對話：**

```
A：これは森田さんの本ですか、鈴木さんの本ですか。
   kore wa Morita-san no hon desu ka, Suzuki-san no hon desu ka.
   這是森田先生的書，還是鈴木先生的書？

B：_________________________
```

**【解答例】**

✅ **森田さんの本です。**
```
Morita-san no hon desu.
是森田先生的書。
```

**也可以回答：**

✅ **鈴木さんの本です。**
```
Suzuki-san no hon desu.
（如果你想說是鈴木的書，就選另一個。）
```

---

### 【練習２】

**對話：**

```
A：今日は休みですか、仕事ですか。
   kyō wa yasumi desu ka, shigoto desu ka.
   今天是休假，還是要上班？

B：_________________________
```

**【解答例】**

✅ **休みです。**
```
yasumi desu.
今天是休假。
```

**或：**

✅ **仕事です。**
```
shigoto desu.
今天要上班。
```

---

### 【練習３】

**對話：**

```
A：映画はおもしろかったですか、つまらなかったですか。
   eiga wa omoshirokatta desu ka, tsumaranakatta desu ka.
   電影好看，還是不好看？

B：_________________________
```

**【解答例】**

✅ **おもしろかったです。**
```
omoshirokatta desu.
很好看。
```

**或：**

✅ **つまらなかったです。**
```
tsumaranakatta desu.
不好看，蠻無聊的。
```

**說明：**
- 雖然這裡用到過去形，但規則一樣：
  問句是「**A でしたか、B でしたか**」，回答只說其中一個，不要加「**はい／いいえ**」。

## 七、整體重點小結（幫你建立清楚的規則樹）

### 📚 規則總覽

#### 1. 基本疑問句
- **句子 + か** → 問句
- 名詞＋ですか／形容詞＋ですか／動詞ます＋か

---

#### 2. 名詞句的問答

**問：** A は B ですか。

**答：**
- ✅ はい、Bです。／はい、そうです。
- ✅ いいえ、Bではありません。／いいえ、ちがいます。

---

#### 3. 形容詞句的問答

**問：** A は 高いですか。

**答：**
- ✅ はい、高いです。
- ✅ いいえ、高くありません。

❌ **不可以說「はい、そうです／いいえ、ちがいます」。**

---

#### 4. 動詞句的問答

**問：** V ますか／Vましたか。

**答：**
- ✅ はい、Vます／Vました。
- ✅ いいえ、Vません／Vませんでした。

❌ **同樣不能只說「そうです／ちがいます」。**

---

#### 5. 『そうです』『ちがいます』使用範圍

- ✅ **只能用在「名詞文」的問題上。**
- ❌ 形容詞、動詞的問句一律要把形容詞／動詞再說一遍。

---

#### 6. 『はい』『いいえ』和「AかBか」

- ❌ 「**Aですか、Bですか。**」這種二選一問題，
  回答時**不要用「はい／いいえ」**。
- ✅ 直接說：「**Aです。**」或「**Bです。**」即可。

## 十一、口語補充區（進階可略讀）

> ⚠️ **注意：** 這是進階內容，初學者可以先跳過。先把「です／ます＋か」學好，這是正式場合必備。

### 💬 朋友間的口語用法

**在正式場合（商務、學校、初次見面）必須用「です／ます＋か」：**
```
これは本ですか。↗
```

**但在朋友間，常常會：**

#### 1. 省略「か」＋語調上揚

**正式：**
```
学校へ行きますか。↗
```

**口語（朋友間）：**
```
学校？↗（省略「へ行きますか」，只用語調上揚）
行く？↗（省略「ますか」，用動詞普通形）
```

#### 2. 用「の？」

**正式：**
```
学校へ行きますか。
```

**口語（朋友間）：**
```
行くの？↗（用「の？」代替「か」）
休みなの？↗（な形容詞用「なの？」）
```

**更多例子：**

| 正式（丁寧体） | 口語（朋友間） | 使用場合 |
|--------------|--------------|---------|
| 学校へ行きますか。 | 学校？／行く？ | 朋友、家人 |
| 休みですか。 | 休み？／休みなの？ | 朋友、家人 |
| おもしろいですか。 | おもしろい？／おもしろいの？ | 朋友、家人 |

### 📌 重要提醒

**初學者建議：**
- ✅ 先掌握「です／ます＋か」的正式用法
- ✅ 這是正式場合（商務、學校、初次見面）的標準用法
- ✅ 等熟悉後，再學習口語用法

**為什麼？**
- 正式用法適用於所有場合
- 口語用法只適合朋友、家人等親近關係
- 用錯場合會顯得沒禮貌

### 📋 AかBか 二選一問題（3秒記住）

**問：** Aですか、Bですか。

**答：** Aです。／Bです。

**重點：** 通常不加「はい／いいえ」，直接選一個（最自然：直接說答案）

---

### ⚠️ 常見錯誤速記

1. ❌ 形容詞句用「はい、そうです」→ ✅ 要把形容詞再說一遍
2. ❌ 動詞句用「いいえ、ちがいます」→ ✅ 要把動詞再說一遍
3. ❌ AかBか問題用「はい、Aです」→ ✅ 直接說「Aです」

---

### 💡 記憶口訣（10秒記住）

1. **疑問句**：句尾加「か」↗（語調上揚）
2. **名詞回答**：可以用「そうです／ちがいます」
3. **い形容詞回答**：不能只用「そうです」，要把形容詞再說一遍
4. **動詞回答**：不能只用「ちがいます」，要把動詞再說一遍
5. **二選一**：通常不加「はい／いいえ」，直接選一個
