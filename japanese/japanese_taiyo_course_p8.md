# 「か」で作る疑問文（疑問句）完全解説
零基礎友好版：詳細說明 + 實用例子 + 常見錯誤提醒

────────────────────────────────

## 📚 零基礎入門：什麼是疑問句？

### 💡 疑問句 = 問問題

**疑問句就是用來問問題的句子。**

想像一下：
- **中文**：這是書嗎？→ 在句尾加「嗎」就變成問句
- **日文**：これは本です。→ これは本ですか。→ 在句尾加「か」就變成問句

**為什麼要學疑問句？**
✅ 日常對話中，問問題是基本技能  
✅ 在商店、餐廳、學校等場合，經常需要問問題  
✅ 掌握疑問句，就能進行基本對話  

**日語疑問句的規則：**
- 在句尾加「**か**」就變成疑問句
- 語調要上揚（像中文的「嗎？」）
- 回答時用「**はい**」（是）或「**いいえ**」（不是）

### 📝 單字例句

**1. 質問**
```
先生に質問します。
sensei ni shitsumon shimasu.
我向老師提問。
```
- **結構說明**：這是「〜に〜します」的句型，表示「向某人做某事」。
- **單字解析**：
  - 先生（sensei）：老師
  - に（ni）：對象助詞，表示動作的對象（向誰）
  - 質問します（shitsumon shimasu）：提問（質問する的ます形）
    - 💡 **為什麼是「質問する的ます形」？**
      - 「質問する」是**サ變動詞**（三類動詞），由「名詞 + する」組成
      - **サ變動詞的變形規則**：
        - 字典形（基本形）：質問**する**（shitsumon **suru**）
        - ます形（禮貌形）：質問**します**（shitsumon **shimasu**）
        - 變化方式：把「**する**」改成「**します**」
      - **更多サ變動詞例子**：
        - 勉強する → 勉強します（學習）
        - 掃除する → 掃除します（打掃）
        - 料理する → 料理します（做菜）
        - 運動する → 運動します（運動）
      - **記憶要點**：所有「〜する」的動詞，變成ます形時都是「〜します」
- **句型重點**：「に」用於表示動作的對象或方向，這裡表示「向老師」提問。
- **使用場景**：在課堂上或學習場合，向老師提問時使用。

**2. 返事**
```
すぐに返事をしてください。
sugu ni henji o shite kudasai.
請立刻回覆。
```
- **結構說明**：這是「〜をしてください」的請求句型，表示「請做某事」。
- **單字解析**：
  - すぐに（sugu ni）：立刻、馬上（副詞）
  - 返事（henji）：回覆、回答（名詞）
  - を（o）：受詞助詞，表示動作的對象
  - してください（shite kudasai）：請做（する的て形 + ください）
- **句型重點**：「〜をしてください」是禮貌的請求句型，比「〜してください」更正式。
- **使用場景**：請求對方回覆訊息、回答問題時使用。

**3. 明日**
```
明日、東京へ行きます。
ashita, Tōkyō e ikimasu.
明天我要去東京。
```
- **結構說明**：這是「時間 + 地點へ + 動詞」的句型，表示「在什麼時候去哪裡」。
- **單字解析**：
  - 明日（ashita）：明天（時間副詞）
  - 東京（Tōkyō）：東京（地點名詞）
  - へ（e）：方向助詞，表示移動的方向（「へ」和「に」都可以表示方向，但「へ」更強調移動的過程）
  - 行きます（ikimasu）：去（行く的ます形）
- **句型重點**：時間詞通常放在句首，用逗號分隔。「へ」表示移動的方向。
- **使用場景**：說明未來的行程、計畫時使用。

**4. 昨日**
```
昨日、新聞を読みました。
kinō, shinbun o yomimashita.
昨天我看了報紙。
```
- **結構說明**：這是「時間 + 名詞を + 動詞（過去式）」的句型，表示「在過去某個時間做了某事」。
- **單字解析**：
  - 昨日（kinō）：昨天（時間副詞）
  - 新聞（shinbun）：報紙（名詞）
  - を（o）：受詞助詞，表示動作的對象
  - 読みました（yomimashita）：讀了（読む的過去式ます形）
- **句型重點**：「ました」是「ます」的過去式，表示動作已經完成。
- **使用場景**：描述過去發生的事情、回憶時使用。

**5. 学校**
```
毎日、学校へ行きます。
mainichi, gakkō e ikimasu.
我每天去學校。
```
- **結構說明**：這是「頻率副詞 + 地點へ + 動詞」的句型，表示「經常性地去某個地方」。
- **單字解析**：
  - 毎日（mainichi）：每天（頻率副詞）
  - 学校（gakkō）：學校（名詞）
  - へ（e）：方向助詞，表示移動的方向
  - 行きます（ikimasu）：去（行く的ます形）
- **句型重點**：頻率副詞（毎日、毎週、毎月等）通常放在句首。
- **使用場景**：說明日常習慣、例行公事時使用。

**6. 新聞**
```
朝、新聞を読みます。
asa, shinbun o yomimasu.
我早上會讀報。
```
- **結構說明**：這是「時間 + 名詞を + 動詞」的句型，表示「在某個時間做某事」。
- **單字解析**：
  - 朝（asa）：早上（時間名詞）
  - 新聞（shinbun）：報紙（名詞）
  - を（o）：受詞助詞，表示動作的對象
  - 読みます（yomimasu）：讀（読む的ます形）
- **句型重點**：時間詞放在句首，表示動作發生的時間。
- **使用場景**：說明日常習慣、生活作息時使用。

**7. 本**
```
この本はおもしろいです。
kono hon wa omoshiroi desu.
這本書很有趣。
```
- **結構說明**：這是「この/その/あの + 名詞は + い形容詞です」的句型，表示「這個/那個東西的性質」。
- **單字解析**：
  - この（kono）：這個（連體詞，必須接名詞）
  - 本（hon）：書（名詞）
  - は（wa）：主題標記，表示要談論的主題
  - おもしろい（omoshiroi）：有趣的（い形容詞）
  - です（desu）：禮貌的斷定助動詞
- **句型重點**：「この/その/あの」是指示連體詞，必須直接接名詞，不能單獨使用。
- **使用場景**：評價物品、描述性質時使用。

**8. テレビ**
```
昨日、テレビを見ました。
kinō, terebi o mimashita.
昨天我看了電視。
```
- **結構說明**：這是「時間 + 名詞を + 動詞（過去式）」的句型，表示「在過去某個時間做了某事」。
- **單字解析**：
  - 昨日（kinō）：昨天（時間副詞）
  - テレビ（terebi）：電視（名詞，外來語）
  - を（o）：受詞助詞，表示動作的對象
  - 見ました（mimashita）：看了（見る的過去式ます形）
- **句型重點**：「見る」是二類動詞，過去式是「見ました」。
- **使用場景**：描述過去看電視、看電影等視覺活動時使用。

**9. 映画**
```
その映画はあまりおもしろくありません。
sono eiga wa amari omoshiroku arimasen.
那部電影不太有趣。
```
- **結構說明**：這是「その + 名詞は + あまり + い形容詞（否定形）」的句型，表示「那個東西不太...」。
- **單字解析**：
  - その（sono）：那個（連體詞）
  - 映画（eiga）：電影（名詞）
  - は（wa）：主題標記
  - あまり（amari）：不太、不怎麼（副詞，通常與否定形搭配）
  - おもしろく（omoshiroku）：有趣的（おもしろい的く形，用於否定）
  - ありません（arimasen）：不是、沒有（ありません的否定形）
- **句型重點**：い形容詞的否定形要把「い」改成「く」，再加「ありません」或「ないです」。「あまり」通常與否定形搭配，表示「不太...」。
- **使用場景**：委婉地表達負面評價時使用。

**10. 日本**
```
日本のカメラは有名です。
Nihon no kamera wa yūmei desu.
日本的相機很有名。
```
- **結構說明**：這是「名詞の + 名詞は + な形容詞です」的句型，表示「某個地方的東西的性質」。
- **單字解析**：
  - 日本（Nihon）：日本（名詞）
  - の（no）：所有格助詞，表示所屬、來源、性質等
  - カメラ（kamera）：相機（名詞，外來語）
  - は（wa）：主題標記
  - 有名（yūmei）：有名的（な形容詞）
  - です（desu）：禮貌的斷定助動詞
- **句型重點**：「の」用於連接兩個名詞，表示所屬、來源、性質等關係。「有名」是な形容詞，直接加「です」。
- **使用場景**：說明某個國家或地區的特產、特色時使用。

**11. カメラ**
```
新しいカメラを買いました。
atarashii kamera o kaimashita.
我買了新相機。
```
- **結構說明**：這是「い形容詞 + 名詞を + 動詞（過去式）」的句型，表示「買了某個性質的東西」。
- **單字解析**：
  - 新しい（atarashii）：新的（い形容詞，直接修飾名詞）
  - カメラ（kamera）：相機（名詞）
  - を（o）：受詞助詞，表示動作的對象
  - 買いました（kaimashita）：買了（買う的過去式ます形）
- **句型重點**：い形容詞可以直接修飾名詞，不需要加「な」。「買う」是一類動詞，過去式是「買いました」。
- **使用場景**：描述購買行為、購物經驗時使用。

**12. 高い**
```
このカメラは高いです。
kono kamera wa takai desu.
這台相機很貴。
```
- **結構說明**：這是「この + 名詞は + い形容詞です」的句型，表示「這個東西的性質」。
- **單字解析**：
  - この（kono）：這個（連體詞）
  - カメラ（kamera）：相機（名詞）
  - は（wa）：主題標記
  - 高い（takai）：貴的、高的（い形容詞）
  - です（desu）：禮貌的斷定助動詞
- **句型重點**：「高い」可以表示「價格貴」或「高度高」，根據上下文判斷。
- **使用場景**：詢問或說明價格、評價商品時使用。

**13. 仕事**
```
仕事は忙しいです。
shigoto wa isogashii desu.
工作很忙。
```
- **結構說明**：這是「名詞は + い形容詞です」的句型，表示「某個主題的狀態」。
- **單字解析**：
  - 仕事（shigoto）：工作（名詞）
  - は（wa）：主題標記
  - 忙しい（isogashii）：忙的（い形容詞）
  - です（desu）：禮貌的斷定助動詞
- **句型重點**：這裡「仕事」是主題，描述工作的狀態是「忙」。
- **使用場景**：說明工作狀況、生活狀態時使用。

**14. 忙しい**
```
今週はとても忙しいです。
konshū wa totemo isogashii desu.
這週非常忙。
```
- **結構說明**：這是「時間 + は + とても + い形容詞です」的句型，表示「某個時間非常...」。
- **單字解析**：
  - 今週（konshū）：這週（時間名詞）
  - は（wa）：主題標記
  - とても（totemo）：非常、很（程度副詞）
  - 忙しい（isogashii）：忙的（い形容詞）
  - です（desu）：禮貌的斷定助動詞
- **句型重點**：「とても」是程度副詞，用來加強形容詞的程度，表示「非常」。
- **使用場景**：強調忙碌程度、說明時間段的狀態時使用。

**15. 土曜日**
```
土曜日は休みです。
doyōbi wa yasumi desu.
星期六休假。
```
- **結構說明**：這是「時間 + は + 名詞です」的句型，表示「某個時間是什麼狀態」。
- **單字解析**：
  - 土曜日（doyōbi）：星期六（時間名詞）
  - は（wa）：主題標記
  - 休み（yasumi）：休假、休息（名詞）
  - です（desu）：禮貌的斷定助動詞
- **句型重點**：「休み」是名詞，表示「休息日、假期」的意思。
- **使用場景**：說明週末、假日的安排時使用。

**16. 会社**
```
大きい会社で働きます。
ōkii kaisha de hatarakimasu.
我在大公司工作。
```
- **結構說明**：這是「い形容詞 + 名詞で + 動詞」的句型，表示「在某個性質的地方做某事」。
- **單字解析**：
  - 大きい（ōkii）：大的（い形容詞，直接修飾名詞）
  - 会社（kaisha）：公司（名詞）
  - で（de）：場所助詞，表示動作發生的場所
  - 働きます（hatarakimasu）：工作（働く的ます形）
- **句型重點**：「で」表示動作發生的場所，與「に」（存在場所）不同。「働く」是一類動詞。
- **使用場景**：說明工作地點、職業時使用。

**17. 休み**
```
明日は会社は休みです。
ashita wa kaisha wa yasumi desu.
明天公司休假。
```
- **結構說明**：這是「時間 + は + 名詞 + は + 名詞です」的句型，這裡有兩個「は」，形成對比或強調。
- **單字解析**：
  - 明日（ashita）：明天（時間名詞）
  - は（wa）：主題標記（第一個）
  - 会社（kaisha）：公司（名詞）
  - は（wa）：主題標記（第二個，形成對比）
  - 休み（yasumi）：休假（名詞）
  - です（desu）：禮貌的斷定助動詞
- **句型重點**：兩個「は」的使用表示「明天」這個時間點，「公司」是休假的。這裡「会社は」的「は」有對比或強調的意味。
- **使用場景**：說明公司、學校等機構的休假安排時使用。

**18. おもしろい**
```
あの映画はとてもおもしろいです。
ano eiga wa totemo omoshiroi desu.
那部電影非常有趣。
```
- **結構說明**：這是「あの + 名詞は + とても + い形容詞です」的句型，表示「那個東西非常...」。
- **單字解析**：
  - あの（ano）：那個（遠稱連體詞，指離說話者和聽話者都遠的東西）
  - 映画（eiga）：電影（名詞）
  - は（wa）：主題標記
  - とても（totemo）：非常、很（程度副詞）
  - おもしろい（omoshiroi）：有趣的（い形容詞）
  - です（desu）：禮貌的斷定助動詞
- **句型重點**：「あの」是指示遠稱，用於指離雙方都遠的事物。「とても」加強程度。
- **使用場景**：評價電影、書籍、活動等時使用。

**19. 鈴木さん**
```
鈴木さんは日本人です。
Suzuki-san wa Nihon-jin desu.
鈴木先生是日本人。
```
- **結構說明**：這是「人名 + は + 名詞です」的句型，表示「某人的身份或國籍」。
- **單字解析**：
  - 鈴木さん（Suzuki-san）：鈴木先生（人名 + 敬稱）
  - は（wa）：主題標記
  - 日本人（Nihon-jin）：日本人（名詞，由「日本」+「人」組成）
  - です（desu）：禮貌的斷定助動詞
- **句型重點**：「さん」是敬稱，用於稱呼他人。「日本人」是複合名詞，表示國籍。
- **使用場景**：介紹他人、說明國籍或身份時使用。

**20. 森田さん**
```
森田さんは会社員です。
Morita-san wa kaishain desu.
森田先生是公司職員。
```
- **結構說明**：這是「人名 + は + 名詞です」的句型，表示「某人的職業或身份」。
- **單字解析**：
  - 森田さん（Morita-san）：森田先生（人名 + 敬稱）
  - は（wa）：主題標記
  - 会社員（kaishain）：公司職員（名詞，由「会社」+「員」組成）
  - です（desu）：禮貌的斷定助動詞
- **句型重點**：「会社員」是職業名詞，表示在公司工作的人。
- **使用場景**：介紹他人、說明職業時使用。

## 一、「か」で作る疑問文（問句的基本型）

### 💡 基本規則（零基礎必看）

日文裡，要把「**敘述句**」變成「**問句**」，最基本的做法就是：

> **句子 + か。**

也就是在句尾加上「**か**」，語調上揚，變成疑問文。

**記憶口訣：**
- 中文：句尾加「嗎」→ 這是書**嗎**？
- 日文：句尾加「か」→ これは本です**か**？

**語調提示：**

**疑問句 vs 敘述句的語調差別：**

| 類型 | 例句 | 語調 | 說明 |
|------|------|------|------|
| **敘述句** | これは本です。↘ | 語調下降 | 像中文的句號 |
| **疑問句** | これは本ですか。↗ | 語調上揚 | 像中文的「嗎？」 |

**視覺對比：**
```
これは本です。↘  （敘述句，語調下降）
これは本ですか。↗ （疑問句，語調上揚）
```

**⚠️ 常見錯誤提醒：**
- ❌ 錯誤：これは本です**か**。↘（語調下降，聽起來像敘述句）
- ✅ 正確：これは本です**か**。↗（語調上揚，清楚表示疑問）

**💡 自我檢查建議：**
- 可以錄音自己說，聽聽語調是否上揚
- 或用手勢：說「か」時手指向上指，提醒自己語調上揚

### 📋 三種句型轉換

#### 1️⃣ 名詞句

| 敘述句 | 疑問句 |
|--------|--------|
| **A は B です。**<br>A 是 B。 | **A は B ですか。**<br>A 是 B 嗎？ |

**例句：**

**敘述句：**
```
あの人は鈴木さんです。
ano hito wa Suzuki-san desu.
那個人是鈴木先生。
```

**疑問句：**
```
あの人は鈴木さんですか。
ano hito wa Suzuki-san desu ka.
那個人是鈴木先生嗎？
```

**更多實用例子：**

**場景1：自我介紹時**
```
A：あなたは学生ですか。
   anata wa gakusei desu ka.
   你是學生嗎？

B：はい、学生です。
   hai, gakusei desu.
   是的，我是學生。
```

**場景2：在商店詢問商品**
```
A：これは本ですか。
   kore wa hon desu ka.
   這是書嗎？

B：はい、本です。
   hai, hon desu.
   是的，是書。
```

**場景3：詢問天氣**
```
A：今日は雨ですか。
   kyō wa ame desu ka.
   今天是雨天嗎？

B：いいえ、雨じゃありません。
   iie, ame ja arimasen.
   不，不是雨天。
```

---

#### 2️⃣ 形容詞句

| 敘述句 | 疑問句 |
|--------|--------|
| **A は 形容詞い です。**<br>A 很～。 | **A は 形容詞い ですか。**<br>A 很～嗎？ |

**例句：**

**敘述句：**
```
この本はおもしろいです。
kono hon wa omoshiroi desu.
這本書很有趣。
```

**疑問句：**
```
この本はおもしろいですか。
kono hon wa omoshiroi desu ka.
這本書有趣嗎？
```

**更多實用例子：**

**場景1：在書店詢問**
```
A：この本はおもしろいですか。
   kono hon wa omoshiroi desu ka.
   這本書有趣嗎？

B：はい、とてもおもしろいです。
   hai, totemo omoshiroi desu.
   是的，非常有趣。
```

**場景2：在商店詢問價格**
```
A：このカメラは高いですか。
   kono kamera wa takai desu ka.
   這台相機貴嗎？

B：いいえ、高くありません。
   iie, takaku arimasen.
   不，不貴。
```

**場景3：詢問天氣**
```
A：今日は寒いですか。
   kyō wa samui desu ka.
   今天冷嗎？

B：はい、とても寒いです。
   hai, totemo samui desu.
   是的，很冷。
```

---

#### 3️⃣ 動詞句（ます形）

| 敘述句 | 疑問句 |
|--------|--------|
| **V ます。**<br>～做、～去…… | **V ますか。**<br>～嗎？ / 要～嗎？ |

**例句：**

**敘述句：**
```

```

**疑問句：**
```
明日、学校へ行きますか。

```

**更多實用例子：**

**場景1：在咖啡廳點餐**
```
A：コーヒーを飲みますか。
   kōhī o nomimasu ka.
   你要喝咖啡嗎？

B：はい、飲みます。
   hai, nomimasu.

```

**場景2：詢問計畫**
```

B：いいえ、行きません。
   iie, ikimasen.
   不，不去。
```

**場景3：詢問習慣**
```
A：毎日、日本語を勉強しますか。

B：はい、勉強します。
   hai, benkyō shimasu.

```

**場景4：在餐廳**


## 二、「はい」「いいえ」的基本回答與「そうです」「ちがいます」的使用規則

### 💡 回答疑問句的基本規則

**日語回答疑問句的方式：**
- **肯定回答**：はい（是的）
- **否定回答**：いいえ（不是）

**⚠️ 重要提醒：**
- 回答時，要把問句中的關鍵詞再說一遍
- 不能只說「はい」或「いいえ」，要說完整句子
- 例：問「これは本ですか？」→ 答「はい、本です。」（不能只說「はい」）

---

### 1️⃣ 名詞句的問句：A は B ですか。

**回答方式：**
- **肯定：** はい、Bです。／はい、そうです。
- **否定：** いいえ、Bではありません。／いいえ、ちがいます。

**例句：**

**問：**
```
あの人は鈴木さんですか。
ano hito wa Suzuki-san desu ka.
那個人是鈴木先生嗎？
```

**答：**

✅ **はい、鈴木さんです。**
```
hai, Suzuki-san desu.
是的，是鈴木先生。
```

✅ **はい、そうです。**
```
hai, sō desu.
是的，沒錯。（這裡可以用「そうです」）
```

✅ **いいえ、鈴木さんではありません。**
```
iie, Suzuki-san de wa arimasen.
不，不是鈴木先生。
```

✅ **いいえ、ちがいます。**
```
iie, chigaimasu.
不，不是。（這裡可以用「ちがいます」）
```

---

### 2️⃣ 形容詞句的問句：A は 高いですか／おもしろいですか。

**回答方式：**
- **肯定：** はい、高いです。／はい、おもしろいです。
- **否定：** いいえ、高くありません。／いいえ、おもしろくありません。

**例句（對比例很重要）：**

**問：**
```
日本のカメラは高いですか。
Nihon no kamera wa takai desu ka.
日本的相機貴嗎？
```

**答：**

✅ **はい、高いです。**
```
hai, takai desu.
是的，很貴。
```

❌ **はい、そうです。**
```
（課本這裡會標為錯，用來說明「そうです」不能這樣用）
```

---

### 3️⃣ 動詞句的問句：行きますか／見ましたか。

**回答方式：**
- **肯定：** はい、行きます。／はい、見ました。
- **否定：** いいえ、行きません。／いいえ、見ませんでした。

**例句：**

**問：**
```
昨日、新聞を読みましたか。
kinō, shinbun o yomimashita ka.
昨天有看報紙嗎？
```

**答：**

✅ **はい、読みました。**
```
hai, yomimashita.
是的，看了。
```

✅ **いいえ、読みませんでした。**
```
iie, yomimasen deshita.
不，沒看。
```

❌ **いいえ、ちがいます。**
```
（同樣，不能只說「ちがいます」，必須說出動詞）
```

### 📌 「そうです」「ちがいます」的使用規則（零基礎必看！）

> **教科書規則（意譯）：**
> 
> 「『そうです』『ちがいます』は、名詞の文の質問に答えるときだけ使います。
> 形容詞や動詞の質問の答えには使いません。」

**中文解說：**
- 「**そうです**」（是的、沒錯）和「**ちがいます**」（不對、不是）
- **在本課的初級規則中，主要用在「名詞＋ですか」這種問句。**
- 問句如果是形容詞句或動詞句，**不能只用「そうです／ちがいます」**，要把關鍵詞再說一遍。

**💡 為什麼教科書這樣要求？**
- 幫助初學者建立正確的句型習慣
- 形容詞和動詞的回答需要具體說明，重複關鍵詞可以強化記憶
- 這是正式場合（商務、學校、初次見面）的標準用法

### ⚠️ 這是初學者最容易犯的錯誤！

**常見錯誤場景：**

**❌ 錯誤1：形容詞句用「そうです」**
```
Q：この本はおもしろいですか。
A：はい、そうです。  ← ❌ 錯誤！
```

**✅ 正確：**
```
Q：この本はおもしろいですか。
A：はい、おもしろいです。  ← ✅ 正確！
```

**❌ 錯誤2：動詞句用「ちがいます」**
```
Q：コーヒーを飲みますか。
A：いいえ、ちがいます。  ← ❌ 錯誤！
```

**✅ 正確：**
```
Q：コーヒーを飲みますか。
A：いいえ、飲みません。  ← ✅ 正確！
```

### 💡 記憶技巧

**口訣：**
- **名詞句** → 可以用「そうです／ちがいます」
- **形容詞句** → 要把形容詞再說一遍
- **動詞句** → 要把動詞再說一遍

**為什麼？**
- 「そうです」意思是「是這樣的」，只能回答「是什麼」的問題
- 形容詞和動詞的問題，需要具體說明「怎麼樣」或「做什麼」

---

## 三、「やってみよう１」：『そうです』的用法練習

### 📝 練習重點

這一部分練習的重點是：
- 看 B 的回答裡用「そうです」對不對。
- 再把錯誤的句子改成正確的句型。

---

### 【例１】（名詞句：可以用「そうです」）

**對話：**

```
A：これは森田さんの本ですか。
   kore wa Morita-san no hon desu ka.
   這是森田先生的書嗎？

B：（○）はい、そうです。　→　はい、森田さんの本です。
   (○) hai, sō desu.  →  hai, Morita-san no hon desu.
   是的，沒錯。→ 是的，是森田先生的書。
```

**說明：**
- 問句是「**森田さんの本ですか**」→ 名詞句。
- 用「**はい、そうです**」沒有問題，然後也可以改寫成完整句：
  「**はい、森田さんの本です。**」

---

### 【例２】（動詞句：不可以用「そうです」）

**對話：**

```
A：きのう、テレビを見ましたか。
   kinō, terebi o mimashita ka.
   昨天有看電視嗎？

B：（×）はい、そうです。　→　はい、見ました。
   (×) hai, sō desu.  →  hai, mimashita.
   （×）是的，沒錯。→（○）是的，看了。
```

**說明：**
- 問句是「**見ましたか**」→ 動詞句。
- 不能用「**はい、そうです**」，要把動詞「見る」的過去形說出來：
  「**見ました。**」

---

### 【問題１】

**對話：**

```
A：この本はおもしろいですか。
   kono hon wa omoshiroi desu ka.
   這本書有趣嗎？

B：（　）はい、そうです。　→　_________________________
```

**【解答】**

❌ **(×)** → ✅ **はい、おもしろいです。**

**說明：**
- 問句是形容詞句「**おもしろいですか**」。
- 所以「**はい、そうです**」不可以，只能用「**はい、おもしろいです。**」

---

### 【問題２】

**對話：**

```
A：日本のカメラは高いですか。
   Nihon no kamera wa takai desu ka.
   日本的相機貴嗎？

B：（　）いいえ、ちがいます。　→　_________________________
```

**【解答】**

❌ **(×)** → ✅ **いいえ、高くありません。**

**說明：**
- 「**高いですか**」是形容詞句。
- 否定回答要再說一次形容詞的否定形：
  「**高くありません**」／「**高くないです**」都可以。
- 「**いいえ、ちがいます**」只適合用在名詞句。

---

### 【問題３】

**對話：**

```
A：あの人は会社員ですか。
   ano hito wa kaishain desu ka.
   那個人是公司職員嗎？

B：（　）はい、そうです。　→　_________________________
```

**【解答】**

✅ **(○)** → ✅ **はい、会社員です。／はい、そうです。**

**說明：**
- 問句是「**会社員ですか**」→ 名詞句。
- 所以「**はい、そうです**」OK，也可以改寫成
  「**はい、会社員です。**」

## 四、「やってみよう２」：AかBか の質問

### 📌 重要原則（零基礎必看！）

> **「『はい』『いいえ』は、『AかBか』という質問の答えには一般不會用。」**

也就是說，當問題是「**Aですか、Bですか**」這種「**二選一**」的句型時，
回答**通常不加「はい／いいえ」**，而是直接說「**Aです**」或「**Bです**」。

### 💡 為什麼一般不會用「はい／いいえ」？

**想像一下：**
- 中文：你要咖啡還是茶？→ 答：咖啡（直接選一個）
- 日文：コーヒーですか、お茶ですか。→ 答：コーヒーです（直接選一個）

**如果用「はい」會比較不自然：**
- ❌ コーヒーですか、お茶ですか。→ はい、コーヒーです。
  - 聽起來有點奇怪，因為問題是「選一個」，不是「是或不是」

**✅ 最自然的做法：**
- コーヒーですか、お茶ですか。→ **コーヒーです。**（直接選一個）
- 或：**コーヒーでお願いします。**（咖啡，麻煩了）

### ⚠️ 常見錯誤提醒

**不太自然：**
```
Q：今日は休みですか、仕事ですか。
A：はい、休みです。  ← 不太自然，通常不加「はい」
```

**✅ 更自然的回答：**
```
Q：今日は休みですか、仕事ですか。
A：休みです。  ← ✅ 最自然！直接選一個
```

### 📋 基本句型

| 問句 | 回答 |
|------|------|
| **Aですか、Bですか。**<br>（是 A 還是 B？） | **Aです。／Bです。** |

---

### 【例】（和課本幾乎同型）

**對話：**

```
A：森田さんは学生ですか、会社員ですか。
   Morita-san wa gakusei desu ka, kaishain desu ka.
   森田先生是學生，還是上班族？

B：× はい、会社員です。
     hai, kaishain desu.
   ○ 会社員です。
     kaishain desu.
```

**說明：**
- 問題已經是「學生嗎？還是上班族？」這是「**二選一**」的問題。
- 你只要選一個答案說出來就好：「**学生です。**」或「**会社員です。**」
- 加上「**はい**」反而會讓句子變得奇怪，所以教科書特別拿出來修正。

---

### 【練習１】

**對話：**

```
A：これは森田さんの本ですか、鈴木さんの本ですか。
   kore wa Morita-san no hon desu ka, Suzuki-san no hon desu ka.
   這是森田先生的書，還是鈴木先生的書？

B：_________________________
```

**【解答例】**

✅ **森田さんの本です。**
```
Morita-san no hon desu.
是森田先生的書。
```

**也可以回答：**

✅ **鈴木さんの本です。**
```
Suzuki-san no hon desu.
（如果你想說是鈴木的書，就選另一個。）
```

---

### 【練習２】

**對話：**

```
A：今日は休みですか、仕事ですか。
   kyō wa yasumi desu ka, shigoto desu ka.
   今天是休假，還是要上班？

B：_________________________
```

**【解答例】**

✅ **休みです。**
```
yasumi desu.
今天是休假。
```

**或：**

✅ **仕事です。**
```
shigoto desu.
今天要上班。
```

---

### 【練習３】

**對話：**

```
A：映画はおもしろかったですか、つまらなかったですか。
   eiga wa omoshirokatta desu ka, tsumaranakatta desu ka.
   電影好看，還是不好看？

B：_________________________
```

**【解答例】**

✅ **おもしろかったです。**
```
omoshirokatta desu.
很好看。
```

**或：**

✅ **つまらなかったです。**
```
tsumaranakatta desu.
不好看，蠻無聊的。
```

**說明：**
- 雖然這裡用到過去形，但規則一樣：
  問句是「**A でしたか、B でしたか**」，回答只說其中一個，不要加「**はい／いいえ**」。

## 五、整體重點小結與快速記憶表

### 📚 規則總覽

#### 1. 基本疑問句
- **句子 + か** → 問句
- 名詞＋ですか／形容詞＋ですか／動詞ます＋か

#### 2. 名詞句的問答
**問：** A は B ですか。  
**答：** ✅ はい、Bです。／はい、そうです。  
**答：** ✅ いいえ、Bではありません。／いいえ、ちがいます。

#### 3. 形容詞句的問答
**問：** A は 高いですか。  
**答：** ✅ はい、高いです。  
**答：** ✅ いいえ、高くありません。  
❌ **不可以說「はい、そうです／いいえ、ちがいます」。**

#### 4. 動詞句的問答
**問：** V ますか／Vましたか。  
**答：** ✅ はい、Vます／Vました。  
**答：** ✅ いいえ、Vません／Vませんでした。  
❌ **同樣不能只說「そうです／ちがいます」。**

#### 5. 『そうです』『ちがいます』使用範圍
- ✅ **只能用在「名詞文」的問題上。**
- ❌ 形容詞、動詞的問句一律要把形容詞／動詞再說一遍。

#### 6. 『はい』『いいえ』和「AかBか」
- ❌ 「**Aですか、Bですか。**」這種二選一問題，回答時**不要用「はい／いいえ」**。
- ✅ 直接說：「**Aです。**」或「**Bです。**」即可。

### 📋 快速記憶表

#### 疑問句轉換表

| 句型 | 敘述句 | 疑問句 | 記憶口訣 |
|------|--------|--------|---------|
| **名詞** | A は B です | A は B ですか | 句尾加「か」 |
| **い形容詞** | A は 高いです | A は 高いですか | 句尾加「か」 |
| **動詞** | V ます | V ますか | 句尾加「か」 |

#### 回答方式對照表

| 句型 | 疑問句 | 肯定回答 | 否定回答 | 注意事項 |
|------|--------|---------|---------|---------|
| **名詞** | A は B ですか | はい、Bです。<br>はい、そうです。 | いいえ、Bではありません。<br>いいえ、ちがいます。 | ✅ 可以用「そうです」 |
| **い形容詞** | A は 高いですか | はい、高いです。 | いいえ、高くありません。 | ❌ 不能只用「そうです」 |
| **動詞** | V ますか | はい、Vます。 | いいえ、Vません。 | ❌ 不能只用「ちがいます」 |

### 💡 記憶口訣總結

1. **疑問句**：句尾加「か」↗，語調要上揚
2. **名詞句回答**：可以用「そうです／ちがいます」
3. **形容詞句回答**：不能只用「そうです」，要把形容詞再說一遍
4. **動詞句回答**：不能只用「ちがいます」，要把動詞再說一遍
5. **二選一問題**：通常不加「はい／いいえ」，直接選一個

## 八、口語補充區（進階可略讀）

> ⚠️ **注意：** 這是進階內容，初學者可以先跳過。先把「です／ます＋か」學好，這是正式場合必備。

### 💬 朋友間的口語用法

**在正式場合（商務、學校、初次見面）必須用「です／ます＋か」：**
```
これは本ですか。↗
```

**但在朋友間，常常會：**

#### 1. 省略「か」＋語調上揚

**正式：**
```
学校へ行きますか。↗
```

**口語（朋友間）：**
```
学校？↗（省略「へ行きますか」，只用語調上揚）
行く？↗（省略「ますか」，用動詞普通形）
```

#### 2. 用「の？」

**正式：**
```
学校へ行きますか。
```

**口語（朋友間）：**
```
行くの？↗（用「の？」代替「か」）
休みなの？↗（な形容詞用「なの？」）
```

**更多例子：**

| 正式（丁寧体） | 口語（朋友間） | 使用場合 |
|--------------|--------------|---------|
| 学校へ行きますか。 | 学校？／行く？ | 朋友、家人 |
| 休みですか。 | 休み？／休みなの？ | 朋友、家人 |
| おもしろいですか。 | おもしろい？／おもしろいの？ | 朋友、家人 |

### 📌 重要提醒

**初學者建議：**
- ✅ 先掌握「です／ます＋か」的正式用法
- ✅ 這是正式場合（商務、學校、初次見面）的標準用法
- ✅ 等熟悉後，再學習口語用法

**為什麼？**
- 正式用法適用於所有場合
- 口語用法只適合朋友、家人等親近關係
- 用錯場合會顯得沒禮貌
