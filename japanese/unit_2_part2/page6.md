# 第六課：日文數字與助數詞（Counter Suffixes）

## 一、日文數字系統

日文的數字系統與中文類似，但讀音不同。本課學習十位數（じゅう）、百位數（ひゃく）、千位數（せん）和萬位數（まん）的讀法。

### 1. 十位數（じゅう - Tens）

| 數字 | 日文 | 羅馬拼音 | 中文 |
|------|------|----------|------|
| 10 | じゅう | jū | 十 |
| 20 | にじゅう | nijū | 二十 |
| 30 | さんじゅう | sanjū | 三十 |
| 40 | よんじゅう | yonjū | 四十 |
| 50 | ごじゅう | gojū | 五十 |
| 60 | ろくじゅう | rokujū | 六十 |
| 70 | ななじゅう | nanajū | 七十 |
| 80 | はちじゅう | hachijū | 八十 |
| 90 | きゅうじゅう | kyūjū | 九十 |
| 幾十？ | なんじゅう | nanjū | 幾十？ |

**文法說明：**
- 十位數的構成方式：數字 + じゅう（jū）
- 例如：2（に）+ じゅう = にじゅう（20）
- 詢問數量時用「なんじゅう」（nanjū）

**實用例句：**
- 私は30歳です。
  - Watashi wa sanjū-sai desu.
  - 我三十歲。

- この本は50ページあります。
  - Kono hon wa gojū-pēji arimasu.
  - 這本書有五十頁。

### 2. 百位數（ひゃく - Hundreds）

| 數字 | 日文 | 羅馬拼音 | 中文 | 注意事項 |
|------|------|----------|------|----------|
| 100 | ひゃく | hyaku | 一百 | |
| 200 | にひゃく | nihyaku | 二百 | |
| 300 | さんびゃく | sanbyaku | 三百 | **音變：hyaku → byaku** |
| 400 | よんひゃく | yonhyaku | 四百 | |
| 500 | ごひゃく | gohyaku | 五百 | |
| 600 | ろっぴゃく | roppyaku | 六百 | **音變：hyaku → pyaku + 促音** |
| 700 | ななひゃく | nanahyaku | 七百 | |
| 800 | はっぴゃく | happyaku | 八百 | **音變：hyaku → pyaku + 促音** |
| 900 | きゅうひゃく | kyūhyaku | 九百 | |
| 幾百？ | なんびゃく | nanbyaku | 幾百？ | **音變：hyaku → byaku** |

**文法說明：**
- 百位數的構成方式：數字 + ひゃく（hyaku）
- **重要音變規則：**
  - 3（さん）+ ひゃく → さんびゃく（hyaku 變成 byaku）
  - 6（ろく）+ ひゃく → ろっぴゃく（hyaku 變成 pyaku，且ろく的「く」變成促音「っ」）
  - 8（はち）+ ひゃく → はっぴゃく（hyaku 變成 pyaku，且はち的「ち」變成促音「っ」）
  - 詢問時：なん + ひゃく → なんびゃく（hyaku 變成 byaku）

**實用例句：**
- この車は300万円です。
  - Kono kuruma wa sanbyaku-man en desu.
  - 這輛車是三百萬日圓。

- 600円のランチを食べました。
  - Roppyaku-en no ranchi o tabemashita.
  - 我吃了六百日圓的午餐。

### 3. 千位數（せん - Thousands）

| 數字 | 日文 | 羅馬拼音 | 中文 | 注意事項 |
|------|------|----------|------|----------|
| 1,000 | せん | sen | 一千 | |
| 2,000 | にせん | nisen | 二千 | |
| 3,000 | さんぜん | sanzen | 三千 | **音變：sen → zen** |
| 4,000 | よんせん | yonsen | 四千 | |
| 5,000 | ごせん | gosen | 五千 | |
| 6,000 | ろくせん | rokusen | 六千 | |
| 7,000 | ななせん | nanasen | 七千 | |
| 8,000 | はっせん | hassen | 八千 | **促音：はち → はっ** |
| 9,000 | きゅうせん | kyūsen | 九千 | |
| 幾千？ | なんぜん | nanzen | 幾千？ | **音變：sen → zen** |

**文法說明：**
- 千位數的構成方式：數字 + せん（sen）
- **重要音變規則：**
  - 3（さん）+ せん → さんぜん（sen 變成 zen）
  - 8（はち）+ せん → はっせん（はち的「ち」變成促音「っ」）
  - 詢問時：なん + せん → なんぜん（sen 變成 zen）

**實用例句：**
- このパソコンは8,000円です。
  - Kono pasokon wa hassen-en desu.
  - 這台電腦是八千日圓。

- 3,000人の学生がいます。
  - Sanzen-nin no gakusei ga imasu.
  - 有三千名學生。

### 4. 萬位數（まん - Ten Thousands）

| 數字 | 日文 | 羅馬拼音 | 中文 |
|------|------|----------|------|
| 10,000 | いちまん | ichiman | 一萬 |
| 20,000 | にまん | niman | 二萬 |
| 30,000 | さんまん | sanman | 三萬 |
| 40,000 | よんまん | yonman | 四萬 |
| 50,000 | ごまん | goman | 五萬 |
| 60,000 | ろくまん | rokuman | 六萬 |
| 70,000 | ななまん | nanaman | 七萬 |
| 80,000 | はちまん | hachiman | 八萬 |
| 90,000 | きゅうまん | kyūman | 九萬 |
| 幾萬？ | なんまん | nanman | 幾萬？ |

**文法說明：**
- 萬位數的構成方式：數字 + まん（man）
- 注意：10,000 要說「いちまん」（ichiman），不能只說「まん」
- 萬位數沒有音變，讀音較為規則

**實用例句：**
- この家は5,000万円です。
  - Kono ie wa goman-en desu.
  - 這間房子是五萬日圓。

- 給料は30万円です。
  - Kyūryō wa sanman-en desu.
  - 薪水是三萬日圓。

## 二、複合數字的讀法

當數字包含多個位數時，按照從大到小的順序讀出。

**實用例句：**
- 53 → ごじゅうさん（gojūsan）
  - 五十 + 三 = 五十三

- 23,800円です。
  - Nisanzen happyaku-en desu.
  - 是二萬三千八百日圓。
  - 分解：2萬（にまん）+ 3千（さんぜん）+ 8百（はっぴゃく）

## 三、練習題（やってみよう！）

以下是課本中的練習題，請試著讀出這些數字：

### 練習題 1：284
**答案：** にひゃくはちじゅうよん（nihyaku hachijū yon）
- 分解：200（にひゃく）+ 80（はちじゅう）+ 4（よん）
- 中文：二百八十四

**實用例句：**
- この本は284ページあります。
  - Kono hon wa nihyaku hachijū yon-pēji arimasu.
  - 這本書有284頁。

### 練習題 2：369
**答案：** さんびゃくろくじゅうきゅう（sanbyaku rokujū kyū）
- 分解：300（さんびゃく）+ 60（ろくじゅう）+ 9（きゅう）
- 中文：三百六十九
- **注意：** 300 要讀成「さんびゃく」，不是「さんひゃく」

**實用例句：**
- 369円の商品を買いました。
  - Sanbyaku rokujū kyū-en no shōhin o kaimashita.
  - 我買了369日圓的商品。

### 練習題 3：612
**答案：** ろっぴゃくじゅうに（roppyaku jū ni）
- 分解：600（ろっぴゃく）+ 10（じゅう）+ 2（に）
- 中文：六百一十二
- **注意：** 600 要讀成「ろっぴゃく」，有促音「っ」，且「ひゃく」變成「ぴゃく」

**實用例句：**
- 612番のバスに乗ります。
  - Roppyaku jū ni-ban no basu ni norimasu.
  - 我搭612號公車。

### 練習題 4：1,450
**答案：** せんよんひゃくごじゅう（sen yonhyaku gojū）
- 分解：1,000（せん）+ 400（よんひゃく）+ 50（ごじゅう）
- 中文：一千四百五十

**實用例句：**
- このコースは1,450円です。
  - Kono kōsu wa sen yonhyaku gojū-en desu.
  - 這個課程是1,450日圓。

### 練習題 5：8,764
**答案：** はっせんななひゃくろくじゅうよん（hassen nanahyaku rokujū yon）
- 分解：8,000（はっせん）+ 700（ななひゃく）+ 60（ろくじゅう）+ 4（よん）
- 中文：八千七百六十四
- **注意：** 8,000 要讀成「はっせん」，有促音「っ」

**實用例句：**
- 8,764人の観客が来ました。
  - Hassen nanahyaku rokujū yon-nin no kankyaku ga kimashita.
  - 來了8,764名觀眾。

## 四、助數詞（Counter Suffixes）的用法

### 基本概念

**日文說明：**
物の数をかぞえるときは、数字のあとに助数詞をつける。どんなものをかぞえるかで使う助数詞が決まる。

**中文說明：**
當你計算物品的數量時，要在數字後面加上助數詞。你計算的物品類型決定了要使用哪個助數詞。

**文法說明：**
- 助數詞是日文中用來表示物品單位的詞彙
- 格式：數字 + 助數詞
- 不同的物品使用不同的助數詞
- 例如：計算人用「人（にん）」，計算書本用「冊（さつ）」，計算圓形物品用「個（こ）」

**實用例句：**
- りんごを3個買いました。
  - Ringo o san-ko kaimashita.
  - 我買了三個蘋果。
  - **文法：** 3（さん）+ 個（こ）= さんこ（san-ko）

- 本を5冊読みました。
  - Hon o go-satsu yomimashita.
  - 我讀了五本書。
  - **文法：** 5（ご）+ 冊（さつ）= ごさつ（go-satsu）

- 友達が2人来ました。
  - Tomodachi ga ni-nin kimashita.
  - 來了兩個朋友。
  - **文法：** 2（に）+ 人（にん）= ににん（ni-nin）

## 五、重要提醒：助數詞會改變數字的讀音

### 基本規則

**日文說明：**
あとにつく助数詞で、数字の読み方が変わることがある。

**中文說明：**
放在後面的助數詞可能會改變數字的讀法。

**文法說明：**
- 這是日文學習中非常重要的一點
- 同樣的數字，根據後面接的助數詞不同，讀音可能會改變
- 這是因為日文有音便（音變）現象，為了發音順暢而改變讀音

### 實例說明

#### 例 1：4円（よえん）

**讀音：** よえん（yoen）
- 4 通常讀作「よん」（yon）
- 但接「円（えん）」時，讀作「よ」（yo）
- **變化：** よん → よ（去掉「ん」）

**實用例句：**
- このペンは4円です。
  - Kono pen wa yo-en desu.
  - 這支筆是四日圓。

- 4円の切手を買いました。
  - Yo-en no kitte o kaimashita.
  - 我買了四日圓的郵票。

**其他「円」的讀音變化：**
- 1円：いちえん（ichien）- 不變
- 2円：にえん（nien）- 不變
- 3円：さんえん（san'en）- 不變
- 4円：よえん（yoen）- **變化**
- 5円：ごえん（goen）- 不變
- 6円：ろくえん（rokuen）- 不變
- 7円：ななえん（nanaen）- 不變
- 8円：はちえん（hachien）- 不變
- 9円：きゅうえん（kyūen）- 不變
- 10円：じゅうえん（jūen）- 不變

#### 例 2：1歳（いっさい）

**讀音：** いっさい（issai）
- 1 通常讀作「いち」（ichi）
- 但接「歳（さい）」時，讀作「いっ」（i + 促音「っ」）
- **變化：** いち → いっ（「ち」變成促音「っ」）

**實用例句：**
- 私は1歳です。
  - Watashi wa issai desu.
  - 我一歲。

- 息子は1歳になりました。
  - Musuko wa issai ni narimashita.
  - 兒子一歲了。

**其他「歳」的讀音變化：**
- 1歳：いっさい（issai）- **變化**
- 2歳：にさい（nisai）- 不變
- 3歳：さんさい（sansai）- 不變
- 4歳：よんさい（yonsai）- 不變
- 5歳：ごさい（gosai）- 不變
- 6歳：ろくさい（rokusai）- 不變
- 7歳：ななさい（nanasai）- 不變
- 8歳：はっさい（hassai）- **變化**
- 9歳：きゅうさい（kyūsai）- 不變
- 10歳：じっさい（jissai）- **變化**

### 常見助數詞的讀音變化總結

| 助數詞 | 意思 | 1的讀音 | 4的讀音 | 8的讀音 | 10的讀音 |
|--------|------|---------|---------|---------|----------|
| 円（えん） | 日圓 | いちえん | **よえん** | はちえん | じゅうえん |
| 歳（さい） | 歲 | **いっさい** | よんさい | **はっさい** | **じっさい** |
| 個（こ） | 個 | **いっこ** | よんこ | **はっこ** | **じっこ** |
| 本（ほん） | 根、支 | **いっぽん** | よんほん | **はっぽん** | **じっぽん** |
| 枚（まい） | 張、片 | いちまい | よんまい | はちまい | じゅうまい |
| 人（にん） | 人 | ひとり | よにん | はちにん | じゅうにん |

**注意：**
- 粗體標示的是有讀音變化的
- 這些變化需要特別記憶，沒有固定規則
- 建議多練習，熟悉後自然會記住

## 六、學習重點總結

### 1. 數字讀音的音變規則

**百位數（ひゃく）的音變：**
- 3 → さんびゃく（byaku）
- 6 → ろっぴゃく（pyaku + 促音）
- 8 → はっぴゃく（pyaku + 促音）
- 詢問 → なんびゃく（byaku）

**千位數（せん）的音變：**
- 3 → さんぜん（zen）
- 8 → はっせん（促音）
- 詢問 → なんぜん（zen）

### 2. 助數詞的重要性

- 日文計算物品時必須使用助數詞
- 不同的物品使用不同的助數詞
- 助數詞會影響數字的讀音

### 3. 記憶技巧

1. **分類記憶：** 將有音變的數字分組記憶
2. **多練習：** 反覆練習讀出數字，熟悉音變
3. **實用例句：** 透過實際例句學習，更容易記住
4. **注意促音：** 6和8在接某些助數詞時會出現促音「っ」
